# Golem [ADR 0352](../../docs/adr/0352-prove-pagination-in-lean.md) の Lean 証明

このディレクトリは、[Golem ADR 0352](../../docs/adr/0352-prove-pagination-in-lean.md) の改ページ証明を作る場所である。`check.sh` は Alloy の42コマンドと期待値の一覧が一致することを確かめ、各コマンドに対応する Lean の宣言を要求する。

現在の `Pagination.lean` には、42コマンドのうち36コマンドと同名の宣言がある。`blankFigureOrder` は、本文を置かない境界の配置を構成し、図版が0〜2枚で行アキが0〜1個の入力について、図版規則、行アキ規則、段容量を同時に満たすことを証明する。`blankRules25` は、空段の先頭内容を本文・図版・内容なしに分け、旧行アキ規則と段容量、本文と図版の順序、空段から先頭内容を送らない規則を同時に満たす配置を証明する。`figureEmpty` と `figureOrder` は行アキのない入力をこの証明から導く。`keep21` はこの配置に、段落境界の orphan、widow、見出しの規則を接続する。`keepHeadingEmpty`、`keepHeadingFigure`、`keepHeadingOrphan`、`keepHeadingWidow`、`orphanEmpty`、`widowEmpty`、`orphanWidow`、`noneMeetsAllButGreedy` は、この同じ配置から対象の規則を取り出す。`waitingBlankNone` と `waitingBlankAllButGreedy` は、待機中の図版を飛ばす現在の行アキ規則について同様の配置を構成する。段容量と図版寸法に有限の上限はないが、元の Alloy 入力と Lean の入力が全体として同値であることは未証明である。

`decidedSome` は、容量3行の空段に改丁見出し1行と1行段落を続け、両方を置く配置を証人とする。手元の Alloy CLI で同じ容量、使用済み行数0、本文の位置0・1、区切り位置2を固定して実行し、解を確認した。`keepAllSome` は、容量3行、使用済み1行、本文1行の配置を証人とする。同じ入力を Alloy CLI で固定して解を確認した。

`relaxedAfterHeadings` の代表入力では、空段の先頭に見出し1行と3行段落を続ける。Lean は任意の段落行数と容量2行以上について、見出しと最初の本文行を置く区切りが緩めた孤立行・寡婦行規則と見出し後の1行規則を満たすことを示す。Alloy でも容量3行、段落3行、区切り2を固定して解を確認した。任意の見出し列と図版を含む `relaxedAfterHeadings` 全体は未証明である。

Alloy の容量下限3行を外し、容量1行の空段に見出し1行と本文1行を続けると、段頭の見出しを置く規則、収まり、見出し後の本文1行を同時に満たす区切りはない。Lean はこの2項目入力の区切り0〜2をすべて排除する。Golem は見出しだけを最初の段に置き、本文を次の段に置いた。したがって、この出力は Alloy の見出し後1行規則を満たさない。容量2行以上では両方を置く区切りがある。

同じ入力を Golem に渡すと、最初の段には見出しと本文2行が置かれ、残る本文1行は次の段に置かれる。Alloy の区切り2も実装の区切り3も緩めた規則を満たす。モデルは配置の存在を調べるもので、規則を満たす配置が複数ある場合の選択順はこの証明では扱っていない。

見出しと最初の本文行の間または後ろに図版が一つある場合も、任意の容量2行以上で、図版の寸法に応じて本文1行と図版のどちらを置くかを算術モデルで証明した。容量3行で見出しの後に高さ2行の図版が収まる入力と、高さ3行の図版が待機する入力は、Alloy の固定入力と Golem の回帰テストの双方で配置を確認した。任意の原稿列における図版の位置と算術モデルの対応は未証明である。

図版がなく、見出し列の後に段落が続く形では、容量2行以上の任意の段、見出し1行以上、本文1行以上に対し、最初の見出しの後か最初の本文行の後で区切れることを示した。見出し2行と本文1行、区切り1の入力は Alloy でも確認した。見出し列と本文の位置を原稿列から取り出す一般的な対応は未証明である。

さらに、任意長の見出し・本文行の列から最初の区切りを選ぶと、容量2行以上で収まり、先頭内容を置き、見出し後の本文1行規則を満たすことを証明した。この区切りで置かれる見出しは必ず最初の行にあり、置かれる本文行より前には見出ししかない。したがって、この本文行が段落の最初の行であれば、緩めた孤立行・寡婦行規則の前提に必要な位置関係が成り立つ。図版を含む原稿と Alloy の `para` 関係への対応は未証明である。

改丁見出しを本文の位置列として与えた場合は、本文を置かない区切りと、空段の最初の本文だけを置く区切りで、置いた改丁見出しが段頭になることを証明した。これは図版と行アキの現在の規則が構成する配置にも接続した。見出し後の1行規則を同時に満たす `rectoKept` と `rectoEnds` 全体は未証明である。

旧 `keepHeading21` と改丁見出しで見出し列を切る `keepHeadingR` の差は、通常見出し2行と改丁見出し1行を続け、区切り2を選ぶ固定入力で示した。この配置は `keepHeadingR` と改丁規則を満たすが、旧 `keepHeading21` を満たさない。Alloy でも同じ述語差を確認した。Golem に同じ原稿を渡す回帰テストは、通常見出し2行を最初のページに置き、空白の2ページ目の後で改丁見出しを3ページ目に置く結果で通過した。

`keepDefaultDiffers` は、段落の分割前後の行数に関する orphan、widow 規則と、先頭・最後の位置による境界規則が一致することを示す。さらに、Lean の段落行位置列を配置済み行と次段の行に分けると、両者の行数の和が元の行数と一致し、分割の存在と両方の行数が正であることも同値である。Alloy の `para`、`first`、`second`、`beforeLast`、`last` から Lean の行数と位置への対応は未証明である。

`keepNone` は、段落の最初の行を含む任意の行位置列と任意の keep 指定について、旧図版規則の配置と keep 指定を同時に満たす証人を構成する。Lean では、本文を置かない場合に分割を生じさせず、空段に最初の本文行を置く場合に分割された段落が段頭で始まることを証明する。Alloy の `para.q` と Lean の行位置列の対応は未証明である。

`needMore27` は、容量3行、使用済み1行、`need-lines` 1行、スペース1行、`need-lines` 3行、段落1行の入力で旧 P7 と P1 を同時に満たす配置がないことを示す。Alloy でも同じ入力と配置3通りを固定して解を確認した。

`needMoreSome` は、容量4行で同じ配置の新 P7 が両方の `need-lines` を満たす証人を示す。`needSpaceSome` は、容量3行、使用済み1行、`need-lines` 2行、スペース1行、段落1行の証人を示す。両方の入力は Alloy でも固定して解を確認した。

さらに、`need-lines`、空き、`need-lines`、本文1行という形では、任意の段容量と使用済み行数について、二つの `need-lines` の大きい値を判定すれば P1 と P7 を同時に満たす区切りがあることを証明した。区切り0、1、2で空きと本文が置かれる位置は Lean の原稿列から計算して照合した。この定理は図版、行アキ、ほかの本文を含む `needMoreNone` 全体にはまだ及ばない。

実装との照合には、二つの入力を [PaginateSpec](../../modules/golem-layout/test/PaginateSpec.hs) に追加した。先頭の1行段落で使用済み1行を作り、後続の `need-lines`、スペース、段落の配置を検査する。手元の実装では二つの回帰テストがそれぞれ1件ずつ通過した。

図版寸法の証明では、`tallFigure` の旧規則が段より高い図版と衝突することを任意の自然数の高さについて示す。縮小後はこの衝突が解消する。キャプション付き図版については、入力の行数から占有できる高さの上限を証明する。

残る6コマンド、既存宣言と元の述語の同値性、キャプションの行分割、改ページの全状態遷移と終了、出力の過不足と順序、実装との境界例の照合は未完である。`check.sh` は `needMoreNone` の欠落を報告して失敗する。移行が完了するまで Alloy の定期実行と既存の参照を維持する。

手元では次のコマンドで Lean 4.7.0 の証明を検査する。

```sh
lean experiments/pagination-proof/Pagination.lean
sh experiments/pagination-proof/check.sh
```

`decidedSome`、`keepAllSome`、`needMore27`、`needMoreSome`、`needSpaceSome`、見出し後の本文行の具体的な証人は、Alloy CLI を用意して次のコマンドで照合する。

```sh
sh experiments/pagination-proof/check-alloy-witnesses.sh
```

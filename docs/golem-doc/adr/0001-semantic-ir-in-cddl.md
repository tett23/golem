# ADR 0001: 意味論 IR の正典を CDDL で定める

ステータス: 採択

## 文脈

意味論 IR は、評価が済んだ文書の内容を表し、すべてのバックエンドがここから分岐する。
同じ構造は、wasm のプラグインとの受け渡し（CBOR）にも使う。
二つを別々に定義すると、処理系の内部の型とプラグインの ABI が次第にずれていく。
そこで、意味論 IR の正典を CDDL で記述し、Haskell の型はそれと一致するように保つと決めている。

意味論 IR には、処理系の内部では型で守っている不変条件がある（ルビの中にルビを入れない、など）。
プラグインの出力は wasm の境界を越えて戻ってくるので、型の保証は失われ、ホストが検証し直す必要がある。

## 実装すること

### CDDL のスキーマ

`modules/golem-doc/schema/golem-doc.cddl` に、意味論 IR の全体を記述する。
少なくとも次の要素を含む。

- ファイル一つ分の文書：ファイルの識別子と、ブロックの列。
- ブロック：段落、見出し（階層、属性、インラインの列）、箇条書きと番号付きのリスト、定義リスト（用語と説明の多対多）、表、コードブロック、図版、チャネルを出力するブロック（目次、索引、参考文献）。
- インライン：テキスト、強調（意味の強調、太字、斜体）、ルビ、圏点、色、文字スタイル、縦中横、Number、遅延参照（DeferredRef）、注の印、索引の印、引用の印。
- 属性：ラベル、短い題、番号の指定、番号からの除外、目次からの除外。
- ソース位置：各ノードが持つ `SrcSpan`。

### 符号化の規則

- 直和型は `[タグ番号, フィールド...]` の配列で表す。タグ番号は一度割り当てたら変えない。
- マップは使わず、フィールドの順序で区別する。
- CBOR は RFC 8949 の決定的エンコードで書く。
- スキーマの先頭に版の番号を置き、ABI の版と一致させる。ノードやフィールドを追加したら版を上げる。

### ルビの入れ子の禁止

CDDL では、ルビを振る対象を、ルビを含まないインラインの規則（`inline-no-ruby`）で定義する。
Haskell では、インラインの型を `InlineF ruby` のように型パラメータで定義し、ルビの中では `ruby` に `Void` を与えて、ルビの入れ子を型で禁じる。

### Haskell の型との一致

- Haskell の型は手で書き、CBOR との相互変換の関数を持つ。
- 変換は、`Data.Map` の走査順に依存せず、決定的なバイト列を出力する。
- CBOR の符号化と復号には `cborg` を使う。

### 検証

`validate :: CBOR -> Either [Diagnostic] Document` を用意し、次を検査する。

- CDDL のスキーマへの適合。
- 意味論上の不変条件：ルビの入れ子がないこと、モノルビのセグメント数が一致すること、ソース位置が入力ファイルの範囲内にあること、評価前の式が含まれないこと。

この検証は、プラグインの出力を受け取るたびに使う。

## 実装しないこと

- CDDL から Haskell の型を自動生成する仕組み。型は手で書き、テストで一致を保証する。
- 文書構造（S1）の集約。後続の ADR で扱う。
- プラグインの呼び出し規約。golem-plugin の ADR で扱う。

## テスト設計

- **往復**：hedgehog で生成した任意の文書について、CBOR に符号化して復号すると元に戻ることを確かめる。
- **決定性**：同じ文書を何度符号化しても、同じバイト列になることを確かめる。
- **スキーマとの一致**：生成した文書の CBOR が CDDL に適合することを、CDDL の検証器で確かめる。Haskell には成熟した CDDL の検証器がないので、テストでは外部の検証器（Rust の `cddl` クレートの CLI）を使う。
- **不変条件の検出**：ルビを入れ子にした CBOR、セグメント数の合わないモノルビ、範囲外のソース位置、評価前の式を含む CBOR を `validate` に与え、それぞれが診断になることを確かめる。

## トレードオフ

CDDL を正典にすると、IR を変えるたびに CDDL、Haskell の型、変換の関数の三箇所を直す必要がある。
その代わり、プラグインの ABI と処理系の内部が同じ定義から外れないことを、テストで機械的に保証できる。

実行時の検証（`validate`）は、Haskell の検証器で CDDL の全機能を解釈するのではなく、意味論 IR に必要な検査を手で書く。
CDDL の汎用の検証器を Haskell で実装する手間を避けるためであり、二つの検証の一致はテストで確かめる。

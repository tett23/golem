# ADR 0002: 文書構造（S1）の集約

ステータス: 採択

## 文脈

ファイル内評価（S0）は、ファイルごとに意味論 IR と、S1 が集める情報（`FileIndex`）を出力する（golem-eval ADR 0002）。
文書構造（S1）は、すべてのファイルの結果をマニフェストの順に集め、ファイルをまたいで決まる値を確定させる段階である。
見出しの番号、ラベルの解決、目次、図番号、索引、参考文献、`doc` の名前空間の値がここで決まる。
ページ番号はまだ決まらず、S2 に残る。

## 実装すること

### 入力と出力

```haskell
assemble
  :: Manifest
  -> Style
  -> [(FileId, Doc.Document, FileIndex)]   -- マニフェストの順
  -> (Doc.Book, [Diagnostic])
```

`Doc.Book` は、S1 の値をすべて解決した文書の全体であり、ページ番号への参照だけが `DeferredRef` として残る。

### 見出しの番号

- 階層ごとに数える。章（階層 1）の番号は本の全体で数え、節と項の番号は、上の階層の見出しが現れるたびに 1 に戻す。
- 番号は 1 から始まり、番号を指定しない見出しは直前の番号に 1 を加える。
- `@number N` を付けた見出しは `N` になり、その後は `N` から数え続ける。
- `@nonumber` を付けた見出しは番号を持たず、番号を消費しない。
- 番号の表記は、style.toml の見出しの `number` の書式から作る。

### 番号付きリスト

番号付きリストの項目の番号も同じ規則で振る。
リストごとに 1 から始まり、`@number N` で途中から始められる。

### ラベル

- すべてのファイルのラベルを一つの表に集める。同じ名前のラベルが二つあればエラーとし、両方の位置を診断に載せる。
- `DeferredRef` のうち、章の番号と題への参照を解決する。存在しないラベルへの参照はエラーとする。
- 題には、`@toc-title` があればそれを、なければ見出しの題を使う。

### `doc` の名前空間

`DeferredExpr` を評価する。
v1 の `doc` の名前空間は次の値を持つ。

- `doc.chapters.count`：番号を持つ章の数。

値の一覧は、必要に応じて ADR を作って追加する。

### 図番号

- 図番号は章ごとに振る。章とは、番号を持つ階層 1 の見出しから、次の階層 1 の見出しまでの範囲である。
- 図の番号の書式（style.toml の `figures.number`）が章の番号を使う場合に、最初の章より前にある図は、エラーとする。

### チャネル

- 目次：番号の有無にかかわらず、`@notoc` のない見出しを集める。`@toc` は文書に一つまでとし、二つ以上あればエラーとする。`depth` を超える階層の見出しは載せない。
- 注：S0 で振った番号のまま、ファイルごとに集める。配置（ページ下か章末か）は出力の段階で決める。
- 索引：項目を読みで並べ、同じ語の出現位置をまとめる。並べ替えの規則は下に定める。
- 参考文献：引用された文献を最初に引用された順に並べ、その順で番号を振る。引用の印はその番号を表示する。

### 索引の並べ替え

JIS X 4061 を基礎とし、次の順で比較する。

1. 読みの文字の種類：記号、数字、ラテン文字、かなの順。
2. かなは、片仮名を平仮名に、小書きの文字を通常の文字に、濁点と半濁点を除いた文字に直して、五十音の順で比べる。長音符号は、直前の文字の母音として扱う。
3. 2 で等しい場合は、清音、濁音、半濁音の順、通常の文字、小書きの文字の順で比べる。
4. それでも等しい場合は、語の文字列をコードポイントの順で比べる。
5. 同じ語の出現位置は、文書の順に並べる。

ロケールに依存する照合のライブラリは使わない。
環境によって並べ替えの結果が変わり、決定性が崩れるためである。

### 並列性と順序

S1 は、すべてのファイルの S0 が終わってから一度だけ実行する。
結果の順序は、マニフェストの章の順とファイルの中の位置で決まり、S0 の完了の順には依存しない。

## 実装しないこと

- ページ番号の解決（S2）。レイアウトの ADR で扱う。
- 参照されていないラベルの検出。golem-lint の ADR で扱う。
- 索引の「〜を見よ」と三段以上の階層。
- 参考文献の書式の選択。v1 の書式は組み込みの一種類だけとする。

## テスト設計

- 見出しの番号：番号の指定、番号からの除外、節の番号が章ごとに 1 に戻ることを、複数のファイルにまたがる原稿で確かめる。
- ラベル：重複、存在しないラベルへの参照、ファイルをまたぐ参照を確かめる。
- 索引の並べ替え：清音と濁音、小書きの文字、長音符号、片仮名と平仮名、ラテン文字とかなの混在を含む項目の集合で、並べ替えの結果を golden テストで固定する。
- 図番号：章をまたぐ番号の振り直しと、最初の章より前の図のエラーを確かめる。
- `@toc` が二つあるとエラーになることを確かめる。
- ファイルの S0 を逆の順で完了させても、S1 の結果が一致することを確かめる。

## トレードオフ

索引の並べ替えを JIS X 4061 の全体ではなく、その基礎の部分に限って自前で実装する。
漢字の読みは書き手が `reading` で必ず与えるので、漢字の照合順を持つ必要はなく、かなとラテン文字の規則で足りる。

参考文献を最初に引用した順に並べると、著者名の順の文献一覧は作れない。
技術書で多い番号付きの参照に合わせた選択であり、書式の選択は後の版で扱う。

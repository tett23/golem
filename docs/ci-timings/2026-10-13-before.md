## 再現の手順

```sh
for id in 38319536503 38318301629 38317046247 38317043016 38315653147 38315656763 38315659152 38315662696 38315666030 38315669925 38315672751 38315677490 38298507275 38296480961 38279316897 38237231913 38181469810; do
  gh run view "$id" -R tett23/golem --json jobs -q .
done | sh scripts/ci/timings.sh --median
```

所要時間は、ジョブとステップの `startedAt` から `completedAt` までの秒数である。
skipped のジョブ（build が失敗した実行の `determinism`）は数えない。
そのため `determinism` の最小は、ADR 0009 の表の 0 ではなく 3 になる。
hlint の実行のステップは、途中でコマンドが変わったので二つの行に分かれている。
この二つを除くと、ADR 0009 の表にあるジョブとステップの値は、下の表と一致する。

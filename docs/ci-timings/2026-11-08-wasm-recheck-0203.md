- golem-driver を含むすべての依存と `feas-driver` が、wasm で組めた（cabal の `Completed` は 70）。
- `feas-driver info` は、`golemVersion`（`0.1.0-rc3`）、`golem explain` の文書（G03016 の節がある）、golem-layout の `englishUS`、golem-pdf の `documentId` を出した。

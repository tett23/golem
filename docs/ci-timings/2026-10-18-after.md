# CI の所要時間（2026-10-18、build ジョブの手戻りをなくした後）

[ADR 0037](../adr/0037-ci-build-job-speedup.md) の実装（[#180](https://github.com/tett23/golem/pull/180)）の後の、`.github/workflows/ci.yml` の所要時間の記録である。
実装の前の記録は [2026-10-17-before.md](2026-10-17-before.md) にある。
2026-10-18 に作り、コミットした後は変更しない。

#180 の後、[ADR 0029](../adr/0029-environment-variation-determinism-test.md) の実装（[#204](https://github.com/tett23/golem/pull/204)）が、x86-64 の build ジョブに環境を変えて出力を比べるステップ（`scripts/env-determinism/check.sh`）を足した。
二つの変更の効果を分けるため、実行を二つの組に分ける。

- 組 A：#180 のマージ（2026-10-17T08:09:41Z）から #204 のマージ（2026-10-17T17:43:58Z）までの実行。[ADR 0037](../adr/0037-ci-build-job-speedup.md) の効果だけを含む。
- 組 B：#204 の変更を含む実行。[ADR 0029](../adr/0029-environment-variation-determinism-test.md) のステップが加わっている。

組の分け方は、実行の時刻ではなく、実行のステップの名前で決めた。
組 A のすべての実行は、[ADR 0037](../adr/0037-ci-build-job-speedup.md) のステップ（`The test wrapper for every cabal command (docs/adr/0037)`）を持ち、[ADR 0029](../adr/0029-environment-variation-determinism-test.md) のステップを持たない。
組 B の二つの実行は、両方を持つ。

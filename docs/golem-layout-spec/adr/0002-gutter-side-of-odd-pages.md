# ADR 0002: 奇数ページのノドの向きの訂正

ステータス: 採択

## 文脈

ADR 0001 は「右綴じでは奇数ページのノドが左にある」と定めた。
この記述は逆である。

右綴じの本は、ページを左へめくる。
奇数ページは見開きの左側に来るので、綴じる辺はそのページの右端になる。
左綴じの本はこの鏡像で、奇数ページは見開きの右側に来て、ノドは左端になる。

ADR 0001 のテスト設計は「ノドと小口の左右が正しく入れ替わる」ことを求めている。
記述のとおりに実装すると、右綴じの本の版面がすべて小口側へ寄る。

## 実装すること

- 右綴じでは、奇数ページのノドを右、偶数ページのノドを左とする。
- 左綴じでは、奇数ページのノドを左、偶数ページのノドを右とする。
- ADR 0001 のほかの規則（版面、余白、傍注欄、柱とノンブルの位置）は、このノドの向きを使ってそのまま適用する。

## 実装しないこと

- 見開きの始まりを偶数ページにする設定（扉を左右どちらに置くかの選択）。

## テスト設計

- 右綴じの奇数ページで、版面の右端からページの右端までの距離が `gutter` に等しいことを確かめる。
- 左綴じの奇数ページで、版面の左端からページの左端までの距離が `gutter` に等しいことを確かめる。
- 傍注欄と、`outside` を指定した柱とノンブルが、どちらの綴じでも小口の側に来ることを確かめる。

## トレードオフ

ADR 0001 の記述を信じて書かれた設定ファイルはまだないので、訂正による移行の負担はない。

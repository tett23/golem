# ADR 0001: ページの幾何

ステータス: 採択→奇数ページのノドの向きは ADR 0002

## 文脈

レイアウト IR は、意味論 IR と並ぶ第二の入力であり、PDF の経路だけが読む（specifications.md）。
その値は `style.toml` に書かれ、golem-project ADR 0002 が単位を整数の sp に変換した `Style` として読み込む。
この ADR は、`Style` からページの幾何（判型、版面、余白、マスターページの要素の位置）を計算し、レイアウトエンジンが使う形にする。

版面は、日本語組版の流儀に従い、文字の大きさ、一行の字数、一ページの行数、行送り、段数で定義する。
余白は、版面をページのどこに置くかから決まる従属的な値である。

フレームのモデルは、IR がレベル 3 まで表現し、エンジンはレベル 1 から実装すると決めている。
この ADR は、レベル 0 と 1 で使う幾何だけを計算する。

## 実装すること

### 版面の大きさ

字送りは文字の大きさに等しいとし（字間を詰めない、べた組み）、次のように計算する。

- 横組み：版面の幅 = 文字の大きさ × 一行の字数、版面の高さ = 行送り × (行数 − 1) + 文字の大きさ。
- 縦組み：版面の高さ = 文字の大きさ × 一行の字数、版面の幅 = 行送り × (行数 − 1) + 文字の大きさ。
- 段組み：段の数と段間（`style.toml` に加える `column-gap`）から、段ごとの版面を計算する。

### 版面の位置と余白

- `position` の `top`（天）と `gutter`（ノド）から版面の位置を決め、地と小口の余白は残りとして計算する。
- 綴じの方向（`binding`）と、奇数ページか偶数ページかから、ノドがページの左右どちらにあるかを決める。右綴じでは奇数ページのノドが左にある。
- 版面がページからはみ出す場合（余白が負になる場合）はエラーとする。

### 行の格子

- 版面の中の各行の位置（横組みではベースライン、縦組みでは行の中心線）を、行送りの間隔で計算する。
- この格子をベースライングリッドとして、レイアウトエンジンに渡す。見開きの左右のページで行の位置がそろう。

### 傍注欄

- `style.toml` に `[sidenotes]` がある場合、版面の外の小口側に、指定した幅の傍注欄を設ける。傍注欄と版面の間は `gap` だけ空ける。
- 傍注欄の高さと上端は、版面と同じにする。
- 奇数ページと偶数ページで、傍注欄の左右は小口の側に合わせて入れ替わる。
- 版面と傍注欄の合計がページからはみ出す場合はエラーとする。
- 縦組みの版面に傍注欄を設けた場合はエラーとする。

### マスターページの要素

- 柱とノンブルの位置（`top-outside`、`bottom-outside` など）を、版面と余白からページ上の座標に変換する。`outside` は小口の側を指し、奇数ページと偶数ページで左右が入れ替わる。
- 柱の内容（`heading.1.short` など）とノンブルの書式は、レイアウトエンジンがページごとに埋める。

### 出力

```haskell
data PageGeometry = PageGeometry
  { pgPageSize   :: !(Sp, Sp)
  , pgTypeArea   :: !Rect          -- 奇数ページの版面
  , pgTypeAreaEven :: !Rect        -- 偶数ページの版面
  , pgLineGrid   :: ![Sp]          -- 行の位置
  , pgColumns    :: ![Rect]
  , pgMasters    :: !(Map MasterName MasterGeometry)
  }

pageGeometry :: Style -> Either [Diagnostic] PageGeometry
```

座標の原点は、PDF と同じくページの左下とする。

## 実装しないこと

- フレーム（レベル 2 と 3）の幾何。`style.toml` に書かれた場合のエラーは golem-project ADR 0002 で行う。
- 字送りを文字の大きさと異なる値にする設定（字間を詰めた版面）。
- 裁ち落とし（ブリード）の領域。PDF の出力で TrimBox と BleedBox を設定するときに、golem-pdf の ADR で扱う。

## テスト設計

- 横組みと縦組み、一段と二段の版面の寸法を、手で計算した値と比べる。
- 右綴じと左綴じ、奇数ページと偶数ページで、ノドと小口の左右が正しく入れ替わることを確かめる。
- 版面がページからはみ出す設定がエラーになることを確かめる。
- 行の格子の行数と間隔が、設定と一致することを確かめる。

## トレードオフ

字送りを文字の大きさに固定すると、字間を詰めた版面は作れない。
和文の書籍の本文はべた組みが標準であり、v1 ではこれに限る。
詰めた組版が必要になったら、字送りを `style.toml` に加える ADR を作る。

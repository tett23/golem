# 韻文の行と配置の資料

この資料は、韻文の行番号を検討するために、詩行と紙面上の行がどこで一致し、どこで分かれるかを記録する。
詩行は作品が区切る行、組版行は版面に置かれた行と呼ぶ。
半詩行は一つの詩行の途中で区切られた部分を指す。
以下の例から言語全体の標準的な配置を推定しない。

## 確認した例

| 言語と文化と資料 | 詩の書き方と確認できる組み方 | 行番号の対象として検討する単位 | 確認の限界 |
| --- | --- | --- | --- |
| 日本語、東園基量筆『古今和歌集』 | 所蔵館の資料紹介は「毎半葉10行、和歌1首1行書、詞書2字下げ」と記録する。和歌の1首と詞書は、紙面でも別の扱いになる。 | 1首を数える場合と組版行を数える場合を区別する。 | 一つの写本の紹介であり、ほかの歌集の配置は未確認。 |
| 日本語、芭蕉の「枯枝に」の発句短冊 | メトロポリタン美術館は、発句一つを記した短冊を公開している。紹介には句の三つの部分と署名が示される。 | 発句一つを番号の単位とする可能性を確認する。 | 公開資料だけでは句の各部分を紙面上の何行と数えるかを確定できない。 |
| 日本語、短い詩行 | W3C の JLReq は、詩などの短い行に中央、行頭、行末、均等のそろえ方を示す。 | そろえによる位置の違いを詩行数の違いとして数えない。 | JLReq の例は一つの詩集の書誌記録ではない。 |
| 英語、Emily Dickinson の詩の TEI 例 | TEI は、詩行を `l` として五つ並べ、連を表す `lg` を付けない例を示す。別の例では `lg` が詩行を連にまとめる。 | `l` を詩行、`lg` を詩行のまとまりとして区別する。 | TEI はテキスト構造の符号化であり、この例だけでは印刷時の折り返しを定めない。 |
| フランス語、TEI に収められた詩行 | TEI の例は、一つの `l` の中に `caesura` を置き、詩行の途中の切れ目を記録する。 | 詩行を一つと数え、必要に応じて行内の切れ目も記録する。 | 例の `caesura` は計量上の区切りであり、紙面の改行位置は未確認。 |
| 中国語、繁体字の TEI 例 | TEI は、複数の `caesura` が一つの `l` に入る例を示す。W3C の CLReq は、台湾の詩などに縦組みの出版例が残ると記す。 | 一つの詩行と、その内部の複数の切れ目を別々に記録する。 | TEI の例から現代の中国語の詩全般の行長やそろえ方は導けない。 |
| アラビア語、Abū Nuwās の詩集の写本群 | Hamburg の写本比較は、韻律によって通常のテキストブロックと半詩行を二列に分ける配置が混在し、一部の写本では半詩行の区切り記号も使うと報告する。韻を担う末尾を次行の中央に置く別の写本例も示す。 | 詩行、半詩行、組版行の対応を記録し、組版行の増減だけで詩行番号を増やさない。 | 調査対象の写本に関する観察であり、アラビア語の詩全般の規則ではない。 |

東園基量筆『古今和歌集』の紹介は、和歌 1 首を紙面上の 1 行に書いた例を示す。
一方、JLReq の短い詩行のそろえ方は、同じ詩行でも行内での位置を変えられることを示す。
したがって、詩行を数える手順では、詩行と組版行の区切りを別々に保持する必要がある。

TEI の英語、フランス語、中国語の例は、詩行、連、半詩行を別々に表現する。
アラビア語の写本例は、一つの詩行の部分を別の列や別の組版行に置く場合があることを示す。
これらの例では、紙面上の行数だけから作品の詩行数を復元できない。

## 確認できていないこと

和歌と俳句に一律の番号の付け方があるかは、確認できていない。
短冊、写本、現代の句集で詩行の単位と番号の表示位置が同じかも、確認できていない。
英語、フランス語、中国語、アラビア語についても、ここに挙げた資料は全ジャンルと時代を覆わない。
Golem の行番号は空でない原稿行を数える。
半詩行を二列に並べた作品や一首を単位に数える歌集は、原稿行との対応を別に確かめる必要がある。

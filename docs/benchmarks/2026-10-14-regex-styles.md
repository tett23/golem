# 正規表現スタイルのビルドの時間（[docs/adr/0015](../adr/0015-regex-styles.md)）

[docs/adr/0015](../adr/0015-regex-styles.md) の「性能」の節が求める計測の記録である。
『蟹工船』の fixture の PDF を、正規表現スタイルを足す前と後で作り、ビルドの時間を比べた。
2026-10-14 に作り、コミットした後は変更しない。

## 対象

- fixture：`modules/golem-driver/test/fixtures/kanikosen`（原稿 204238 バイト、縦組み、B6）。
- 足した設定：`style.toml` の末尾に次を足した。

```toml
[paragraph-styles.body]
regex-styles = [
  { pattern = '[0-9０-９]+', style = "bold" },
  { pattern = '(?<=「)[^」]{1,10}(?=」)', style = "italic" },
]
```

同じ設定で HTML を作ると、`<b>` が 27 箇所、`<i>` が 474 箇所に付いた。
二つの正規表現は、どちらもすべての段落に一致を求めている。

## 環境

- 計算機：Apple M1 Max、メモリ 64GB、macOS 27.0。
- golem：impl-adr-0015 のブランチのコミット `0fe641c` から `cabal build exe:golem` で作ったもの（golem 0.1.0-rc1、GHC 9.10.3、最適化は cabal の既定の `-O1`）。
- 方法：fixture を作業用のディレクトリに写し、`golem build --target pdf` を一度空で走らせた後、7 回の壁時計の時間を測った。並列化は既定のまま。

## 結果

| 回 | 足す前（秒） | 足した後（秒） |
|---|---|---|
| 1 | 1.429 | 1.465 |
| 2 | 1.436 | 1.461 |
| 3 | 1.421 | 1.471 |
| 4 | 1.439 | 1.471 |
| 5 | 1.442 | 1.461 |
| 6 | 1.421 | 1.468 |
| 7 | 1.442 | 1.471 |
| 中央値 | 1.436 | 1.468 |

足した後は、中央値で 0.032 秒（約 2.2%）遅くなった。
ADR が照合器の改良を別の ADR で検討するとした 10% には届かない。

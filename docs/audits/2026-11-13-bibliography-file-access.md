# 存在する参考文献ファイルを読めない場合の G03026

[参考文献の発生条件の監査](2026-11-13-bibliography-diagnostic-causes.md) に続き、参照先がディレクトリの場合と、通常ファイルを読む権限がない場合を調べた。
同じ tempest フィクスチャーのコピーで、manifest.toml の先頭に `bibliography = ["refs.json"]` を加えた。
macOS で Golem [ADR 0357](../adr/0357-validate-embedded-cff.md) のブランチの CLI を用いて `golem check` を実行した。

| refs.json の状態 | 終了コード | 報告された結果 |
| --- | --- | --- |
| 空のディレクトリ | 1 | G03026、参考文献のファイルがありません |
| 内容が `[]` の通常ファイル、モード 000 | 1 | G03026、参考文献のファイルがありません |
| 同じ通常ファイル、モード 600 | 0 | エラーなし |

二つのエラーはいずれも manifest.toml の 1 行 1 列に出た。
読み取り権限が原因の場合は既存ファイルのモードを変えるだけで解消した。
ディレクトリの場合は参照先に CSL-JSON の通常ファイルを用意する必要がある。

## 手元での確かめ

公開されたリリースから `gh release download v0.1.0-rc4` で 19 のファイルを取得しました。
道具は、macOS 27.0 の `shasum` 6.02 と、GitHub CLI 2.103.3 です。

### SHA256SUMS

`shasum -a 256 -c SHA256SUMS` は、載っている 17 のファイルのすべてで `OK` を出し、終了コードは 0 でした。
`gmp-6.3.0.tar.xz` は `SHA256SUMS` に載っていません。

### 来歴の証明

`gh attestation verify <ファイル> --repo tett23/golem` を、`SHA256SUMS` の 17 のファイルと `gmp-6.3.0.tar.xz` に走らせました。

| ファイル | 結果 |
|---|---|
| `golem-v0.1.0-rc4-x86_64-linux.tar.gz` | 通った |
| `golem-v0.1.0-rc4-aarch64-linux.tar.gz` | 通った |
| `golem-v0.1.0-rc4-aarch64-macos.tar.gz` | 通った |
| `golem-v0.1.0-rc4-wasm32-wasi.tar.gz` | 通った |
| `golem-manual-v0.1.0-rc4-html.tar.gz` | 通った |
| `golem-dev-manual-v0.1.0-rc4-html.tar.gz` | 通った |
| `golem-plugins-licenses-v0.1.0-rc4.tar.gz` | 通った |
| `golem-manual-v0.1.0-rc4.pdf`、`golem-dev-manual-v0.1.0-rc4.pdf` | 証明がない（HTTP 404） |
| 見本のプラグインの 8 つの `.wasm` | 証明がない（HTTP 404） |
| `gmp-6.3.0.tar.xz` | 証明がない（HTTP 404） |

通った 7 つは、どれも証明の内容が次のとおりでした。

- **ソースのコミット**：`40eb98ce0abc39c8b11db3c09389b98e8e2efe05`（タグのコミットと一致）
- **ソースの参照**：`refs/tags/v0.1.0-rc4`
- **署名したワークフロー**：`https://github.com/tett23/golem/.github/workflows/release.yml@refs/tags/v0.1.0-rc4`
- **実行**：https://github.com/tett23/golem/actions/runs/42529741450/attempts/1

証明がない 11 のファイルは、`release.yml` の `actions/attest-build-provenance` の `subject-path` が `dist/golem-*.tar.gz` だけを指すためで、今の仕組みのとおりです。

### wasm のアーカイブの中身

取得した `golem-v0.1.0-rc4-wasm32-wasi.tar.gz` に、`SHA256SUMS` の行を `.sha256` として添えて `scripts/release/check-wasm-archive.sh` を走らせ、終了コード 0 で通りました。
`THIRD_PARTY_LICENSES/` の最上位には `freetype`、`ghc`、`gmp`、`harfbuzz`、`haskell`、`hyph-en-us`、`wasi-sdk` と、`LICENSE-golem`、`README` があります。

## 見つけた問題

- **リリースノート**：ジョブ `notes` の Release notes のステップが約 3 秒で終わり、ノートは `notes.sh` の一覧のままでした。一覧の `## Unsorted` は空でした。`notes.sh` が GitHub の形のマージのコミット（`Merge pull request #N from …`）を拾わなかったためです。ノートは人が手で書いて公開しました。AI が失敗した理由はジョブの要約にしか書かれず、API では読めないので、確かめられていません。直しは [#753](https://github.com/tett23/golem/pull/753) で行います。
- **証明のないファイル**：リリースノートの「Verifying the downloads」は、来歴の証明を「Each archive」について書いています。PDF の二つのマニュアルと見本のプラグインの `.wasm` はアーカイブではなく、証明もありません。これらは `SHA256SUMS` だけで確かめられます。

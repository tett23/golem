# ADR 0049: 文字クラスと分割禁止の字の組を JLReq の文字クラスに合わせる

ステータス: 採択（未実装）

## 文脈

### ロードマップの項目

[docs/roadmap.md](../../roadmap.md) の v1.0.0 の「行分割と禁則」に、次の項目がある。

- **分離禁止文字と禁則の見直し**：分離禁止文字と禁則の文字の分類を、JLReq の文字クラスに照らして見直す。U+2015 の `――` は v0.1.0-rc3 で分離禁止文字に加えた（[golem-layout ADR 0016](0016-ellipsis-before-full-stop.md)）ので、この項目はそれ以外の文字を扱う。

### 今の文字クラス

和文の組版は、JLReq の文字クラスのうち 15 の分類を使う（[golem-layout ADR 0002](0002-japanese-composition.md)、[`CharClass`](https://github.com/tett23/golem/blob/9608953da3806ab63cb82abf091bfc1e04b76533/modules/golem-layout/src/Golem/Layout/CharClass.hs#L23-L39)）。
始め括弧類から小書きの仮名までの十の分類は、字の一覧で決める（[`openings` から `smallKana`](https://github.com/tett23/golem/blob/9608953da3806ab63cb82abf091bfc1e04b76533/modules/golem-layout/src/Golem/Layout/CharClass.hs#L51-L61)）。
一覧にない字は、ASCII と U+00A0 から U+024F とギリシア文字とキリル文字なら欧文（cl-27）、ほかは漢字等（cl-19）になる（[`charClass`](https://github.com/tett23/golem/blob/9608953da3806ab63cb82abf091bfc1e04b76533/modules/golem-layout/src/Golem/Layout/CharClass.hs#L63-L79)）。
行頭禁則、行末禁則、分離禁止は、この分類で決める（[`lineStartProhibited`](https://github.com/tett23/golem/blob/9608953da3806ab63cb82abf091bfc1e04b76533/modules/golem-layout/src/Golem/Layout/Japanese.hs#L81-L95)、[`normalize` の `between`](https://github.com/tett23/golem/blob/9608953da3806ab63cb82abf091bfc1e04b76533/modules/golem-layout/src/Golem/Layout/Japanese.hs#L1722-L1755)）。

### JLReq の一覧との比べ

JLReq の付録の「文字クラス一覧」と、Golem の一覧を、字ごとに比べた（w3c/jlreq の `index.html` から符号位置を抜き出した。2026-11-10）。
JLReq は ASCII の括弧と句読点を挙げ、多くの処理系が全角の互換文字を使うと注記している。
Golem の一覧は全角の互換文字を持つので、その違いは食い違いに数えない。

| 分類 | JLReq にあり Golem にない字 | Golem にあり JLReq にない字 |
| --- | --- | --- |
| 始め括弧類（cl-01） | U+2985 ⦅ | U+FF5F ｟（全角の互換文字） |
| 終わり括弧類（cl-02） | U+2986 ⦆ | U+FF60 ｠（全角の互換文字） |
| ハイフン類（cl-03） | なし | U+2011 ‑（改行しないハイフン） |
| 分離禁止文字（cl-08） | なし | U+2015 HORIZONTAL BAR（[golem-layout ADR 0016](0016-ellipsis-before-full-stop.md)） |
| 区切り約物から小書きの仮名（cl-04 から cl-11） | なし | なし |
| 前置省略記号（cl-12） | 分類がない | 分類がない |
| 後置省略記号（cl-13） | 分類がない | 分類がない |
| 連数字中の文字（cl-24） | 分類がない | 分類がない |

行頭禁則の範囲（cl-02 から cl-07、cl-09、cl-10、cl-11）、行末禁則（cl-01）、`kinsoku = "loose"` で長音記号と小書きの仮名を外すこと（JLReq の 3.1.7 の注）は、JLReq と一致する。

### 一覧の外の字

JLReq の一覧にない字にも、日本語の原稿でよく使うものがある。

- **U+301E 〞**：横組みの〝〞の閉じのほうである。Unicode の一般カテゴリは Pe（閉じ括弧）だが、JLReq は U+301F 〟だけを終わり括弧類に挙げる。今は漢字等になり、行頭に来うる。
- **U+FF5E ～**：Windows の入力で「から」の波ダッシュとして入る字である。今は漢字等になり、U+301C 〜と違って行頭に来うる。
- **U+2E3A ⸺ と U+2E3B ⸻**：二倍と三倍の長さのダッシュである。今は漢字等になる。
- **半角形（U+FF61 から U+FF9F）**：半角の句読点、括弧、片仮名である。今はどれも漢字等になる。

### 数と省略記号と連数字

JLReq の 3.1.10（分割禁止）は、分離禁止文字の連続のほかに、次の字間を分割禁止とする。

1. 連続するアラビア数字の字間。ただし、縦組みでアラビア数字を正しい向きで一字ずつ並べた場合は分割してよい。
2. 前置省略記号（cl-12。`¥`、`$` など）と、その後ろのアラビア数字か漢数字のあいだ。
3. アラビア数字か漢数字と、その後ろの後置省略記号（cl-13。`%`、`‰` など）のあいだ。

Golem は、ASCII の数字と記号を欧文の字として一つの語の箱にするので、`100%` と `$100` は今も分けない。
全角の数字（U+FF10 から U+FF19）と、ASCII にない省略記号（`％`、`￥`、`€`、`℃`、`′` など）は漢字等になる。
そのため、`１２３` は字のあいだで、`100％` は `100` と `％` のあいだで、`￥１００` は `￥` の後で改行しうる。
`100％` では、欧文の `100` と漢字等の `％` のあいだに和欧間の空き（四分）も入る。

JLReq の 3.1.10 は、`%` の前での分割を認める考え方もあると注記し、`50パーセント` の `0` と `パ` のあいだは分割してよいとする。
この ADR は、注記ではなく本文の規定に従う。

JLReq は、分割禁止の字間を、行の調整で空ける箇所からも外す（3.1 の「行の調整処理で字間を空ける処理に使用しない箇所」）。
Golem は、漢字等どうしのあいだに 1/10 em の伸びを置くので、`１２３` の字のあいだも伸びうる。

InDesign の文字の分類と禁則の文字の一覧は、確かめていない。
この ADR は、JLReq の記述に従う。

## 実装すること

### 1. 一覧に足す字

`Golem.Layout.CharClass` の一覧に、次の字を足す。

| 字 | 足す分類 | 根拠 |
| --- | --- | --- |
| U+2985 ⦅ | 始め括弧類 | JLReq の cl-01 |
| U+2986 ⦆ | 終わり括弧類 | JLReq の cl-02 |
| U+301E 〞 | 終わり括弧類 | Unicode の Pe、〝との対（「メンテナーが決めること」の 2） |
| U+FF5E ～ | ハイフン類 | 〜（U+301C）の全角の互換文字として使われる（「メンテナーが決めること」の 3） |
| U+2E3A ⸺、U+2E3B ⸻ | 分離禁止文字 | U+2015 と同じ扱い（「メンテナーが決めること」の 4） |

`dualCharacters` には足さない。
足した字は、行頭禁則、行末禁則、分離禁止、アキ量のセットの空きを、その分類のとおりに受ける。

### 2. 数の字と省略記号の述語

`Golem.Layout.CharClass` に、次の四つの述語を足す。
`CharClass` の値は足さず、アキ量のセットの分類の名前も変えない（「メンテナーが決めること」の 6）。

- **`isArabicDigit`**：U+0030 から U+0039 と、U+FF10 から U+FF19。
- **`isNumeral`**：`isArabicDigit` の字と、漢数字（`〇一二三四五六七八九十百千万億兆`）。
- **`isPrefixedAbbreviation`**：JLReq の cl-12 の六字（U+00A5、U+0024、U+00A3、U+0023、U+20AC、U+2116）と、その全角の互換文字（U+FFE5、U+FF04、U+FFE1、U+FF03）。
- **`isPostfixedAbbreviation`**：JLReq の cl-13 の 32 字（U+00B0、U+2032、U+2033、U+2103、U+00A2、U+0025、U+2030、U+33CB、U+2113、U+3303、U+330D、U+3314、U+3318、U+3322、U+3323、U+3326、U+3327、U+332B、U+3336、U+333B、U+3349、U+334A、U+334D、U+3351、U+3357、U+338E、U+338F、U+339C、U+339D、U+339E、U+33A1、U+33C4）と、その全角の互換文字（U+FF05、U+FFE0）。

### 3. 分割禁止の字の組

`normalize` の `between` が分割を禁じる条件に、隣り合う二つの箱の、前の箱の最後の字 a と後の箱の最初の字 b の組として、次の三つを足す。

- **連数字**：a と b がともに `isArabicDigit` で、横組みである。縦組み（`ceVertical`）では足さない。
- **前置省略記号**：a が `isPrefixedAbbreviation` で、b が `isNumeral` である。
- **後置省略記号**：a が `isNumeral` で、b が `isPostfixedAbbreviation` である。

分離禁止文字の連続と同じく、隣り合う字にだけ当て、語間の空白とコードの空白を挟む組には当てない（[golem-layout ADR 0028](0028-kinsoku-across-spaces-and-explicit-hyphens.md) の行頭禁則と行末禁則の扱いとは違う）。
禁じた位置の空きのグルーの幅と伸び縮みは変えず、罰点 10000 を前に置くだけとする。
本文の中のコード（`lkCode`）と URL（`lkUrl`）の箱どうしのあいだには当てない（「メンテナーが決めること」の 7）。
ルビの箱の端の字は、今の禁則と同じく字として見ない。

### 4. 文書

- [docs/specifications.md](../../specifications.md) の「行分割」の節に、足した字と分類、三つの分割禁止の組、縦組みの連数字の扱いを書き、この ADR へのリンクを付ける。
- [docs/roadmap.md](../../roadmap.md) の v1.0.0 の「行分割と禁則」から「**分離禁止文字と禁則の見直し**」の行を消す。
- 「メンテナーが決めること」の 5 のとおり、分割禁止の字間を空けない規則を扱うなら、ロードマップの v1.0.0 の「行分割と禁則」に項目を足す。
- [TeX と InDesign との差異](../../differences-from-tex-and-indesign.md) に、InDesign の一覧と比べていないことを書く。

### 5. 出力の変化

全角の数字、省略記号、足した字を含む段落だけが変わる。
実装のプルリクエストで、二つのマニュアル、golden、complex fixture、kanikosen の原稿に、足した字と三つの組がいくつあるかを数え、PDF の変わったページを説明に書く。

## 実装しないこと

- **半角形の字の分類**：半角の句読点と括弧は、全角の字と字幅が違い、アキ量のセットの空きの意味が変わる。使う原稿を見ておらず、分類を決める材料がない（「メンテナーが決めること」の 8）。
- **cl-12、cl-13、cl-24 を `CharClass` の値にすること**：アキ量のセットの規則の名前（`akiPositions`）と、既定のセットの空きを決め直すことになる。この ADR は分割の可否だけを変える。
- **分割禁止の字間の伸びを外すこと**：「メンテナーが決めること」の 5。
- **単位記号中の文字（cl-25）**：`km`、`kg` は ASCII の字なので、今も一つの語の箱であり、字のあいだで分けない。数との間の空白での改行は、JLReq の 3.1.10 のとおり許す。
- **数と、その後の和字の単位や助数詞（`100円`、`3人`）**：JLReq は分割禁止としない。[ADR 0275](../../adr/0275-keep-numbers-with-the-units-after-them.md) が扱う。
- **HTML と EPUB**：ブラウザーの改行は UAX #14 による。足した字と組でブラウザーがどう分けるかは確かめておらず、この ADR では変えない。

## 不変条件

「隣り合う字の組」は、項目の並びで隣り合う二つの箱（あいだに罰点とアキのグルーだけがあり、語間の空白もコードの空白もない）の、前の箱の最後の字 a と後の箱の最初の字 b とする。
a と b は、結合文字を除いた字であり、ルビの箱の端では字を持たない。
「組の位置」は、二つの箱のあいだとする。

- **B1 足した字の分類**：1 の表のどの字の `charClass` も、表の分類である。表にない字の `charClass` は、この ADR の前と同じである。
- **B2 連数字**：横組みで、a と b がともに `isArabicDigit` の組の位置には、分割の候補がない。縦組みでは、その位置の項目はこの ADR の前と同じである。
- **B3 前置省略記号**：a が `isPrefixedAbbreviation` で b が `isNumeral` の組の位置には、分割の候補がない。
- **B4 後置省略記号**：a が `isNumeral` で b が `isPostfixedAbbreviation` の組の位置には、分割の候補がない。
- **B5 空白を挟む組**：語間の空白かコードの空白を挟んだ a と b には、B2 から B4 を当てない。その空白の項目は、この ADR の前と同じである。
- **B6 候補を消すだけ**：B2 から B4 で候補を消した入力の項目の並びは、この ADR の前の項目の並びから、組の位置の候補を無限の罰点に替えたもの（グルーの候補は前に罰点 10000 を置いたもの）に等しい。箱、グルーの幅と伸び縮みは変わらない。
- **B7 ほかの入力**：1 の表の字も、`isNumeral`、`isPrefixedAbbreviation`、`isPostfixedAbbreviation` の字も含まない段落の項目は、この ADR の前と同じである。
- **B8 コードと URL**：`lkCode` か `lkUrl` の箱どうしのあいだの項目は、この ADR の前と同じである。

[ADR 0209](../../adr/0209-line-breaking-invariants-by-exhaustive-small-inputs.md) の L1 から L13 との関わりは次のとおりである。

- L2 と L3 は、足した字の分類で判定するので、述語は分類の一覧を引くだけで変わらない。
- L4（分離禁止）は、分離禁止文字の連続に、B2 から B4 の組を足して読む。B2 から B4 の組の位置で分けた行は、L5 の例外（行長に収まる分割がない行）に限る。
- L5 から L13 は、候補が減るだけなので、そのまま成り立つ。

[golem-layout ADR 0034](0034-line-breaks-between-japanese-characters-in-inline-code.md) の C1 から C8 と [golem-layout ADR 0045](0045-break-inline-code-after-hyphens-and-full-stops-to-avoid-loose-lines.md) の J1 から J7 は、B8 によりそのまま成り立つ。

境界の入力：

| 量 | 調べる値 |
| --- | --- |
| 数の字 | ASCII の `1`、全角の `１`、漢数字の `一`、混ざった並び（`1１`、`１1`） |
| 数の並びの長さ | 1、2、行の幅、行の幅より一つ多い |
| 省略記号 | ASCII（`%`、`$`）、ASCII にない字（`％`、`￥`、`℃`、`′`、`㎏`） |
| 組の形 | 数の前、数の後、両側（`￥１００％`）、空白を挟む（`１００ ％`） |
| 足した字 | `⦅`、`⦆`、`〞`、`～`、`⸺`、`⸻` を行頭、行末、行の中に置く |
| 組方向 | 横組み、縦組み |
| 禁則の強さ | `strict`、`loose` |
| 文字スタイル | なし、`code`、`url` |

## テスト設計

テストを先に書き、今の実装で失敗することを確かめてから実装する。
テストの名前には、B1 から B8 の番号を入れる。

- **B1**：1 の表の六字の `charClass` が表の分類になること。今は漢字等なので失敗する。`charClass` の結果を、U+0000 から U+FFFF と U+1B000 から U+1B16F のすべての字について、この ADR の前の値と比べ、違うのは表の字だけであること。
- **B2**：横組みの 2 字の行に `１２３` を組み、`１２` で分けないこと（行長に収まる分割がないので、はみ出す行になる）。3 字の行では一行になること。縦組みでは 2 字の行で分けること。今は横組みでも分けるので失敗する。
- **B3**：`あ￥１００` を `￥` の後で分けない行の幅で組み、`￥` と `１` のあいだに候補がないこと。`€100` と `№1` も同じであること。
- **B4**：`100％`、`三〇％`、`１０℃`、`5′` のそれぞれの数と記号のあいだに候補がないこと。今は候補があるので失敗する。
- **B5**：`１００ ％` の空白の項目が、この ADR の前と同じであること。
- **B6**：B2 から B4 の入力の項目を、この ADR の前の実装の項目と比べ、違いが組の位置の罰点だけであること。
- **B7**：[ADR 0209](../../adr/0209-line-breaking-invariants-by-exhaustive-small-inputs.md) の 24 の部品の列挙の入力のすべてで、項目がこの ADR の前と同じであること。
- **B8**：`[code: １２３]` と `[code: 100％]` の項目が、この ADR の前と同じであること。
- **列挙**：24 の部品の列挙に `１`、`％`、`￥` の三つを足し、L1 から L13 と B2 から B6 がすべての入力で成り立つことを確かめる。L4 の述語に、B2 から B4 の組を足す。プルリクエストの段の時間が範囲ごとの予算 10 秒（[ADR 0208](../../adr/0208-widen-lightweight-formal-methods.md) の 4）を超えるなら、足した部品は毎晩のジョブの段だけで足す。

## トレードオフ

分割の候補が減るので、全角の数字の多い段落は、行の調整の余地が減る。
`２０２６年１１月１０日` のような日付は、横組みでは数字の並びで分けられず、年、月、日の字の後でだけ分ける。
狭い表のセルでは、長い数字の並びが行長を超え、はみ出す行になりうる。
半角の数字（`2026年`）では今も分けないので、全角の数字を半角と同じ扱いにそろえることになる。

JLReq の注記にある、`%` の前で分ける考え方は採らない。
`100％` を分けない本と分ける本の両方に応える設定は、この ADR では足さない。
書き手が分けたい箇所は、今は手で分ける手段がない。

分割を禁じても空きの伸びは残すので、JLReq の「分割禁止の字間は空けない」とは一致しない。
空いた行では、`１２３` の字のあいだが他の字間と同じだけ空く。

## メンテナーが決めること

1. **U+2985 ⦅ と U+2986 ⦆**：推奨は、括弧類に足すことである。JLReq の cl-01 と cl-02 にある。
   - 退けた案は、全角の互換文字（｟｠）だけで足りるとして足さないことである。原稿に ⦅⦆ を書いた本で、括弧の禁則が当たらない。
2. **U+301E 〞**：推奨は、終わり括弧類に足すことである。横組みで〝と対に使い、Unicode も閉じ括弧とする。
   - 退けた案は、JLReq の一覧にないので漢字等のままにすることである。〞が行頭に来る。
3. **U+FF5E ～**：推奨は、ハイフン類に足すことである。〜の代わりに入力される字であり、行頭禁則を同じに当てるのが書き手の期待に合う。
   - 退けた案は、漢字等のままにすることである。同じ「から」の字が、入力の環境によって行頭に来たり来なかったりする。
4. **U+2E3A ⸺ と U+2E3B ⸻**：推奨は、分離禁止文字に足すことである。U+2015 を足した [golem-layout ADR 0016](0016-ellipsis-before-full-stop.md) と同じ理由で、ダッシュの連続を分けない。
   - 退けた案は、JLReq の一覧にないので漢字等のままにすることである。
5. **分割禁止の字間の伸び**：推奨は、この ADR では外さず、ロードマップの v1.0.0 の「行分割と禁則」に「行の調整で空けない字間」の項目を足すことである。伸びを外すには、アキ量のセットの規則に分割禁止の組を表す方法が要り、`style.toml` のアキ量のセットの書き方も変わりうる。
   - 退けた案は、この ADR で三つの組の位置のグルーを捨てることである。アキ量のセットで決まる空きを、セットの外の規則で上書きすることになる。
6. **新しい分類を `CharClass` の値にするか**：推奨は、述語にとどめることである。アキ量のセットの分類の名前と既定の空きを変えずに済む。
   - 退けた案は、cl-12、cl-13、cl-24 を `CharClass` の値にすることである。アキ量のセットで空きを決められるようになるが、`style.toml` の規則の名前が増え、既定のセットの空きを JLReq の表から決め直すことになる。
7. **本文の中のコードに当てるか**：推奨は、当てないことである。コードの字の並びは書き手の書いたとおりに読ませるもので、和文の字のあいだの改行は [golem-layout ADR 0034](0034-line-breaks-between-japanese-characters-in-inline-code.md) の規則で決める。
   - 退けた案は、コードにも当てることである。0034 の C1 の「禁則」の範囲が変わり、コードの列挙の述語を書き直すことになる。
8. **半角形の字**：推奨は、この ADR では分類しないことである。
   - 退けた案は、半角の句読点と括弧を全角の字と同じ分類に足すことである。字幅が半分の字にアキ量のセットの二分の空きを足すと、全角の字より空きが目立つ。

## 決めたことの記録

2026-11-10 に、tett23 がすべて推奨のとおりに決めた。

1. U+2985 ⦅ と U+2986 ⦆ は、推奨のとおり始め括弧類と終わり括弧類に足す。
2. U+301E 〞は、推奨のとおり終わり括弧類に足す。
3. U+FF5E ～は、推奨のとおりハイフン類に足す。
4. U+2E3A ⸺ と U+2E3B ⸻ は、推奨のとおり分離禁止文字に足す。
5. 分割禁止の字間の伸びは、推奨のとおりこの ADR では外さず、ロードマップの v1.0.0 の「行分割と禁則」に「行の調整で空けない字間」の項目を足す。項目は、この ADR の実装のプルリクエストで足す（「実装すること」の 4）。
6. 新しい分類は、推奨のとおり `CharClass` の値にせず、述語にとどめる。
7. 本文の中のコードには、推奨のとおり当てない。
8. 半角形の字は、推奨のとおりこの ADR では分類しない。

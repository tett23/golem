# ADR 0001: Knuth-Plass による行分割

ステータス: 採択

## 文脈

段落の行分割は、段落の全体を見て最適な分割を選ぶ Knuth-Plass の方式で行う。
この方式は、段落を箱（box）、伸縮する空き（glue）、分割の候補とその罰則（penalty）の並びに変換し、各行の伸び縮みの度合いから計算した罰点（demerits）の合計が最小になる分割を選ぶ。
箱、空き、罰則の並びは、欧文のハイフネーションと語間の伸縮と、和文の禁則と字間の空きを、同じ表現で扱える。
和文の規則をこの並びにどう写すかは ADR 0002 で扱い、この ADR は並びの型と、行分割のアルゴリズムを定める。

図版の回り込みのような除外領域があると、行ごとに使える幅が変わる。
そのため、目標の行長は定数ではなく、行の番号の関数 L*(i) として扱う。
決定性の規則から、計算はすべて整数で行う。

## 実装すること

### 並びの型

```haskell
data Item
  = Box     { itemWidth :: !Sp, itemContent :: !BoxContent }
  | Glue    { itemWidth :: !Sp, itemStretch :: !Sp, itemShrink :: !Sp }
  | Penalty { itemWidth :: !Sp, itemPenalty :: !Int, itemFlagged :: !Bool }
```

- 分割できる位置は、箱の直後の空きと、罰則が無限大でない罰則である。
- 段落の終わりには、無限に伸びる空きと、罰則が負の無限大の罰則を置く。
- `itemPenalty` の無限大は 10000、負の無限大は −10000 とする（TeX と同じ）。

### アルゴリズム

- 目標の行長を `lineWidth :: Int -> Sp` として受け取る。
- 調整比は、伸ばす場合は（目標の行長 − 自然な幅）/ 伸びの合計、縮める場合は（目標の行長 − 自然な幅）/ 縮みの合計とする。縮みの限界（調整比が −1 未満）を超える行は採らない。
- 不良度（badness）は TeX の整数の近似式で計算し、10000 を上限とする。浮動小数点数は使わない。
- 罰点は、行の罰点の定数、不良度、罰則から TeX と同じ式で計算し、ハイフンで終わる行が続く場合と、隣り合う行の伸縮の度合い（適合度の分類）が二段以上離れる場合に罰点を加える。
- 動的計画法で、各分割の候補に至る罰点の最小の経路を、適合度の分類ごとに保持する。
- 罰点が等しい候補が複数ある場合は、より前の位置で分割する候補を選ぶ。選択の規則を固定して、結果を一つに定めるためである。

### 許容度と複数回の試行

TeX と同じく、段階を分けて試す。

1. ハイフネーションの候補を使わず、許容度（`pretolerance`）の範囲で分割を探す。
2. 見つからなければ、ハイフネーションの候補を加え、許容度（`tolerance`）の範囲で探す。
3. それでも見つからなければ、緊急の伸び（`emergency-stretch`）を各行に加えて探す。
4. それでも見つからなければ、はみ出す行を許して分割し、警告の診断（`G07xx`）を出す。

各段階の値は `style.toml` の `[composition]` に加える。

### ハイフネーション

欧文の語のハイフネーションの候補は、Liang のパターンで求める。
パターンのファイルは言語ごとに Golem に同梱し、版を固定する。
v1 で同梱するのは英語（米国）のパターンだけとする。

## 実装しないこと

- 和文の規則（禁則、字間の空き、ルビ、圏点）を並びに写すこと。ADR 0002 で扱う。
- 改ページ。ADR 0003 で扱う。
- 文字の版面外への突き出しと、グリフの幅の微小な伸縮（hz）。行分割の品質を上げる拡張として、後の ADR で扱う。
- 英語以外の欧文のハイフネーションのパターン。

## テスト設計

- Knuth と Plass の論文の例の段落で、論文と同じ分割が得られることを確かめる。
- 行長を行ごとに変えた段落で、各行がその行の目標の行長に収まることを確かめる。
- 罰点が等しい候補が複数ある入力で、常に前の位置の候補が選ばれることを確かめる。
- 分割できない長さの語を含む狭い行で、4 番目の段階まで進み、警告が出ることを確かめる。
- 任意の並びと行長で、結果が二つのアーキテクチャで一致することを確かめる。

## トレードオフ

不良度を TeX の整数の近似式で計算すると、厳密な三乗の式とは結果がわずかに異なる。
浮動小数点数による計算は決定性を崩しうるので、近似式を選ぶ。
TeX が長年使ってきた式であり、組版の品質に実用上の差はない。

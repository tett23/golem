# ADR 0006: 傍注の配置

ステータス: 採択

## 文脈

傍注は、本文の脇の傍注欄に置く短い注である（specifications.md）。
傍注欄は版面の外の小口側に設け（golem-layout-spec ADR 0001）、本文の行の長さには影響しない。
そのため、傍注の配置は行分割とは独立に、ページへの配置（ADR 0003）で本文の行の位置が決まった後に行える。
この ADR は、傍注欄の中で傍注を並べる規則を定める。

## 実装すること

### 傍注の組版

- 傍注の本文は、`style.toml` の `[sidenotes]` のフォントと文字の大きさで、傍注欄の幅を行長として組む。行分割には ADR 0001 と ADR 0002 の規則をそのまま使う。
- 本文側の印は、`marker` の設定に従い、番号、記号（※）、なしのいずれかとする。印を付ける場合は、傍注の本文の先頭にも同じ印を付ける。

### 傍注欄での配置

ページごとに、そのページの傍注を本文での出現の順に並べ、次の手順で縦の位置を決める。

1. 各傍注の上端の希望の位置を、注の印を含む行の上端とする。
2. 上から順に置き、前の傍注の下端に重なる場合は、前の傍注の下端まで下へずらす。傍注の間には `style.toml` の行送りの半分の空きを置く。
3. 最後の傍注の下端が傍注欄の下端を越える場合は、下から順に、はみ出した分だけ前の傍注を上へ詰める。ただし、各傍注の上端は傍注欄の上端より上に出さず、順序を入れ替えない。
4. 詰め直してもなお収まらない場合は、収まらない傍注の位置を示すコンパイルエラーとする。

### ページとの関係

- 傍注はページをまたがない。一つの傍注の本文が傍注欄の高さを超える場合もエラーとする。
- 傍注の量によって本文の改ページは変えない。本文の配置は傍注に依存しないので、傍注の配置で S2 の繰り返しが増えることはない。

### 書字方向

縦組みの段落の中の傍注は、コンパイルエラーとする。

## 実装しないこと

- 縦組みの傍注。
- 収まらない傍注を自動的に脚注に回す処理。
- 傍注欄に図版を置く機能。

## テスト設計

- 重ならない傍注が、印を含む行と同じ高さに置かれることを確かめる。
- 近接した傍注が下へずらされ、順序が保たれることを確かめる。
- ページの下端近くの傍注が、前の傍注を上へ詰めて収まることを確かめる。
- 詰めても収まらない量の傍注で、エラーが出ることを確かめる。
- 傍注の有無で、本文の行と改ページが変わらないことを確かめる。
- 縦組みの段落の中の傍注がエラーになることを確かめる。

## トレードオフ

収まらない傍注をエラーにするので、傍注の多いページでは書き手が原稿を直す必要がある。
脚注への自動の振り替えは、書き手の意図しない形に注を変えることになるので行わない。
エラーは、その注を脚注にすべきだと書き手に知らせる役割を持つ。

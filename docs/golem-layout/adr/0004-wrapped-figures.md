# ADR 0004: 回り込みのある図版

ステータス: 採択

## 文脈

v1 のレイアウトエンジンは、フレームのレベル 1（単一のフローと除外領域）まで実装すると決めている（specifications.md）。
除外領域の代表は、本文を脇に回り込ませる図版である。
ADR 0001 の行分割は、目標の行長を行の番号の関数 L*(i) として受け取るので、除外領域によって行ごとに使える長さが変わる段落を組める。
この ADR は、`@figure` の `wrap` の指定（docs/markup.md）から除外領域を作り、行分割と改ページにつなぐ手順を定める。

## 実装すること

### 除外領域の作り方

- `wrap` を指定した図版は、版面の行の始まりの側（`start`）か終わりの側（`end`）に寄せて置く。
- 図版の大きさ（`width` と、画像の縦横比から決まる長さ）にキャプションと `style.toml` の `figures.wrap-gap` を加えた矩形を、除外領域とする。
- 除外領域の行の方向の範囲を、行の格子（golem-layout-spec ADR 0001）の行の単位に切り上げる。回り込みの終わりで、本文が行の格子からずれないようにするためである。

### 行分割とのつなぎ方

- 図版の後に続く段落を組むとき、除外領域にかかる行の目標の行長を、版面の行長から除外領域の幅を引いた値にする。
- 除外領域を過ぎた行は、版面の行長に戻す。
- 段落の途中で除外領域が終わる場合も、L*(i) の切り替わりとして一つの段落のまま組む。

### 改ページとのつなぎ方

- 図版を置こうとした位置で、除外領域がページの残りに収まらない場合は、図版を次のページの先頭に送り、ADR 0003 の図版の規則に従う。
- 除外領域がページの終わりを越えることは許さない。

### 媒体ごとの扱い

回り込みは PDF でだけ行う。
EPUB と HTML では、`wrap` の指定を無視し、回り込ませない図版として出力する。
リフローする媒体では、画面の幅によって回り込みの見え方が大きく変わり、読みにくくなる場合があるためである。

## 実装しないこと

- 矩形以外の形の除外領域（画像の輪郭に沿った回り込み）。
- 傍注。傍注も除外領域として表せるが、傍注の記法がまだないので、記法を決める段階で ADR を作る。
- 段組みをまたぐ除外領域。

## テスト設計

- 横組みと縦組みで、`start` と `end` の回り込みの組版の結果を golden テストで固定する。
- 除外領域にかかる行が、除外領域の幅だけ短く組まれ、過ぎた行が版面の行長に戻ることを確かめる。
- 回り込みの終わりの後の行が、行の格子の位置にそろうことを確かめる。
- ページの残りに収まらない回り込みの図版が、次のページに送られることを確かめる。
- EPUB と HTML の出力で、`wrap` が無視されることを確かめる。

## トレードオフ

除外領域の範囲を行の単位に切り上げるので、図版の下（縦組みでは左）に、最大で一行分未満の余分な空きができる。
行の格子のそろいを保つことを優先する。

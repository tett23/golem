# ADR 0002: 日本語組版の規則

ステータス: 採択→ルビの配置は[ADR 0009](0009-ruby-placement.md)、異体字セレクタの箱は [golem-pdf ADR 0006](../../golem-pdf/adr/0006-cid-system-info.md)、縦書き用の字形がない文字の回転は [golem-driver ADR 0015](../../golem-driver/adr/0015-vertical-dashes.md)、字間の空きの量は [docs/adr/0019](../../adr/0019-aki-settings.md)

## 文脈

和文の組版は、日本語組版処理の要件（JLReq）に従う（specifications.md）。
行分割は [ADR 0001](0001-knuth-plass-line-breaking.md) の Knuth-Plass の方式で行い、和文の規則はその入力である箱、空き、罰則の並びに写す。
禁則は罰則で、字間の空きの伸縮は空きで表せる。
この ADR は、文字の分類、禁則、空きの規則、ルビ、圏点、縦中横、和欧の混植を、並びとシェイピングにどう写すかを定める。

## 実装すること

### 文字の分類

- JLReq の文字クラス（始め括弧類、終わり括弧類、句点類、読点類、中点類、分離禁止文字、繰返し記号、長音記号、小書きの仮名、漢字等、平仮名、片仮名、欧文の文字など）に、各文字を分類する。
- 分類の表は Golem に持ち、Unicode の版を固定する。

### 禁則

- 行頭禁則（終わり括弧類、句読点、中点類、小書きの仮名など）と行末禁則（始め括弧類）を、分割の候補の罰則で表す。禁則に当たる位置には分割の候補を置かない。
- 分離禁止文字（「──」「……」など）の間には分割の候補を置かない。
- 禁則の強さ（`kinsoku = "strict"` と `"loose"`）で、小書きの仮名と長音記号を行頭禁則に含めるかを切り替える。

### 字間の空き

- 約物（括弧、句読点、中点）は、JLReq の規則に従い、字面の外側の空きを空きの項目として持たせる。行中では、隣り合う約物の空きを JLReq の表に従って詰める。
- 行の長さを調整するときは、JLReq の優先順位（約物の空きを先に詰め、次に和欧間の空き、最後に字間）に従うよう、空きの伸縮の量を設定する。
- 和文と欧文の間には、四分の空きを伸縮する空きとして置く。
- ぶら下げ組（`hanging-punctuation = true`）では、行末の句読点を版面の外に出すことを許す。

### ルビ

- ルビは、ルビの文字の大きさを親文字の半分とし、親文字の上（縦組みでは右）に置く。
- `position = "mono-center"` では、モノルビを親文字の中央にそろえ、グループルビを親文字の全体に均等に配置する。
- ルビが親文字より長い場合は、`overhang` の量まで隣の仮名にかけることを許し、それでも収まらない場合は親文字の字間を空ける。
- ルビ付きの親文字は一つの箱とし、モノルビの親文字の間でだけ分割を許す。

### 圏点

圏点は親文字ごとに置き、形は `style.toml` の `kenten` か `shape` の引数に従う。
圏点は行の幅に影響しない。

### 縦中横

縦中横の文字列は、横組みで組んだ結果を全角一字分の箱とする。
`[number-text ... style=tcy]` の数も同じ扱いとする。

### 縦組み

- 縦組みでは、HarfBuzz に縦書きの方向を指定し、OpenType の `vert`（または `vrt2`）の機能で縦書き用の字形を使う。
- 縦組みの中の欧文は、時計回りに 90 度回転して組む。

### Number の解決

Number の表記は、書字方向が決まった段階で解決する。
縦組みでは `style` 引数か `style.toml` の既定に従い、横組みでは算用数字とする。

## 実装しないこと

- 割注、傍線、添え字の組版。
- 段落の行頭の字下げ以外の、JLReq の段落の書式（ぶら下げインデントなど）。
- 縦組みの中の欧文を回転せずに一字ずつ組む方式（全角の欧文を除く）。

## テスト設計

- JLReq の付録の例（約物の連続、行頭と行末の禁則、和欧間の空き）を組み、期待した配置になることを golden テストで固定する。
- 禁則の強さを切り替えて、小書きの仮名が行頭に来るかどうかが変わることを確かめる。
- ルビが親文字より長い場合のかけと字間の空けを確かめる。
- 縦組みで縦書き用の字形が使われ、欧文が回転することを確かめる。
- 縦中横の文字列と、`style=tcy` の数が一字分の箱になることを確かめる。

## トレードオフ

JLReq の規則のうち、v1 で実装するのは書籍の本文に必要な範囲に限る。
割注や傍線のような記法は言語仕様にもまだ存在せず、必要になった段階で記法と組版の規則を合わせて ADR で加える。

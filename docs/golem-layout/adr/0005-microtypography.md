# ADR 0005: 文字の突き出しとグリフの幅の伸縮（hz）

ステータス: 採択

## 文脈

ADR 0001 の Knuth-Plass の方式は、語間の空きだけを伸び縮みさせて行の長さを合わせる。
欧文の両端揃えの品質をさらに上げる方法として、Hàn Thế Thành が pdfTeX に実装した二つの拡張（hz と呼ばれる）がある。

- 文字の突き出し（protrusion）：行末のハイフンや句読点を版面の外にわずかに出し、行の端が視覚的にそろって見えるようにする。
- グリフの幅の伸縮（expansion）：グリフの幅をごくわずかに伸び縮みさせ、語間の空きのむらを減らす。

どちらも Knuth-Plass の枠の中で、箱に伸縮の量を与える形で表せる。
和文の行末の句読点のぶら下げ（ADR 0002）は文字の突き出しの一種であり、この ADR は主に欧文の行を対象にする。

## 実装すること

### 文字の突き出し

- 行頭と行末で突き出しを許す文字と、その量（文字の幅に対する割合）の表を Golem に持つ。対象は、ハイフン、句読点、引用符などの欧文の約物とする。
- 突き出しの量は、行分割で行の長さを計算するときに、行頭と行末の箱の幅から差し引く。
- `style.toml` の `[composition]` の `protrusion` で有効にする。

### グリフの幅の伸縮

- 欧文の各グリフの箱に、伸びと縮みの量を与える。伸縮の限度（`limit`）と刻み（`step`）は千分率の整数で指定する（`limit = 20` は 2%、`step = 5` は 0.5%）。
- 行分割は、語間の空きとグリフの伸縮を合わせた伸び縮みの量で調整比を計算する。
- 行ごとに決まった伸縮の率を、刻みの整数倍に丸める。丸めは整数の計算で行う。
- PDF では、伸縮した行のグリフを、水平方向の拡大縮小（`Tz` の演算子）で描く。グリフの輪郭は変えない。
- 和文のグリフは伸縮しない。和文の行の長さは、ADR 0002 の字間の空きで調整する。
- `style.toml` の `[composition]` の `expansion` で有効にする。

## 実装しないこと

- 和文のグリフの伸縮。
- 可変フォントの幅の軸を使った伸縮。
- 突き出しの量をフォントごとに調整する設定。v1 では、すべてのフォントに同じ表を使う。

## テスト設計

- 突き出しを有効にした段落で、行末のハイフンと句読点が版面の外に出る量が表のとおりであることを確かめる。
- 伸縮を有効にした段落で、各行の伸縮の率が限度の範囲内にあり、刻みの整数倍であることを確かめる。
- 伸縮の有無で、語間の空きのばらつき（行ごとの調整比の分散）が小さくなることを確かめる。
- 和文のグリフが伸縮されないことを確かめる。
- 伸縮を含む段落の組版の結果が、二つのアーキテクチャで一致することを確かめる。

## トレードオフ

グリフの幅の伸縮は、フォントの設計者の意図しない字形の変形であり、伸縮の限度を大きくすると字面の濃さのむらが目立つ。
既定の限度は 2% とし、それ以上にする場合の見た目の責任は利用者が負う。

`Tz` による拡大縮小は、pdfTeX のようにフォントのインスタンスを伸縮ごとに作り分ける方式より単純で、PDF も小さくなる。
その代わり、グリフの輪郭は字幅に合わせて一様に伸縮し、細部の線の太さも変わる。

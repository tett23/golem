# ADR 0366: 注の本文と章末の注の見出しに段落スタイルを指定する

ステータス: 採択（未実装）

## 文脈

スタイルのうち、書き手が必要とする「脚注と章末の注の本文」の扱いを決める。

## 調査した事項

Golem [ADR 0177](0177-note-mark-style-and-numerals.md) の調査は、次の扱いを記録している。
本文の段落スタイルの見た目（`bodyLook`）で組み、段落スタイルを当てる手段がない（[脚注](https://github.com/tett23/golem/blob/50b9fca8a0744f6f9d92808db231e6c04ac35d2c/modules/golem-driver/src/Golem/Driver/Pdf/Flow.hs#L1462-L1470)、[章末の注](https://github.com/tett23/golem/blob/50b9fca8a0744f6f9d92808db231e6c04ac35d2c/modules/golem-driver/src/Golem/Driver/Pdf/Flow.hs#L1258-L1264)）。
章末の注の一覧の見出しは、第 2 階層の見出しの書体で組む。

## 実装すること

脚注本文、章末注本文、章末注の一覧の見出しにそれぞれ段落スタイルを選ぶ。
省略した本文は本文段落、一覧見出しは第 2 階層見出しの既定を継承する。
注の印には本文の指定を伝えない。

注チャネルの body-style に本文の段落スタイル名、heading-style に章末一覧の段落スタイル名を指定する。

## 実装しないこと

既存の原稿を新しい指定へ自動変換する機能は設けない。

## 不変条件

1. 一つの注チャネルの本文スタイルだけを変更しても他のチャネルの本文スタイルは変わらない。

| 境界の入力 | 期待する結果 |
| --- | --- |
| 脚注本文だけ指定 | 章末注は既定 |
| 一覧見出しだけ指定 | 注本文は既定 |

## テスト設計

- `inv1_note_body_styles_property` で次の述語を検査する。一つの注チャネルの本文スタイルだけを変更しても他のチャネルの本文スタイルは変わらない。
- `inv1_note_body_styles_case_1` は「脚注本文だけ指定」を入力とし、「章末注は既定」を確かめる。
- `inv1_note_body_styles_case_2` は「一覧見出しだけ指定」を入力とし、「注本文は既定」を確かめる。

## トレードオフ

注の行数が変わると、本文に使えるページの高さも変わる。

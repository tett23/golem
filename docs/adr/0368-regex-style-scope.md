# ADR 0368: 見出し、定義リストの用語、注の本文を正規表現スタイルの対象にする

ステータス: 採択

## 文脈

スタイルのうち、書き手が必要とする「正規表現スタイルの届かない文字」の扱いを決める。

## 調査した事項

Golem [ADR 0177](0177-note-mark-style-and-numerals.md) の調査は、次の扱いを記録している。
見出し、定義リストの用語、表のセル、注の本文には正規表現スタイルを当てない（[`RegexStyle.hs`](https://github.com/tett23/golem/blob/50b9fca8a0744f6f9d92808db231e6c04ac35d2c/modules/golem-eval/src/Golem/Eval/RegexStyle.hs#L50-L80)）。
原稿で `[style ...]` を書けば、文字スタイルは当てられる。

## 実装すること

各対象の一段落を本文と同じ規則で照合し、既存の文字スタイルとの優先順位を共用する。
生成番号を除いた文字列を使い、段落境界をまたいで照合しない。

注の番号と本文を別の範囲とし、定義リストの用語と説明も別の段落として照合する。

## 実装しないこと

既存の原稿を新しい指定へ自動変換する機能は設けない。

## 不変条件

1. 段落をまたがない各一致範囲だけに、本文と同じ優先順位で文字スタイルを当てる。

| 境界の入力 | 期待する結果 |
| --- | --- |
| 一段落内で一致 | 一致範囲だけ適用 |
| 二段落を連結して初めて一致 | 適用0件 |

## テスト設計

- `inv1_regex_style_scope_property` で次の述語を検査する。段落をまたがない各一致範囲だけに、本文と同じ優先順位で文字スタイルを当てる。
- `inv1_regex_style_scope_case_1` は「一段落内で一致」を入力とし、「一致範囲だけ適用」を確かめる。
- `inv1_regex_style_scope_case_2` は「二段落を連結して初めて一致」を入力とし、「適用 0 件」を確かめる。

## トレードオフ

照合対象が増えるため、既存の規則が新たに見出しにも一致しうる。

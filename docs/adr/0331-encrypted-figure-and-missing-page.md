# ADR 0331: 図版の PDF の暗号化と存在しないページを区別する

ステータス: 採択（未実装）

## 文脈

図版の PDF が暗号化されているときは、書き手が暗号化していないファイルを用意する必要がある。
一方、一ページの PDF の 100 ページ目を指定したときは、原稿の `page` を直せばよい。
現行版はどちらにも G08010 を出す。
PDF を読むモジュールでは既に別の原因として返しているが、図版を読み込む段階で文言だけにしている。

## 実装すること

暗号化された PDF には G08105 を、存在しないページの指定には G08106 を返す。
PDF の読み込み結果が持つ原因を図版の diagnostics を作るところまで渡す。
後者のメッセージは、要求したページ番号と読み取った総ページ数を含む。
どちらも原稿の該当する `@figure` の位置を指す。
各コードは PDF のビルドとプリフライトで同じ意味を持つ。

## 実装しないこと

パスワードによる復号や、存在するページへの自動的な置き換えは行わない。
破損した PNG の読み込み、SVG の構文、PDF の圧縮方式などは、この二つの原因に割り当てない。
それぞれの分割には別の入力と、書き手が実際に取れる対処を用意する。

## 不変条件

1. I1：読み込みが暗号化を検出すれば G08105、要求ページが範囲外であれば G08106 が、該当する図版の位置に一度出る。
2. I2：有効な一ページの PDF の一ページ目を指定したときに、どちらも出ない。

| 入力 | 結果 |
| --- | --- |
| 有効な一ページ PDF の一ページ目 | 新コードなし |
| 同じ PDF の二ページ目 | G08106 |
| 暗号化の辞書を持つ PDF | G08105 |
| PNG のヘッダーだけのファイル | 従来の G08010 |

## テスト設計

`experiments/diagnostics/baseline.mjs` はリポジトリの一ページの PDF を使う。
I1 の暗号化側は、既存のテストと同じ方法でトレーラーに暗号化辞書への参照を置く。
ページ側は変更していないファイルの 100 ページ目を要求する。
どちらも基準版では G08010 が原稿の三行目に出た。
本実装は境界の二ページ目と、実際に暗号化した外部生成の試料も加える。

## トレードオフ

G08010 を監視して図版の失敗を一括で扱う既存の CI は二つのコードを追加する必要がある。
文言の一部を照合して暗号化を判別する処理は不要になる。

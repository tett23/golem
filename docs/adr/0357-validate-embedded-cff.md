# ADR 0357: 範囲外を参照する CFF を PDF への埋め込み前に拒む

ステータス: 採択

## 文脈

フォント、PDF、EPUB の出力のうち、書き手が必要とする「CFF の表を短く切ったフォント」の扱いを決める。

## 調査した事項

[golem-pdf ADR 0013](../golem-pdf/adr/0013-renamed-cff-table-is-g08003.md) は、フォントを開けない場合と、埋め込み時に CFF の表を取り出せない場合を区別している。

## 実装すること

CFF の表を境界とし、INDEX の終端、辞書が指すデータ、使用グリフの CharString とサブルーチンの参照先を検証する。
表外を読む入力は新しい G08107 で拒み、PDF を発行しない。

G08003 はフォントを開けない場合、G08018 は埋め込む表がない場合に引き続き使う。
G08107 は表が存在して内部参照が範囲を外れる場合に限る。

## 実装しないこと

未使用グリフを含むフォント全体の適合性認証は扱わない。

## 不変条件

1. 使用する参照先の終端が宣言された表長を超える入力から PDF を発行しない。

| 境界の入力 | 期待する結果 |
| --- | --- |
| 終端が表末尾と一致 | 受理 |
| 使用データが1バイト不足 | G08107 |

## テスト設計

- `inv1_validate_embedded_cff_property` で次の述語を検査する。使用する参照先の終端が宣言された表長を超える入力から PDF を発行しない。
- `inv1_validate_embedded_cff_case_1` は「終端が表末尾と一致」を入力とし、「受理」を確かめる。
- `inv1_validate_embedded_cff_case_2` は「使用データが 1 バイト不足」を入力とし、「G08107」を確かめる。

## トレードオフ

使うグリフの参照をたどるため、埋め込み前の検査時間が増える。

# ADR 0370: 縦中横とルビの外側の字間にトラッキングを適用する

ステータス: 採択（未実装）

## 文脈

スタイルのうち、書き手が必要とする「トラッキングの届かない文字」の扱いを決める。

## 調査した事項

Golem [ADR 0177](0177-note-mark-style-and-numerals.md) の調査は、次の扱いを記録している。
縦中横の箱は外側の見た目の大きさで一つの箱になり、トラッキングを足さない（[`Japanese.hs`](https://github.com/tett23/golem/blob/50b9fca8a0744f6f9d92808db231e6c04ac35d2c/modules/golem-layout/src/Golem/Layout/Japanese.hs#L289)）。
仕様書は、ルビ、縦中横、注の印にトラッキングを足さないとしている。
注の印はこの ADR で直す。

## 実装すること

縦中横とルビをそれぞれ外側の一つの箱として数える。
同じトラッキング値の列では隣接する箱の間に一度だけ指定量を足す。
縦中横の内部や読みの内部には外側の値を配らない。

異なるトラッキング値が隣接した場合は先行する箱の値を使い、行末には足さない。

## 実装しないこと

既存の原稿を新しい指定へ自動変換する機能は設けない。

## 不変条件

1. 行内の n 個の対象箱に同じ値 t を指定したとき、追加する幅は max(0, n − 1) × t である。

| 境界の入力 | 期待する結果 |
| --- | --- |
| 単独の箱 | 追加0 |
| 縦中横とルビの2箱 | 箱間に1回 |

## テスト設計

- `inv1_tracking_inline_boxes_property` で次の述語を検査する。行内の n 個の対象箱に同じ値 t を指定したとき、追加する幅は max(0, n − 1) × t である。
- `inv1_tracking_inline_boxes_case_1` は「単独の箱」を入力とし、「追加 0」を確かめる。
- `inv1_tracking_inline_boxes_case_2` は「縦中横とルビの 2 箱」を入力とし、「箱間に 1 回」を確かめる。

## トレードオフ

箱の内部の字間は外側のトラッキングだけでは調整できない。

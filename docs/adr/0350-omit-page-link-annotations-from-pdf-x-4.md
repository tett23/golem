# ADR 0350: PDF/X-4 の本文にリンクの注釈を置かない

ステータス: 採択

## 文脈

Golem は PDF/X-4 を宣言する本にも、外部リンクと文書内リンクの文字の上にクリックできる矩形を置く（[ADR 0182](0182-external-links.md)、[ADR 0267](0267-pdf-bookmarks-and-links-inside-the-document.md)）。
PDF Association の解説は、PDF/X の印刷領域に注釈を置けないとする。
印刷データの入稿を受け付ける DUON の PDF/X-4 用の検査も、仕上がりや塗り足しの領域にある通常の注釈を指摘する。

2026-11-11 に macOS の Golem 0.1.0-rc4 で再現した。
golem-driver の conformance fixture の横組みの設定に、CI の golem-test-cmyk.icc を[color]の intent として指定した。
章を一つにして、見出し「見本」の次の段落に外部リンクを置いた。

```
# 見本

[link "https://example.com/": 外部リンク]
```

`golem build --target pdf` の出力に対し、`pdfinfo -box` は PDF/X-4 と表示し、`pdfinfo -url` は 1 ページ目のリンク先を返した。
PDF の TrimBox と BleedBox はともに `[0 0 419.5276 595.2756]` で、注釈の矩形 `[65.1969 447.874 107.5465 456.3779]` は両方の内側にある。
この出力を DUON に入稿する検査は実施していない。

## 実装すること

PDF/X-4 を宣言する出力では、本文にある外部リンクと文書内リンクを、文字とその装飾として描く。
書誌の外部リンクと、[ADR 0267](0267-pdf-bookmarks-and-links-inside-the-document.md) の「リンクにするもの」の表にある相互参照、注の往復、目次、索引、引用にも同じ扱いを適用する。
ページにリンク注釈を割り当てる前に分岐し、構造ツリーには読み順と本文を保ち、生成しない注釈を指す OBJR を残さない。
文書内のページを直接指すしおりはページの注釈を使わないので維持する。
電子配布用にクリックできる本文リンクが必要な場合の出力方法を仕様書、README、利用者マニュアルに記す。
リンク注釈の存在を前提にしたリリース手順とロードマップを改め、変更の及ぶ既存 ADR のステータスにこの ADR へのリンクを付ける。

[ADR 0221](0221-check-iso-15930-7-for-link-annotations-before-rc4.md) と [ADR 0226](0226-move-the-iso-15930-7-check-to-before-v1.md) の照合について、印刷領域のリンクは公開資料と生成物を照らし合わせて対処する。
実装 PR で、根拠、検査した出力、未確認の事項を新しい監査記録に残す。
メンテナーの指示に基づき、この印刷領域の問題については、公開資料と生成物による監査記録を実装修正の根拠とする。
未確認の問いと要件一覧の照合は、期限と担当を含めて [ADR 0226](0226-move-the-iso-15930-7-check-to-before-v1.md) に従い、確認できた項目と分けてロードマップに残す。

## 実装しないこと

リンクをページの外へ移したり、Print フラグだけを落としたりする方法は採らない。
ページとは別の辞書にあるしおりの全面的な適合性、URI アクション一般の許容範囲、外観ストリームを省略できる条件は今回の資料では確定していない。
golem-pdf の PDF/X-4 要件一覧全体の照合は別に記録する。

## 不変条件

1. X1。PDF/X-4 の各ページには、本文の外部リンクおよび文書内リンクに対応する Link 注釈がゼロ個ある。
2. X2。PDF/X-4 のリンクの表示文字、ページ上の位置、読み順は維持され、存在しない注釈を参照する構造要素はゼロ個である。
3. X3。PDF/X-4 を宣言しない PDF では既存の URI と文書内の行先が機能する。
4. X4。PDF/X-4 の文書内のしおりは実在するページを指す。

| 入力 | 確かめること |
| --- | --- |
| リンクがない1ページ | X1、X2 |
| 外部リンク一つ、文書内リンク一つ | X1、X2、X3 |
| 行をまたぐリンク、目次としおりのある複数ページ | X1、X2、X4 |
| PDF/X-4 と PDF/A-2a、PDF/UA-1 を同時に宣言する本 | X1、X2、X4 と既存の veraPDF 検査 |

## テスト設計

X1 のテストを先に追加し、現在のライターが生成するリンク注釈を検出して失敗させる。
生成した PDF のページ辞書と構造ツリーをたどり、X1、X2、X4 を確かめる。
X2 は同一の原稿、設定、書体による変更前後のページ画像と、位置付きの抽出テキストを比較する。
構造ツリーを文書順にたどり、注釈を除いた本文の順序と文字列も比較する。
同じ原稿を出力インテントを外して組み、X3 の注釈の辞書と行先を照合する。
PDF/A と PDF/UA を宣言する試料は既存の CI の veraPDF で確かめる。

## トレードオフ

入稿用 PDF の本文リンクをクリックする機能が失われる。
リンクの矩形を出力しないことで、印刷領域の注釈を指摘する入稿検査の原因を取り除く。

# ADR 0397: 段落ごとの行送りと寸法で指定する段落間隔

Status: accepted

## 文脈

台本では、一つの台詞の折り返し行の間隔と、次の台詞までの間隔を別々に決めたい。
ト書きには台詞と異なる行送りを使い、段落のインデントや、読まない台詞に付ける文字色とは独立して調整したい。
一つの台詞を一つの段落にし、Emet のブロック命令から段落スタイルを付ける使い方を対象にする。
台詞やト書きのスタイル名、行送り、段落間隔、文字色、インデントはプロジェクトごとに定義し、Golem の台本専用の既定値にはしない。

現在の本文は共通の行の格子に載る。
段落間に整数行のアキを入れるだけでは、台詞内の行送りと台詞間の追加のアキをプロジェクトごとの寸法で指定する要求を満たせない。
この提案では、従来の格子にそろえる組版を既定として残し、寸法で行を配置する組版を選べるようにする。

## 実装すること

### 組版モードと設定

`[page.grid]` に `alignment = "grid" | "free"` を加える。
既定は `"grid"` とし、既存の原稿の配置と改ページを変えない。
`"free"` は本文の行を格子の位置へ丸めず、行送りと段落間隔の寸法で配置するモードである。
文書全体で選び、段落の途中では切り替えない。
`font-size`、`characters`、`lines`、`columns` と版面寸法の関係は従来どおりとし、`line-pitch` は既定の行送りとして残す。

段落スタイルに `line-pitch` を追加する。
値は正の寸法、または `"auto"` であり、`"auto"` は版面の `line-pitch` を使う。
`body` の既定は `"auto"` とし、`based-on` で継承できる。
寸法の単位は `mm`、`pt`、`Q`、`H`、`in`、`zw` とし、`zw` は継承を解決した段落の文字の大きさを基準にする。
行送りは横組みでは隣り合う行の基準位置の上下の距離、縦組みでは左右の距離である。

`space-between`、`space-before`、`space-after` は、従来の 0 以上の整数に加えて、0 以上の寸法の文字列を受け取る。
整数は引き続き版面の行送りの倍数を表し、段落固有の行送りの倍数にはしない。
寸法の単位と `zw` の基準は段落の `line-pitch` と同じである。
数値の `1` と文字列の `"1pt"` は異なる意味になる。

`alignment = "grid"` で、解決後の段落スタイルに寸法の `line-pitch` または寸法の段落間隔があれば、設定のエラー G03006 とする。
黙って格子へ切り上げたり、設定を無視したりしない。
`"free"` を選ぶ案内を diagnostics に含める。
負の間隔、0 以下の行送り、不正な単位も G03006 とし、設定位置を示す。
寸法から内部の整数単位 sp への変換後にも値の範囲を検査し、0 へ丸められる行送りを拒否する。

### 新しい欄の適用範囲

`line-pitch` は、文書の通常の段落に適用する。
通常の段落には、最上位の段落、`@style` の本体、リスト項目、定義リストの説明、Emet とプラグインがそれらの位置へ返す段落を含める。
定義リストの用語は本文の既定の P を使う。
目次項目、索引、参考文献など処理系が生成する専用の行には、この欄を適用せず従来の内部の行送りを使う。

実際のキャプション、脚注、章末注、傍注、表のセル、見出し、コード内部には適用しない。
一方、`caption`、`sidenote`、`table` の名前の段落スタイルを通常の段落に付けた場合は、通常の段落として `line-pitch` を使う。
`code` は従来どおり通常の段落に付けられず、その定義の `line-pitch` も G03006 で拒否する。
ほかの特殊スタイルの定義に欄を書くこと自体は許し、適用する場所かどうかで使い分ける。

寸法の `space-between`、`space-before`、`space-after` は、通常の段落と独立した生成行に適用し、各欄の対象は既存の整数指定の範囲を超えない。
たとえばリストの項目には既存の `space-between` の範囲で適用し、段落前後のアキの適用範囲は広げない。
目次など既存の整数のアキを使う生成行にも寸法のアキを適用するが、それによって `line-pitch` の適用範囲は広げない。
実際のキャプション、傍注、脚注、章末注、表のセル、見出し、コードの内部の間隔は、整数行の指定だけを使う。
これらの内部で適用する間隔を寸法で解決した場合は、使用箇所で G03006 とし、整数行を指定する案内を含める。
この制限は [root ADR 0367](0367-caption-sidenote-paragraphs.md) のキャプションと傍注の `space-between` にも適用する。

### Emet とプロジェクトの役割

Emet の公開ブロック関数は、受け取った本文に、プロジェクトで定義した段落スタイルを付けて返す。
台詞やト書きの命令名、話者の扱い、読まない台詞を選ぶ条件は、プロジェクトの `.emet` に書く。
文字色は文字スタイル、インデントと行送りと段落間隔は段落スタイルに書く。
原稿を変えずに、プロジェクトのスタイル定義を変えて見た目を変更できるようにする。

既存の `Block.Paragraph`、`Block.styled` と `Inline.style` で表せる処理には、専用の言語機能を追加しない。
[Emet の組み込み定義](https://github.com/tett23/golem/blob/dc8bf92ec33549ae2cd3b1cbf43487d451b1071a/modules/golem-emet/src/Golem/Emet/Builtins.hs#L102-L187) に、文字スタイルと段落スタイルを付ける機能がある。
この ADR の拡張は、その段落スタイルから行送りと寸法の段落間隔を指定するためのものである。
台本固有の数値を処理系に埋め込まない。

### 行の配置と段落間隔

自由な配置では、各本文行に解決済みの行送り p の行ボックスを割り当てる。
行ボックスの送り方向の中心に文字の仮想ボディの中心を合わせ、隣接する行ボックスを順に置く。
同じ段に置く同じ段落の基準位置の差は p となる。
罫線、囲み、明示的なアキ命令を挟まない段落の境界では、行送り p と q に対し、中心位置の差は `p - floor(p / 2) + floor(q / 2) + s` sp となる。
行ボックスの始まりは整数 sp で累積し、中心位置は始まりから `floor(p / 2)` sp の位置とする。
文字の仮想ボディの中心も同じ丸め方で配置する。
s は境界に入れる追加のアキである。
段の先頭は最初の行ボックスの始まりを版面の始まりに置く。

境界のアキを選ぶ規則は、[root ADR 0189](0189-paragraph-alignment-spacing-and-end-indent.md) を引き継ぐ。
同じ段落スタイルなら `space-between` を使い、異なるスタイルなら前段落の `space-after` と後段落の `space-before` の大きいほうを使う。
比較の前に、各スタイルの寸法を sp に解決する。
段の先頭と、改ページで分かれた段落の続きの先頭には、段落間のアキを置かない。
前後のアキは加算しない。

`line-breaks = "keep"` の明示的な行分けにも、同じ段落の行送りを使う。
一つの段落を内部で複数の単位に分けても、各行の間に `space-between` を入れない。
段落のインデントと文字色は、行送りや段落間隔の設定で変えない。
文字列と行長が同じなら、行分割も変えない。
アキの変更で回り込み図版との位置関係が変わり、行長が変わる場合は、行分割をやり直す。

行送りは固定値であり、ルビ、大きい文字、ベースラインの移動で自動的に広げない。
小さい行送りによる字形の重なりは許す。
ただし、配置の計算と描画で異なる行送りを使ってはならない。

### 段の寸法と改ページ

自由な配置でも版面の寸法は変えない。
版面の行送りを P、文字の大きさを F、行数を L とすると、送り方向の段の長さは `H = (L - 1) × P + F` sp である（[golem-layout-spec ADR 0001](../golem-layout-spec/adr/0001-page-geometry.md)）。
段の始まりを 0、終わりを H とする半開区間に、行ボックスの全長を収める。
横組みでは上から下、縦組みでは右から左へ測り、ページ上の座標への変換は最後に行う。
`free` の `auto` も P の長さの行ボックスなので、同じ設定の `grid` と収まる行数が等しいとは限らない。
互換性を保証する対象は、既定の `grid` である。

改ページの本文使用量、脚注予約量、間隔、残量、先読みの必要量を sp で持つ。
残量は段の長さから本文使用量と脚注予約量を引き、囲みの中では後述する末尾の padding の必要量も予約する。
行がちょうど収まれば同じ段に置き、1sp でも足りなければ次の段を検討する。
段落の行送りは分割後も変えない。
新しい段では、送った図版と続きの脚注を先に配置し、その結果の残量で保持条件を再判定する。

孤立行と保持の対象は [root ADR 0261](0261-keep-options-of-paragraph-styles.md) のままとする。
`keep-first-lines`、`keep-last-lines`、`keep-with-next` が指すのは表示行数であり、選んだ行の行ボックスの長さを合計して収まるかを判定する。
`line-breaks = "keep"` の行を一つのまとまりとして扱う規則も維持する。
空の段にも保持対象が入らない場合は、既存の優先順位で保持を緩め、G07111、G07112、G07113 を出す。
一行そのものが空の段に入らない場合は、新しいエラーG07129 で止める。

見出し、表、回り込ませない図版、コードの内部の行送りと分割単位は変えない。
既存の占有行数 n を `n × P` sp へ変換し、そのブロックの先頭に対する既存の相対配置を使う。
既存の先頭の字面の原点は、ブロックの先頭から `floor(P / 2) - floor(F / 2)` sp の位置に移す。
これにより旧来の格子の一行を、自由な配置の一行ボックスに対応させる。
ブロック間では格子に整列しない。
目次と索引の段切り替えでも開始位置を sp で保持し、整数の格子行へ戻さない。

非段落ブロックの事前検査も、整数行数の比較だけで済ませず、変換後の実寸と H を比較する。
各不可分単位と diagnostics は次のとおりとする。

| ブロック | 空の段に収まらない場合 |
| --- | --- |
| 見出し | 本体の行取りがHを超えればG07024。見出しと後続の保持が守れない場合は既存の優先順位で保持を緩める |
| 表 | 見出し行と本体一行の最小部分がHを超えればG07042。キャプションも一緒に必要な先頭か末尾の最小部分が超えればG07116 |
| コード | 続きの表示が必要な場合はその表示も含む最小部分がHを超えればG07043 |
| 回り込ませない図版 | 下記の実効行数で従来の縦横比を保つ縮小を行う。キャプションが画像の一行を残さなければG07038。縮小した場合はG07039 |

図版が利用できる実効行数は `floor(H / P)` とする。
画像とキャプションが合わせてこの行数に収まるよう、[golem-driver ADR 0034](../golem-driver/adr/0034-fit-figures-to-column.md) の縮小と寄せの手順を使う。
実効行数が 0 なら、画像の一行分の領域を確保できないため G07131 で止める。
回した図版は従来どおり一ページの専用領域を使い、その領域の送り方向の長さから同じ基準で判定する。
これらの縮小と検査は、各ブロックを配置する前に完了させる。

`@page-lines` で縮めた段に限って見出しが入らない場合の G07100 は維持する（[golem-layout ADR 0020](../golem-layout/adr/0020-heading-taller-than-column.md)）。
この場合は、見出しを縮める前の段に収まる寸法のまま置き、調整後の段からの超過を許す既存の例外とする。
以後の通常のブロックは次の段へ送る。
ほかの不可分単位が縮めた段に入らない場合は、調整がリセットされる次の段へ送り、空段でも同じ調整状態を繰り返さない。

傍注の内部の行送りと重なりを避ける規則は変えない。
配置を要求する本文行の位置には、自由な配置で確定した実際の位置を使う。
傍注の領域の位置と寸法、縦組みでの制限、収まらない場合の G07033 も維持する。

### 行アキと改ページの制御

`@blank-line`、`@need-lines`、`@page-lines` の一行は P とし、整数 N を `N × P` sp へ換算する。
段落間隔と `@blank-line` が重なる場合は、従来どおり `@blank-line` だけを使う。
段の先頭では両方とも捨てるが、囲みの padding と罫線領域は捨てない。
文末と明示改ページ直前の行アキ、連続する行アキの合算と上限は [root ADR 0046](0046-blank-line-command.md) と [root ADR 0047](0047-blank-line-limit.md) を引き継ぐ。
この上限は従来どおり設定の L で判定し、自由な配置で実際に入る本文行数には依存させない。

`@need-lines` は空きの前後の位置によらず、同じ境界の空きを除いた残量で判定する。
待つ図版は、その境界の空きの記録を区切らない。
配置する段が変わったときだけ、移った先の図版と脚注を配置した後で判定し直す。
必要量が段の長さを超える場合は G07037 を出し、必要量を段の長さまでに制限する。
この判定は [golem-layout ADR 0025](../golem-layout/adr/0025-need-lines-and-blank-lines-after-figures-sent-on.md)、[golem-layout ADR 0026](../golem-layout/adr/0026-need-lines-and-blank-lines-pass-over-waiting-figures.md)、[golem-layout ADR 0027](../golem-layout/adr/0027-need-lines-judged-again-after-spaces.md)、[golem-layout ADR 0043](../golem-layout/adr/0043-spaces-before-need-lines-are-not-counted-either.md)、[golem-layout ADR 0047](../golem-layout/adr/0047-spaces-before-a-waiting-figure-and-need-lines.md) の制御順を維持する。

`@page-lines` は、その段の終わりを `N × P` sp だけ動かす。
要求する増減は整数行のままとし、許される増減の範囲内で、要求に最も近い整数行の増減を採る。
減らした段は、調整前の一行に相当する長さ F 以上を残し、すでに配置した本文と予約した脚注の全体を収める。
増やした段は仕上がり線を越えない。
制限で要求どおりに変えられなければ G07037 を出す。
段を進めると増減はリセットし、脚注は変えた段の終わりにそろえる。
`@no-page-break` の対象と優先順位、明示的な改ページと改丁も [root ADR 0030](0030-manual-page-break-control.md) のままとし、必要な量だけを sp へ変える。

### 脚注

本文の行送りと脚注の行送りを混同しない。
脚注の行は従来の P を使い、注の残り行数は行数のまま保持し、予約する長さだけを `注の行数 × P` sp に変換する。
脚注の区切り領域は既存の規則で求めた行数に P を掛け、その段に脚注があるときだけ一度予約する。
区切り線の指定と既定値は変更しない。
注本文と区切りの相対配置を一つの領域とし、その終わりを段の終わりにそろえる。

通常の本文行を置く判定では、その行の行ボックスと、そこから初めて参照する注の必要量を一緒に調べる。
今の段に入らなければ印の行を次の段へ送る。
空の段でも注の全体が入らなければ、本文行と区切りを予約した残量に収まる注行の接頭部分を置き、残りを次の段へ送る。
必要な注が複数ある場合は既存の文書順で処理し、まだ置けない注も続きの列に残す。
本文一行と区切りと注一行も空の段に入らない場合は、G07130 で止める。
囲み内の行では、当該行だけで一つの囲み部分を作ったときの前後の追加分も、この合計に含める。
先に囲み単独の G07121 を検査し、それを通った後に脚注との合計を G07130 で検査する。
注だけが継続する空の段でも、区切りと注一行の合計がその段に収まらなければ G07130 とし、その注を最初に参照した印の位置を示す。
保持の先読みでも、本文の長さと注の長さを別々に合計し、区切りを二度足さない（[golem-layout ADR 0019](../golem-layout/adr/0019-keep-with-next-counts-footnotes.md)）。

罫線付き段落では、段落全体を優先し、入らない注本文を後続へ送る既存の例外を維持する。
見出しは注本文も含めて先読みする（[golem-layout ADR 0013](../golem-layout/adr/0013-heading-footnotes.md)）。
囲みの脚注は囲みの外に配置し、囲みの後ろの padding と脚注予約量を別々に引く。
脚注の印と本文の対応、脚注の順序、段をまたぐ注の継続は変えない。

### 回り込み

自由な配置でも、回り込む図版と脇の段落を、図版の先頭を原点とする一つの仕事として先に組む。
図版とキャプションの実際の範囲に `wrap-gap` を加え、送り方向を格子行に切り上げず、実寸の除外矩形を作る。
段落の開始位置を sp で持ち、段落内の行 i の位置は、その開始位置と行送りから求める。
行ボックスと文字の仮想ボディの和集合が、除外矩形と送り方向に正の長さで交わる行の行長を短くする。
端が一致するだけなら交差しない。
`wrap=start` の始まりのずらしも同じ交差判定で決める。

段落の終了位置と次の段落とのアキを開始位置に足して、次の段落を組む。
したがって、スタイルを変更してアキか行送りが変われば、その組版の仕事で行分割を計算し直す。
ページへ配置するたびに再行分割する反復は加えない。
脇に置ける範囲は、現行と同じく罫線と囲みを持たない通常の段落の並びとし、段落間のアキはその並びの位置計算に含める。
見出し、表、コード、明示的な改ページ、行アキ命令、別の図版、罫線付き段落、囲みが来たところで脇の本文を終える。
これらのブロックは、除外矩形とすでに組んだ脇の行の終わりの大きいほうから配置する。

除外矩形が今の段に入らなければ、図版と脇の行を次の段へ送り、元の段の残りは空ける。
図版を送るだけでは、図版と脇の行の相対位置は変わらないので行分割をやり直さない。
脚注の予約や最後の脇の行ボックスの長さで脇の行の一部が収まらない場合は、最初に収まらなくなる行以降を続きの行として後続の段へ送る。
送った行の短い行長とインデントはそのまま残す。
これは [golem-driver ADR 0005](../golem-driver/adr/0005-pdf-wrapped-figures.md) の、脚注で脇の行が送られる場合の扱いを引き継ぎ、行分割と改ページの相互反復を避けるためである。
一行自体が空段に入らない場合は G07129 とする。

段組みの回り込みの禁止 G07026、脇に残す行長の下限 G07022、字下げ後に行長が残らない G07028 は維持する。
G07023 は、自由な配置では除外矩形の送り方向の長さが段の長さ H を超える場合とし、行数でなく寸法をメッセージに書く。
ページ番号解決の各回で、仮の参照値から行分割をやり直す従来の S2 を使い、上限の回数と未収束の G07021 は変更しない。
図版ごとの仕事の結果は文書順に戻してから行番号を振り、並列と逐次の結果を一致させる。

### 段落の罫線

自由な配置の罫線領域は、前後の行ボックスと字面の実寸から求める。
行ボックスの先頭を x、行送りを p、文字の大きさを h とし、字面の始まりを `x + floor(p / 2) - floor(h / 2)`、終わりを始まり+h とする。
罫線の内側の間隔は、その段落の字面と罫線の端との距離である。
前の罫線では段落の最初の行のルビと圏点の張り出しを字面の前に加える。
後ろの罫線では、次の行の同じ張り出しを加える。

隣接する行の字面のあいだの元の距離を g、罫線の太さを w、内側の指定間隔を i、外側を o、考慮する張り出しを r とする。
段内では、必要な追加の長さを `max(0, i + w + o + r - g)` sp とし、格子行へ切り上げない。
間隔の指定があれば内側の間隔を正確に取り、余った距離を外側に置く。
両方の間隔が未指定なら、張り出しを除いた距離の中央に線を置き、奇数 sp の余りを外側に置く。
負の元の距離も式のまま扱い、小さい行送りで字面が重なっている場合には必要な長さを足す。

二つの罫線が領域を共有する場合、必要量は `iA + wA + max(oA, oB) + wB + iB + r` とし、同じく元の字面間隔を引いた非負の長さを足す。
指定した内側の間隔を保ち、余りを罫線間へ入れる。
すべての間隔が未指定なら、線の太さと張り出しを除いた距離を三つに分け、割り切れない sp を中央に置く。
段落間のアキを挟むときは領域を共有せず、前段落の後ろの罫線、アキ、後段落の前の罫線の順に置く。
この場合、各罫線の外側の境界はアキの領域の端とし、アキの長さを罫線の間隔へ流用しない。

段の先頭と終わりでは外側の間隔を捨てる。
対象の行の前の空きを `a = floor(p / 2) - floor(h / 2)`、後ろの空きを `b = p - h - a` とする。
先頭の罫線の追加量は `max(0, i + w + r - a)`、末尾の罫線の追加量は `max(0, i + w - b)` sp とし、行ボックス内の空きを二重に数えない。
段端で間隔が未指定の場合は、この追加後の字面と段端の距離から線の太さと張り出しを除き、その中央に線を置く。
奇数 sp の余りは段端の側に置く。
最小一格子行を予約する現行の規則は自由な配置には適用しない。
`keep-in-column = false` の版面外配置は [golem-driver ADR 0040](../golem-driver/adr/0040-rules-outside-column-only-at-type-area-edge.md) のとおり版面の端だけで許し、途中から始まる段や、脚注に接する段末では内側へ置く。
版面外に線全体が収まり、内側の間隔も確保できるときは、本文側に追加の長さを取らない。
仕上がり線と段間へのはみ出しの検査 G07001 は維持する。

前後の罫線と本文を合わせて空の段に収まるかを実寸で判定する。
収まる段落は全体を同じ段に置き、収まらない注本文だけを送る。
空の段にも収まらない段落は、[golem-driver ADR 0035](../golem-driver/adr/0035-paragraph-rules-split-and-space-units.md) のとおり、罫線をすべて省き、G07046 を出して通常の段落として分割する。
この分割には段落の保持指定を当て、保持できない場合の警告も通常どおり出す。
見出しに付く罫線も領域の長さはこの節で求め、見出し自体の内部配置と不可分性は変更しない。

### 段落の囲み

同じ囲みへまとめる条件、内側の段落間隔、分割した各部分で囲みを閉じる規則は [root ADR 0271](0271-paragraph-backgrounds-and-borders.md) を維持する。
自由な配置では、各部分の最初と最後の字面から、指定した padding の距離に囲みの内側の端を置く。
padding を d、最初の行の行送りと文字サイズを p と h とすると、前の追加量は `max(0, d - (floor(p / 2) - floor(h / 2)))` sp である。
最後の行の行送りと文字サイズを q と j とすると、後ろの追加量は `max(0, d - (q - j - (floor(q / 2) - floor(j / 2))))` sp である。
したがって、行ボックス内にすでにある空きと padding は二重に数えない。
線の太さの取り方と、囲みの行方向の位置は既存の規則を使う。
枠線の中心を囲みの辺に置き、枠の太さを占有長さへ加えないため、枠の輪郭は占有領域から半分の太さだけ外へ出る。
この挙動と仕上がり線へのはみ出しの検査は変更しない。

部分に k 行を置く場合、最初の行の前の追加分、各行の行送り、内部の段落間隔、最後の行の後の追加分を合計して収まりを判定する。
最後の行の行送りや文字サイズが変われば、後ろの追加分も計算し直す。
囲みを分割した各段で前後の追加分を取り、段の先頭でも捨てない。
囲みの外の段落前後のアキは、先頭の部分の前と末尾の部分の後にだけ置く。
本文行の脚注は囲みの外へ予約する。

空の段にも、一つの行ボックスと、その行の前後の padding の追加分が収まらなければ G07121 を出す。
複数の行送りを含む囲みでは各行について検査し、同じ段落スタイルには最初の該当箇所で一度だけ出す。
囲みのない一行の G07129 より、この G07121 を優先する。

### diagnostics と停止性

新しい diagnostic コードは、採択前に確認した main（`05c4a20de1b532a4346fc9e22f997dbed4e1aa96`）で未使用の G07129、G07130、G07131 を使う。
いずれもレイアウトのエラーとし、PDF の生成を止める。
既存コードの原因と重大度は維持し、自由な配置のメッセージで収まりを説明する場合は、行数の代わりに寸法を書く。
原稿の行数指定そのものを説明する箇所には、指定した行数も残す。

| コード | 自由な配置での条件と位置 |
| --- | --- |
| G07129 | 囲みのない本文の一行ボックスが空の段に入らない。メッセージは「段落スタイル <名前> の一行が段に収まりません」。その段落の位置 |
| G07130 | 本文の一行と必要な囲みの追加分、脚注区切り、必要な注一行が空の段に入らない。または注の継続段で区切りと注一行が入らない。メッセージは「脚注の最初の一行を段に配置できません」。その注を参照した印の位置 |
| G07131 | 自由な配置で、回り込ませない図版に一行分の領域も確保できない。メッセージは「図版の一行分の領域が段に収まりません」。図版の位置 |
| G07121 | 囲みの一行と前後の追加分が空の段に入らない。そのスタイルの最初の該当段落 |
| G07046 | 罫線付き段落が空の段に入らず、罫線を省略する。従来の罫線の位置 |
| G07023 | 回り込みの除外矩形が段より長い。図版の位置 |
| G07037、G07111からG07113 | 手で指定した改ページ制御や段落の保持を守れない。従来と同じ指定箇所 |
| G07047 | 段の先頭で行アキを捨てた。従来と同じ行アキの位置 |

配置の進捗は、入力の次の Flow を処理するか、待つ図版か継続する注を取り出す外側のループの一反復で検査する。
各反復は、次のいずれかを行う。

- 本文か注の行を一つ以上消費する。
- 待つ図版を配置する。
- 未処理の空きか改ページ制御を消費する。
- まだ物がある段から次へ進む。
- 空の段の非ゼロの行数調整をリセットして次へ進む。
- エラーを返す。

保持の先読みと領域の計算は有限の入力を走査する内部処理とし、その中の再計算を一回の配置反復とは数えない。
同じ未処理入力のまま空の段を作り続けない。
空の縮小段からの移送は調整をリセットするため、同じ未処理入力について繰り返さない。
脚注の継続と回り込みを含めても、ページへの移送を理由とする新しい行分割の反復は作らない。

### データ構造と出力

設定の段階では、段落間隔を行数と寸法の和型で持ち、継承と型検査の後に解決する。
自由な配置の組版では、解決済みの行送りと間隔を sp で持ち、行数の `Int` に戻さない。
意味論 IR と Emet の `Block.Paragraph` には段落スタイルの名前だけを残す。
行送りと間隔の解析、継承、実寸への解決は golem-project、行ボックスの生成と回り込みは golem-typeset、配置と保持の判定は golem-layout が受け持つ。
寸法の積と和は、既存の任意精度の整数を使う Sp のまま計算する（[Length.hs](https://github.com/tett23/golem/blob/dc8bf92ec33549ae2cd3b1cbf43487d451b1071a/modules/golem-length/src/Golem/Length.hs#L31)）。
設定値の符号と 0 への丸めを検査し、配置で合計が段を超える場合は飽和させず通常の収まり判定で扱う。

`LineBox` に解決した送り方向の長さと文字の大きさを渡し、行の個数は別に保持する。
`Need` は本文と注の長さを別々に持ち、脚注の継続位置は従来どおり行の番号を使う。
`PageOut` の配置位置と、表と囲みの各部分の開始位置と終了位置は、自由な配置では sp で表す。
格子行番号との取り違えを防ぐ型を設け、描画側が行番号に P を掛け直すことを禁止する。
脚注、罫線、囲み、図版、リンクの矩形、索引と傍注の参照位置にも、同じ配置結果を使う。
格子モードの既存の経路は維持し、内部型を共有する箇所でも従来の丸め位置を変えない。

[root ADR 0398](0398-styled-separators-in-manuscripts.md) の区切りと併用する場合、style で指定した区切りの一行を P へ変換し、格子に戻さず配置する。
Emet が返した段落と行アキは、通常の段落と行アキとしてこの ADR の規則を使う。
区切り機能の採択と実装は、この ADR の実装の前提にはしない。

HTML と EPUB では、自由な配置の段落に解決した `line-height` と段落間の margin を書く。
段落のフォントサイズに依存しない絶対単位へ変換し、本文の既定の margin と二重に加算しない。
ブラウザーによる行分割とページ分割が PDF と一致することは要求しない。
プレーンテキストでは、新しい寸法指定を出力に反映せず、従来の段落区切りを保つ。

`@style-def`、設定の補完、diagnostics、README、仕様書、利用者向けマニュアルを実装と同時に更新する。
[ロードマップ](../roadmap.md) の段落スタイルの拡張からは、実装を終えた行送りの部分だけを取り除く。
採択時には、以下の範囲の変更を各 ADR のステータス行に記録する。
記録は自由な配置に限る変更として、既存の格子モードの決定を残す。

## 実装しないこと

台本専用の組み込み命令、配役の管理、自動的な話者判定は追加しない。
台詞やト書きの命令は既存の Emet の機能で定義する。
段落ごとの格子への復帰、自動行送り、見開きの行位置の自動調整は追加しない。
表のセルや注に本文と同じ段落スタイルの全項目を適用する変更は含めない。

## 不変条件

- `I1`: 新しい設定を省略した入力の行位置とページ分割は、変更前と等しい。
- `I2`: 自由な配置で同じ段に置く同じ段落の隣接する行の基準位置の差は、解決した行送りと等しい。
- `I3`: 罫線、囲み、明示的なアキ命令を挟まない同じ段内の隣接段落の中心位置の差は、前後の行送り p と q、選択したアキ s に対し、`p - floor(p / 2) + floor(q / 2) + s` sp に等しい。
- `I4`: 段落間のアキを変えても各段落の行送りは変わらず、文字列と各行の行長が等しければ行分割も変わらない。
- `I5`: 段の先頭には段落前後のアキと段落間のアキを置かない。
- `I6`: 格子モードの寸法指定と、不正な寸法は、配置を始める前にエラーとなる。
- `I7`: Emet が返した段落と原稿に直接書いた同じ段落は、同じスタイルなら同じ位置に組まれる。
- `I8`: 自由な配置の各段で、配置した行ボックス、ブロックの占有領域、脚注予約領域、囲みの追加分は、許可した版面外罫線と G07100 で知らせる見出しの超過を除き、段の区間内に収まる。
- `I9`: 脚注の区切り領域は、脚注のある段に一度だけ予約され、本文の行送りを変えても脚注一行の長さ P は変わらない。
- `I10`: 回り込みの図版と脇の行を同じ量だけ移しても、行長とインデントは変わらない。
- `I11`: 罫線の領域と位置、囲みの各部分の範囲は、収まり判定と描画が共有する解決結果と等しい。
- `I12`: 自由な配置でも、同じ境界の空きを need-lines の前後に移すだけでは、行の配置と制御の未達記録は変わらない。
- `I13`: 本文、囲み、注、非段落ブロックの最小部分が調整前の空の段にも入らない場合は、有限の処理で対応する diagnostics か図版の縮小へ到達し、空の段を作り続けない。
- `I14`: 同じ入力を並列と逐次で組んだ結果は、配置位置、diagnostics の順序、PDF のバイト列が等しい。

## 受けいれ条件

- `A1`: プロジェクトで指定した台詞の行送り、台詞間のアキ、ト書きの行送りを、横組みと縦組みの PDF に反映でき、同じ原稿を別の設定で組み直せる。
- `A2`: 継承、`@style-def`、Emet のブロック命令を通して指定しても、同じ配置になる。
- `A3`: HTML と EPUB が指定した行送りと追加のアキを CSS に出力する。
- `A4`: 既存の格子モードの回帰テストが通り、自由な配置の改ページで行が欠落せず、重複しない。
- `A5`: 脚注、回り込み、罫線、囲み、段組み、改ページの手での制御を含む自由な配置で、実寸の収まり判定と描画位置が一致する。
- `A6`: 明示的に free を選ばない既存の原稿は、配置と diagnostics と PDF のバイト列が変わらない。

## テスト設計

境界表の数値は計算を検査するテスト入力であり、台本の既定値ではない。

実装前に、設定の読み込み、継承、配置、改ページ、CSS 出力の順で失敗するテストを書く。
テスト名は `root ADR 0397 I2: ...` のように、不変条件か受けいれ条件の番号を含める。

I1 は既存の格子モードの配置のスナップショットと比較する。
I2 から I5 は、既知の行ボックスを入力し、描画に渡る位置を sp で比較する。
段をまたぐ同じ段落でも行送りの設定を保つことと、アキで回り込みの行長が変われば行分割をやり直すことを、A4 の回帰テストに加える。
I6 は単位、値の境界、継承後の不正な値を表駆動で検査する。
I7 と A2 は同じ本文を直接指定と Emet で作り、生成した意味論 IR と組版位置を比較する。

A1 と A4 では、複数ページの台本に一行と複数行の台詞、ト書き、色の異なる台詞、明示改ページ、保持指定を混在させる。
横組みと縦組みで行位置とページ分割を検査し、PDF を描画して文字の欠落と囲みのずれを目視する。
A3 では生成 CSS の値を検査し、HTML をブラウザーで表示して段落間の余白が二重に入らないことを確かめる。

### 改ページ周辺の検証

I8 で検査する占有領域は、字形や枠線の輪郭そのものとは区別する。
小さい行送りでの字形の張り出しと、辺を中心に引く枠線の半分の張り出しを、占有領域の超過として誤って拒否しない。

I8 から I13 は、段の長さ、行送り、字面、アキを小さな整数 sp で表した境界テストを先に書く。
浮動小数点の許容誤差で合格にせず、1sp 単位で一致を比較する。
脚注のある通常段落と罫線付き段落の例外、囲みの各分割部分の padding、段端と途中から始まる段の罫線を別々に検査する。
G07129 から G07131 では、diagnostic の位置と PDF 生成の失敗も確かめる。
見出し、表、コード、図版について、従来の行数では入るが実寸では入らない境界と、調整した段にだけ入らない境界を検査する。
G07100 で知らせる見出しの超過は I8 の例外として、通常の過大な見出し G07024 と区別する。

保持のテストは、同じ行数で異なる行送りの段落を並べる。
表示行数による保持対象が変わらず、収まるかだけが変わることを検査する。
need-lines と page-lines は、P の倍数と倍数でない本文使用量、待つ図版、続きの注、前後のアキを組み合わせる。
page-lines を減らすときは、すでに配置した量より短くしない整数の増減へ切り詰めることを確かめる。

回り込みは、図版の先頭、除外矩形の終わりにちょうど接する行、最後の脇の行が段からあふれる場合、脚注で脇の行を送る場合を検査する。
図版ごとの相対位置を使うことと、短く組んだ続きの行を保持することを検査し、ページ移送に伴う行分割の反復を実装していないことも確かめる。
S2 を使うページ参照入りの原稿を含める。

A5 と I14 は横組みと縦組み、奇数と偶数ページで座標を検査し、同じ入力の並列と逐次の PDF を比較する。
A6 には既存の格子モードの golden と改ページの不変条件のテストを使う。
新しい自由な配置の小さな列挙テストでは、空の流れ、一行、異なる長さの二段落、注、空き、囲みの分割を生成し、行の欠落と重複、領域の超過を検査する。
性能の予算や既存の列挙テストの実行頻度は変更しない。

## トレードオフ

自由な配置では、見開きの行位置はそろわなくなる。
台本の間隔を寸法で指定するための選択であり、書籍本文には既定の格子モードを使い続けられる。

文書全体でモードを選ぶと、段落ごとに格子へ戻る位置を定義する必要がなくなる。
一方、同じ本の一部分だけを自由な配置にする用途には対応しない。
既存の行数による改ページ処理への影響は広く、設定のパーサーだけでは実装を終えられない。

## 採択する設計

この提案では、文書全体で `alignment = "free"` を明示する方式を採る。
個々の段落が格子へ戻る方式は今回の対象にしない。
著者はプロジェクトごとにモードとスタイルを定義し、Emet はスタイル名を付ける。
改ページ周辺の規則と実装の変更箇所は調査済みであり、実装時にはこの文書の不変条件と受けいれ条件で検証する。
この調査は現行ソースの確認と設計の具体化であり、自由な配置の実装や動作確認を済ませたという意味ではない。

# ADR 0407: 色を置き換えられない SVG 図版はエラーにする

Status: accepted

## 文脈

[root ADR 0403](0403-include-grayscale-tones-in-single-color-figures.md) は SVG を含む単色図版の色を置き換える。
HTML と EPUB がそのまま表示できる SVG の範囲は、PDF に描ける SVG の範囲より広い。
色を指定したのに元の色で出力することを避けるため、色の判定と置き換えができない場合の扱いを補足する。

## 調査した事項

[golem-pdf ADR 0009](../golem-pdf/adr/0009-svg-figures.md) は、PDF に描く SVG の要素と属性の範囲を定め、輪郭にしていない文字などを対象外にしている。
実装中の図版の色指定では、SVG を描画データとして読んでから色を判定している。
指示者は 2026-11-22 に、色を変換できない SVG はエラーにする案を選んだ。

## 実装すること

図版の描画色を指定し、SVG の描画色を判定できないか、指定色への置き換えができない場合は、G08113 のエラーにする。
その図版を含む対象媒体の生成を中止し、その媒体の古い出力を成功した成果物として残さない。
単色か多色かを判定できない場合も、元の色のまま生成を成功させない。
PDF、HTML、EPUB に同じ規則を適用する。

図版の描画色を指定しない場合は、従来の SVG の受け入れ範囲と出力を変えない。
HTML と EPUB にそのまま写せた SVG を、今回の色置換の対応範囲だけを理由に拒まない。
判定できた多色の SVG は、root [ADR 0403](0403-include-grayscale-tones-in-single-color-figures.md) に従って元の色を保つ。

## 実装しないこと

SVG の PDF 描画で対応する要素と属性は増やさない。
外部の変換器へ SVG を渡さない。
JPEG、PNG、取り込んだ PDF の対応範囲は変えない。

## 不変条件

I1: 色を指定した SVG の色を判定または置換できない場合は、G08113 を出し、対象媒体を生成しない。
I2: 色を指定しない SVG の受け入れ範囲と出力は、この補足の前と一致する。
I3: 判定と置換ができる SVG の濃淡、一色、多色の扱いは [root ADR 0403](0403-include-grayscale-tones-in-single-color-figures.md) と一致する。

| 入力 | 期待 | 不変条件 |
| --- | --- | --- |
| 色指定あり、対応範囲の白黒の図 | 指定色の濃淡 | I3 |
| 色指定あり、対応範囲の多色の図 | 元の色を保持 | I3 |
| 色指定あり、判定できない SVG | G08113、対象媒体を生成しない | I1 |
| 色指定あり、壊れた SVG | G08113、対象媒体を生成しない | I1 |
| 色指定なし、従来 Web 出力に写せた SVG | 従来の出力 | I2 |

## 受けいれ条件

A1: 通常 CLI の PDF、HTML、EPUB で、対応範囲の色置換と、対応できない SVG の失敗を照合する。

## テスト設計

root ADR 0407 I1、I2、I3 の試験で、単色、濃淡、多色、対応できない要素と属性、破損、色指定の有無を検査する。
古い成果物を先に置き、失敗時には残らないことも検査する。
root ADR 0407 A1 は、通常 CLI の生成物、diagnostic と終了コードを照合する。

## トレードオフ

色の指定に従わない出力を成功として渡すことを避ける。
HTML と EPUB では色を指定しなければ使える SVG でも、色を指定するとエラーになる場合がある。

# ADR 0421: EPUB の一致を同じバージョンで保証し、プロジェクトの外のフォントをどの出力でもエラーにする

Status: proposed

## 文脈

[ADR 0361](0361-epub-byte-determinism.md) は、同じ Golem の「ビルド」と同じ入力から、EPUB のバイト列が一致することを保証した。
一方、互換性の約束（`docs/compatibility.md`）は、出力について「同じバージョンと同じ入力からは、同じバイト列を得る」と書く。
二つの条件が食い違っている。
0361 は、プロジェクトの外を指す素材の扱いも決めていない。

tett23 は 2026-11-18 に、一致の条件を同じバージョンとし、プロジェクトの外の素材はエラーにすることを決めた。
2026-11-23 には、v1 で決定性を保証すると述べた。

## 調査した事項

`origin/main`（`2ac7fb273`）で確かめた。

- [ADR 0361](0361-epub-byte-determinism.md) は、「同じ Golem のビルド、設定、原稿、素材で EPUB 全体のバイト一致を保証する」「同じビルドには EPUB を構成する圧縮器の版も含む」「異なるビルド間の一致は保証しない」と書く。
- 仕様書は、一致の条件を同じビルドとし（[docs/specifications.md](../specifications.md) の 1349 行）、「異なるビルドの間の一致は保証しない」と書く（同 1354 行）。
  同じ節は、`cabal.project.freeze` が依存の版を固定するので、同じバージョンの配布物は同じ圧縮器を使うと書く。
- `docs/compatibility.md` の 18 行は、同じバージョンと同じ入力からは同じバイト列を得ると約束する。
- プロジェクトの外を指す素材は、次のとおり扱う。
  - `@figure`、`@table`、`@listing` のパスの `..`、外を指すシンボリックリンク、絶対パス、URL は、エラー G02060 である。
  - 章、import、参考文献などのパスは、エラー G03003 である。
  - フォントのパスは、PDF では G08002 のエラーであり、外を指せば `pathErrorMessage` の文を出す。
    プレーンテキストは、フォントのパスを調べない。
    HTML と EPUB では、[`missingStyleFiles`](https://github.com/tett23/golem/blob/2ac7fb273d6e26d3b42d57eef76f8f1ddd0634e2/modules/golem-driver/src/Golem/Driver.hs#L1160-L1161) が見つけた外のパスを [`targetFileDiagnostics`](https://github.com/tett23/golem/blob/2ac7fb273d6e26d3b42d57eef76f8f1ddd0634e2/modules/golem-driver/src/Golem/Driver.hs#L1171-L1172) が出し、G03010 として dev では警告、prod ではエラーになる。
    HTML と EPUB は、プロジェクトの中にあるフォントのファイルを同梱し（[docs/specifications.md](../specifications.md) の 4597 行）、外を指すフォントは同梱せずに出力する。
    同じ関数は、出力インテントの ICC プロファイルのパス（`stIntent`）も調べる。
- G03010 は、フォントのファイルがないこと、プロジェクトの外を指すこと、中身が読めないことを一つのコードに束ねている（2026-11-17 の監査の候補）。
- EPUB が取り込む素材の種類のうち、図版、表、コードとフォントのほか（表紙など）があるかは、確かめていない（未確認）。

## 実装すること

### 一致の条件

- EPUB のバイト列の一致の条件を、同じ Golem のバージョン、同じ設定、原稿、素材とする。
  同じバージョンの配布物は、`cabal.project.freeze` で同じ圧縮器の版を使うので、この条件はバージョンで言える。
- 圧縮器（zip-archive、zlib、同梱の C の zlib である zlib-clib）の版を変えると、同じ入力からでも EPUB のバイト列が変わりうる。
  互換性の約束は、パッチのバージョンでは出力を変えないとしているので、圧縮器の版を変えるのは minor のバージョンに限る。
  `docs/compatibility.md` の出力の行に、このことを書き足す。
- 仕様書の 1349 行と 1354 行を、この条件に直す。
- 採択したら、[ADR 0361](0361-epub-byte-determinism.md) のステータスの行に、部分「一致の条件（同じビルド）」をこの ADR による置き換えとして足す。

### プロジェクトの外の素材

- `style.toml` が指すファイル（フォントと出力インテントの ICC プロファイル）のパスがプロジェクトの外を指すときは、どの出力、どのプロファイルでもエラーにする。
- この原因に新しいコード G03279 を振る（「`style.toml` のファイルのパスがプロジェクトの外を指す」）。
  G03010 と G08002 からこの原因を外し、PDF でも G03279 だけを出す。
  プレーンテキストでも、このパスを検査する。
- 実装の前に、EPUB と HTML が図版、表、コード、フォント、出力インテントのほかの素材を取り込むかを確かめる。
  ほかにあれば、それも外を指すときはエラーにし、その素材の種類を実装のプルリクエストに書く。
- ほかの素材（図版、表、コード、章、import、参考文献）は、今と同じくエラー（G02060、G03003）のままとする。
- 新しいコードを `docs/diagnostics.md` に足し、組み込みの写しを作り直す。

## 実装しないこと

- 異なるバージョンのあいだの一致は保証しない。
- PDF と HTML の一致の条件は、この ADR では変えない（互換性の約束のとおり、すでに同じバージョンである）。
- G03010 のほかの原因（ファイルがない、中身が読めない）の分け方は、この ADR では変えない。

## 不変条件

- I1：同じバージョンの `golem` で、同じ設定、原稿、素材から、作業ディレクトリと時刻を変えて作った EPUB は、バイト単位で等しい。
- I2：プロジェクトの外を指すフォントか出力インテントのパスを書いたどの本でも、どの出力、どのプロファイルでも、diagnostic はそのパスについて G03279 のエラーをちょうど一つ含み、G03010 も G08002 も含まない。
- I3：プロジェクトの中のフォントの本の diagnostic は、この ADR の前と同じである。

| 入力 | 期待 | 不変条件 |
| --- | --- | --- |
| 同じ本を別のディレクトリで、別の時刻に組む | 全バイト一致 | I1 |
| 素材の列挙順だけが違う | 全バイト一致 | I1 |
| フォントのパスが `../fonts/a.otf`、EPUB、dev | G03279 のエラー | I2 |
| 同じ、HTML、prod | G03279 のエラー | I2 |
| 同じ、PDF | G03279 のエラー | I2 |
| 外を指すシンボリックリンクのフォント | G03279 のエラー | I2 |
| 絶対パスのフォント | G03279 のエラー | I2 |
| 外を指す出力インテントの ICC | G03279 のエラー | I2 |
| 外を指すフォント、プレーンテキスト | G03279 のエラー | I2 |
| プロジェクトの中のフォント | 前と同じ | I3 |
| プロジェクトの中にない名前のフォント | G03010（前と同じ） | I3 |

## 受けいれ条件

なし。
この ADR の振る舞いは、不変条件のテストで確かめる。

## テスト設計

- 名前は `root ADR 0421 I<番号>: ...` とする。
- I1 は、今の [ADR 0361](0361-epub-byte-determinism.md) のテストの名前を、この ADR の番号に付け直して残す。
- I2 は、golem-driver のテストで、PDF、HTML、EPUB、プレーンテキストと dev、prod のすべての組で確かめる。
  実装の前に、HTML と EPUB の dev で警告になることを確かめて失敗させる。
- I3 は、今のフォントのテストが変わらないことで確かめる。

## トレードオフ

dev で警告だった本は、エラーになり組めなくなる。
HTML と EPUB は外を指すフォントを同梱せずに出力するので、今はその本でも出力を得られていた。
プロジェクトの外のフォントは、別のマシンで同じ本を組めない原因になるので、どの出力でも止める。

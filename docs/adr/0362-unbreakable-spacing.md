# ADR 0362: 分割禁止の字間を行の調整で伸ばさない

ステータス: 採択

## 文脈

行分割と禁則のうち、書き手が必要とする「行の調整で空けない字間」の扱いを決める。

## 調査した事項

今は分割の候補を消すだけで、漢字等どうしの 1/10 em の伸びが残るので、空いた行では `１２３` の字のあいだも他の字のあいだと同じだけ空く（[golem-layout ADR 0049](../golem-layout/adr/0049-align-the-character-classes-and-unbreakable-pairs-with-jlreq.md)）。

## 実装すること

分離禁止文字の連続、連数字、前置省略記号と数、数と後置省略記号の境界では、アキ量のセットを解決した後に伸びの上限を 0 にする。
固定アキと縮みは保存し、カスタムセットにも同じ規則を適用する。
設定の書式は維持する。

禁則判定が使う文字クラスと境界判定をアキ量の計算でも共有する。
数字列の外側では通常のアキ量のセットを適用する。

## 実装しないこと

強制改行の意味は変えない。

## 不変条件

1. 対象となる全境界の調整による伸びの和は、配分する余白の量にかかわらず 0 である。

| 境界の入力 | 期待する結果 |
| --- | --- |
| １２３ | 内部2境界の伸び0 |
| 数字1字 | 対象境界0 |

## テスト設計

- `inv1_unbreakable_spacing_property` で次の述語を検査する。対象となる全境界の調整による伸びの和は、配分する余白の量にかかわらず 0 である。
- `inv1_unbreakable_spacing_case_1` は「１２３」を入力とし、「内部 2 境界の伸び 0」を確かめる。
- `inv1_unbreakable_spacing_case_2` は「数字 1 字」を入力とし、「対象境界 0」を確かめる。

## トレードオフ

調整可能な字間が減るため、余白を他の字間で吸収できない行が生じる。

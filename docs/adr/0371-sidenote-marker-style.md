# ADR 0371: 傍注の印に文字スタイルを指定する

ステータス: 採択（未実装）

## 文脈

スタイルのうち、書き手が必要とする「傍注の `※` の印」の扱いを決める。

## 調査した事項

Golem [ADR 0177](0177-note-mark-style-and-numerals.md) の調査は、次の扱いを記録している。
印の位置の見た目のまま組み、文字スタイルを当てる手段がない（[`Japanese.hs`](https://github.com/tett23/golem/blob/50b9fca8a0744f6f9d92808db231e6c04ac35d2c/modules/golem-layout/src/Golem/Layout/Japanese.hs#L301-L305)）。

## 実装すること

傍注の印の文字スタイルを本文中の ※ にだけ適用する。
省略時は印を挿入した位置の見た目を継承する。
印の幅は適用後に測る。

[sidenotes]の marker-style には文字スタイル名を指定し、傍注本文の sidenote とは別に解決する。

## 実装しないこと

既存の原稿を新しい指定へ自動変換する機能は設けない。

## 不変条件

1. 印のスタイルだけを変更しても、傍注本文のスタイルは変わらない。

| 境界の入力 | 期待する結果 |
| --- | --- |
| 指定なし | 周囲と同色 |
| 色を指定 | 印だけ指定色 |

## テスト設計

- `inv1_sidenote_marker_style_property` で次の述語を検査する。印のスタイルだけを変更しても、傍注本文のスタイルは変わらない。
- `inv1_sidenote_marker_style_case_1` は「指定なし」を入力とし、「周囲と同色」を確かめる。
- `inv1_sidenote_marker_style_case_2` は「色を指定」を入力とし、「印だけ指定色」を確かめる。

## トレードオフ

印を独立に測るため、印の指定を変えると本文が折り返す場合がある。

# ADR 0365: 隠しノンブルの書体と色を選ぶ

ステータス: 採択（未実装）

## 文脈

スタイルのうち、書き手が必要とする「隠しノンブル」の扱いを決める。

## 調査した事項

Golem [ADR 0177](0177-note-mark-style-and-numerals.md) の調査は、次の扱いを記録している。
本文の役割の書体で、`[hidden-folio]` の `size` だけを変えられる（[`hiddenMarks`](https://github.com/tett23/golem/blob/50b9fca8a0744f6f9d92808db231e6c04ac35d2c/modules/golem-driver/src/Golem/Driver/Pdf/Draw.hs#L1041-L1054)）。

## 実装すること

hidden-folio の character-style を隠しノンブルだけに適用する。
G03029 と G07050 の重なりの判定にも、優先順位を解決した後の実効サイズを使う。
既存の size を明示した場合は文字スタイルのサイズより優先する。

明示サイズがなく文字スタイルにもサイズがなければ、現行の隠しノンブルの既定値を使う。

## 実装しないこと

既存の原稿を新しい指定へ自動変換する機能は設けない。

## 不変条件

1. 描画とノド側の重なりの検査が用いる隠しノンブルのサイズは一致する。

| 境界の入力 | 期待する結果 |
| --- | --- |
| size のみ | 従来のサイズ |
| 両方指定 | 書体と色はスタイル、サイズは size |

## テスト設計

- `inv1_hidden_folio_style_property` で次の述語を検査する。描画とノド側の重なりの検査が用いる隠しノンブルのサイズは一致する。
- `inv1_hidden_folio_style_case_1` は「size のみ」を入力とし、「従来のサイズ」を確かめる。
- `inv1_hidden_folio_style_case_2` は「両方指定」を入力とし、「書体と色はスタイル、サイズは size」を確かめる。

## トレードオフ

従来の size を優先するため、スタイルだけでサイズを一括変更するには個別の size を外す必要がある。

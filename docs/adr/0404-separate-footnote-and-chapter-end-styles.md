# ADR 0404: 脚注と章末注の段落スタイルを別々に指定する

Status: proposed

## 文脈

[root ADR 0366](0366-note-body-styles.md) は脚注本文と章末注本文に別々の段落スタイルを選ぶと決めた。
現在の共通設定に加えて、配置先別の設定を定める。

## 調査した事項

現在のロードマップは、[notes]の body-style が両方の注本文に同じスタイルを当てると記載している。
同項目は、配置先ごとの設定キーを未決としている。

## 実装すること

[notes.footnote]の body-style で脚注本文の段落スタイルを指定する。
[notes.chapter-end]の body-style で章末注本文の段落スタイルを指定する。
[notes.chapter-end]の heading-style で章末注一覧の見出しの段落スタイルを指定する。
値は既存の段落スタイル名とし、存在しない名前は既存のスタイル参照 diagnostic で拒む。

本文は、配置先の body-style、共通の[notes].body-style、本文の役割の書体と版面の文字の大きさの順で選ぶ。
一覧見出しは、[notes.chapter-end].heading-style、共通の[notes].heading-style、第 2 階層見出しの既定の順で選ぶ。
適用する段落スタイルの範囲と各媒体への反映は root [ADR 0366](0366-note-body-styles.md) に従う。
本文中で注を呼び出す印には本文のスタイルを伝えない。
注本文先頭の印は、既存の body-mark-style を明示した場合にその指定を使い、省略した場合は配置先の注本文の書体と大きさを使う。
この区別を root [ADR 0366](0366-note-body-styles.md) の「注の印」の適用範囲の補足として記録する。

## 実装しないこと

新しい注チャネルや、注ごとに配置先を選ぶ記法は追加しない。

## 不変条件

I1: 一方の配置先の body-style だけを変えても、他方の実効本文スタイルは変わらない。
I2: 配置先別の指定を省略した入力の実効スタイルは、変更前の同じ入力と一致する。
I3: 本文と一覧見出しの指定を変えても、本文中で注を呼び出す印の実効スタイルは変わらない。

| 入力 | 期待 | 不変条件 |
| --- | --- | --- |
| 配置先の指定なし | 従来の共通設定と既定を使う | I2 |
| 脚注だけ指定 | 章末注の実効スタイルは変わらない | I1 |
| 共通設定と脚注の設定 | 脚注だけ配置先の設定を優先する | I1 |
| 一覧見出しだけ指定 | 本文と呼出印は変わらない | I3 |

## 受けいれ条件

A1: 通常 CLI で生成する PDF の注本文に、配置先の設定が反映される。

## テスト設計

root ADR 0404 I1、I2、I3 を名前の先頭に置いた試験で、省略と上書き、配置先間と印の独立性を検査する。
存在しない段落スタイル名と値の型の誤りも設定の読み込みで検査する。
root ADR 0404 A1 の試験では同じ原稿を脚注配置と章末配置で通常 CLI から生成し、本文の書体、サイズ、色を出力から照合する。

## トレードオフ

共通設定を保つため、既存の入力は同じ指定で使える。
配置先の指定を加えると、実効値を調べる際に共通設定も確認する必要がある。

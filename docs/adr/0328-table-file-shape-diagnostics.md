# ADR 0328: 空の表と列数の違う行に別の diagnostics を出す

ステータス: 採択（未実装）

## 文脈

`@table` で読む CSV または TSV が空のときは、少なくとも見出しの行を書き足す必要がある。
見出しの行とデータ行の列数が違うときは、指された行の区切りを直す。
現行の G02085 はどちらも指す。
前者の位置は表のファイルの先頭、後者の位置は列数の違う最初の行である。

## 実装すること

空の表には G02085 を残し、列数の不一致に G02154 を割り当てる。
メッセージには既存の見出し行とデータ行の列数を保つ。
G02085 を条件に表の構造を検査している CI は、新たに G02154 も扱う。

## 実装しないこと

CSV または TSV の空行の解釈、CSV の引用符、テーブルを読み込む条件は変えない。
セルが一つだけの有効な表を空とは扱わない。

## 不変条件

1. T1：読み取った行が 0 行の場合は G02085、見出しと列数の違う最初のデータ行には G02154 を一度返す。
2. T2：ファイル内の位置は、空ならバイト 0、列数が違えば該当するレコードである。

| 入力 | 結果 |
| --- | --- |
| 0 バイト | G02085 |
| 見出し一行 | どちらも出ない |
| 二列の見出しと一列の行 | G02154 |
| 二列の見出しと二列の行 | どちらも出ない |

## テスト設計

未コミットの `experiments/diagnostics/baseline.mjs` は CSV と TSV について、空、不一致、一致の六つを `build --target html` に渡す。
`expected.mjs` の T1 は各コードと表のファイル名、行を検査する。
基準版では空と不一致がいずれも G02085 であった。
本実装の T2 では引用符の中の改行をまたぐ CSV の範囲も検査する。

## トレードオフ

既存の G02085 に対応していた CI はコードの追加が必要になる。
空の表を自動生成したツールと、行の区切りを直す書き手とで、報告を振り分けられる。

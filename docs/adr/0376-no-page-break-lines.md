# ADR 0376: 改ページで前の段落から送る行数を指定する

ステータス: 採択（未実装）

## 文脈

ページ分割のうち、書き手が必要とする「`@no-page-break` で送る行の数の設定」の扱いを決める。

## 調査した事項

Golem [ADR 0055](0055-no-page-break-moves-short-paragraphs-whole.md) は、前の段落または定義リストの用語が 3 行以下なら全体、4 行以上なら末尾 2 行を送ると定めている。

## 実装すること

`@no-page-break N` は、`@blank-line N` と同じく自然数（0 を含む）の位置引数を一つ指定できる。
既定は 2 行とする。
前にある段落と定義リストの用語に適用する。
既存の keep-with-next と同じ位置なら、両方が要求する行数の大きい方を使う。
末尾から指定数だけ取り、前に残るのが 1 行以下なら全体を送る。
孤立行の規則が要求する最小行数を優先し、空の段で守れないときは既存の G07037 に従う。

たとえば `@no-page-break 3` は末尾 3 行を指定する。
HTML と EPUB では 0 の指定から改ページを抑える CSS を生成しない。
0 はこの命令による連動を要求しない値とし、段落自身の孤立行規則や keep-with-next は通常どおり適用する。
負数と整数でない数は自然数の既存の規則に従い、それぞれ G02103 と G02104 とする。
キーワード引数と余分な位置引数は G02096、単独の数でない値は G02156 とする。

## 実装しないこと

段落をまたぐ大域的な改ページ最適化は扱わない。

## 不変条件

1. 収まる段で末尾を送った後、前の段に残る行数は 0 か 2 以上である。

| 境界の入力 | 期待する結果 |
| --- | --- |
| 既定で3行 | 全体 |
| 既定で4行 | 2行 |
| `@no-page-break 0` | この命令による追加の連動なし |
| 5行の段落に `@no-page-break 3` | 前に2行を残して3行を送る |
| 引数が -1、1.5 | それぞれ G02103、G02104 |

## テスト設計

- `inv1_no_page_break_lines_property` で次の述語を検査する。収まる段で末尾を送った後、前の段に残る行数は 0 か 2 以上である。
- `inv1_no_page_break_lines_case_1` は「既定で 3 行」を入力とし、「全体」を確かめる。
- `inv1_no_page_break_lines_case_2` は「既定で 4 行」を入力とし、「2 行」を確かめる。
- `inv1_no_page_break_lines_case_3` は位置引数に 0、3、負数、小数を渡し、表の行数と diagnostic を確かめる。

## トレードオフ

孤立行を避けるため、送る行が書き手の指定より多くなる場合がある。

# ADR 0313: 罫線、コード、段の切り替え、手動制御、表、回り込む図版を並べて改ページを確かめる

ステータス: 採択

## 文脈

Golem [ADR 0312](0312-enumerate-length-and-heading-rounding.md) の見出しでは、必要な行数と占める領域をそれぞれ確かめた。
ページ分割でも、入力した行が出力に残ることと、各行が段内に収まることを別の述語にする。
[golem-layout ADR 0025](../golem-layout/adr/0025-need-lines-and-blank-lines-after-figures-sent-on.md) が判断を委ねた表と回り込む図版も含める。

## 実装すること

専用の小さな列挙に、罫線付きの段落、コード、二段への切り替え、元の段への復帰、必要行数、空行、段の行数の調整、改ページの禁止、表、回り込む図版を加える。
行を持つ各要素に異なる ID を振る。
コードの出力は先頭 ID と行数から個々の行に戻し、表の本文行と回り込む図版の横の行も数える。
PR 用の候補は、容量 3 から 5 行の段に 0 から 3 個を並べた全組み合わせとする。
本実装時に [ADR 0281](0281-budgets-of-the-exhaustive-tests-and-what-moves-to-the-nightly-job.md) の方法で時間を測り、予算を超えた段は毎晩のジョブに移す。

## 実装しないこと

この専用の列挙では表の見出しの繰り返し、段より高い要素、注の継続は扱わない。
既存の列挙と個別テストが扱う入力は、そのまま検査する。

## 不変条件

1. P1：入力した本文行の ID を多重集合として数えると、出力した本文行と一致し、回り込む図版の ID もそれぞれ一度だけ現れる。
2. P2：段に置いた各項目の開始行は 0 以上で、その段の有効行数より小さい。

| 境界の入力 | 期待する結果 |
| --- | --- |
| 空の流れ | 出力した本文行は 0 行 |
| 空行、表、段の復帰 | 表の本文行を 1 回数える |
| 回り込む図版と罫線付き段落 | 図版とそれぞれの本文行が残る |
| 段の行数の調整後 | 調整後の段の有効行数で P2 を調べる |

## テスト設計

未コミットの `experiments/formal/Pagination.hs:8` は、10 要素から重複を許して並びを作る。
`experiments/formal/compile.sh experiments/formal/Pagination.hs` は、3333 入力で終了コード 0 だった。
本実装ではテスト名に P1 と P2 を付け、最初の反例の段の容量と要素列を出力する。
広い入力を扱う段階では、表の見出しと本文の ID を区別してから、見出しの繰り返しを足す。

出力の本文行を無視する対照は、罫線付きの段落一つを置く入力で失敗した。
再現には試作のルートで `experiments/formal/mutations.sh` を使う。

## トレードオフ

既存の列挙の各段に 10 種類を足すと、保持の設定や囲みとの直積が増える。
専用の列挙では候補数を固定できるが、既存要素とのすべての組み合わせは含まれない。
試作の P2 は項目の開始行を検査するため、複数行の表や図版の下端の検査には別の述語が要る。

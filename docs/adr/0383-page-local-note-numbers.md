# ADR 0383: ページ別の注番号を幅の予約後に振る

ステータス: 採択（未実装）

## 文脈

本の部品の拡張のうち、書き手が必要とする「チャネルの番号をページごとに振り直す方式」の扱いを決める。

## 調査した事項

今の注の番号は、章（既定）、ファイル、本の全体のどれかの範囲で、文書の組み立て（S1）で振る。

## 実装すること

[notes]の numbering に新しい値 page を指定した場合、チャネル内の注の総数を上限として、1 から上限までの印を実際の書体と書式で測り、最大幅を全ての印に予約する。
注本文側の番号にも同じ予約を適用する。
配置後に呼出位置の物理ページとチャネルごとに原稿順で 1 から番号を振り、予約幅を保ったまま描く。
固定ページを持たない出力では指定に対する diagnostic を出す。

ページ別の番号を持つ注を参照する箇所にも同じ予約幅を使う。
予約のキーには実効スタイル、縦横、番号の前後の文字を含める。

## 実装しないこと

番号を振った後に版面を詰め直さない。

## 不変条件

1. 同じチャネルの各物理ページの呼出順の番号列は 1 からそのページの件数までの連続した整数列である。

| 境界の入力 | 期待する結果 |
| --- | --- |
| 注なし | 予約0 |
| 同じページに2件 | 1、2 |
| 次ページの先頭 | 1 |
| 番号確定後の再改ページ | 0回 |

## テスト設計

- `inv1_page_local_note_numbers_property` で次の述語を検査する。同じチャネルの各物理ページの呼出順の番号列は 1 からそのページの件数までの連続した整数列である。
- `inv1_page_local_note_numbers_case_1` は「注なし」を入力とし、「予約 0」を確かめる。
- `inv1_page_local_note_numbers_case_2` は「同じページに 2 件」を入力とし、「1、2」を確かめる。
- `inv1_page_local_note_numbers_case_3` は「次ページの先頭」を入力とし、「1」を確かめる。
- `inv1_page_local_note_numbers_case_4` は「番号確定後の再改ページ」を入力とし、「0 回」を確かめる。

## トレードオフ

再配置が要らない代わりに、短い番号の横にも最大幅との差が残る。

# ADR 0372: 番号と題の区切りを段落スタイルで選ぶ

ステータス: 採択（未実装）

## 文脈

スタイルのうち、書き手が必要とする「番号と題のあいだの区切りの設定」の扱いを決める。

## 調査した事項

ロードマップの「スタイル」は「番号と題のあいだの区切りの設定」を v1.0.0 の対象に挙げている。

## 実装すること

段落スタイルの number-title-separator に文字列を指定する。
番号付き見出し、図、コード、表のキャプションで番号と題の両方があるとき一度だけ挿入し、省略時は本の言語の既定値を使う。

番号と題を表示する目次と柱も、元の見出しに指定した区切りを用いる。

## 実装しないこと

既存の原稿を新しい指定へ自動変換する機能は設けない。

## 不変条件

1. 番号か題の少なくとも一方が空なら、区切りとして生成する文字列は空である。

| 境界の入力 | 期待する結果 |
| --- | --- |
| 空文字列 | 区切りなし |
| 題のみ | 区切りなし |
| 両方あり | 指定文字列1回 |

## テスト設計

- `inv1_number_title_separator_property` で次の述語を検査する。番号か題の少なくとも一方が空なら、区切りとして生成する文字列は空である。
- `inv1_number_title_separator_case_1` は「空文字列」を入力とし、「区切りなし」を確かめる。
- `inv1_number_title_separator_case_2` は「題のみ」を入力とし、「区切りなし」を確かめる。
- `inv1_number_title_separator_case_3` は「両方あり」を入力とし、「指定文字列 1 回」を確かめる。

## トレードオフ

区切りを文字列に限定すると、区切り自体には個別の装飾を付けられない。

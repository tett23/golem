# ADR 0377: ページと見開きの境で部品を分ける位置を定める

ステータス: 採択（未実装）

## 文脈

ページ分割のうち、書き手が必要とする「ページと見開きをまたぐ泣き別れの禁止」の扱いを決める。

## 調査した事項

段落の単位の設定は仕様書の「改ページ」の節の段落スタイルの欄（[ADR 0261](../adr/0261-keep-options-of-paragraph-styles.md)）で、見開きの単位の最適化は v2 以降の「改ページの大域の最適化」で扱うので、この項目はそれ以外のまとまりを扱う。

## 実装すること

既存の表は行間で分け、続きのページでは見出し行を繰り返す（[仕様書](../specifications.md)）。
表は行間、リストは項目間、定義リストは用語と最初の説明行の後を分割候補にする。
図とキャプションは一組とする。
ページを単位とする指定では各ページ、見開き指定では対向する 2 ページの外側だけで保持条件を課す。
見開き指定では、現在の見開きに収まるかだけを調べ、複数の見開きを比較して過去の分割位置を選び直さない。
一単位に収まらない組は次単位への移動を一度だけ試し、表の行や項目内の行など通常の分割位置を使う。

表の見出しは最初のデータ行と、定義用語は説明の最初の行と同じ単位に置く。
分割できない図または単独の表の行が空の領域にも収まらない場合は、その部品の既存の寸法エラーを出す。

## 実装しないこと

見開き全体を最適化する探索は扱わない。

## 不変条件

1. 一度空の配置単位で失敗した同じ部品を、同じ条件の空の単位へ無限に送り直さない。

| 境界の入力 | 期待する結果 |
| --- | --- |
| ちょうど収まる | 移動0 |
| 空の単位にも収まらない | 同じ組を繰り返し送らない |

## テスト設計

- `inv1_keep_book_parts_property` で次の述語を検査する。一度空の配置単位で失敗した同じ部品を、同じ条件の空の単位へ無限に送り直さない。
- `inv1_keep_book_parts_case_1` は「ちょうど収まる」を入力とし、「移動 0」を確かめる。
- `inv1_keep_book_parts_case_2` は「空の単位にも収まらない」を入力とし、「同じ組を繰り返し送らない」を確かめる。

## トレードオフ

まとまりを保つと、直前のページに使い切れない空きが残る。

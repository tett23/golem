# ADR 0402: 固定ページを持たない出力と章末注のページ別番号を扱う

Status: accepted-pending

## 文脈

[root ADR 0383](0383-page-local-note-numbers.md) は PDF の注番号を呼出位置の物理ページごとに振り直す。
固定ページを持たない出力では diagnostic を出すと決めたが、重大度と番号の範囲は未決である。
章末注の一覧では異なるページの注が同じ番号になるため、その通知も定める。

## 調査した事項

調査した版は `3b3e649a06493d2bd2b809e6e3959ef611078c0f` である。
`Golem.Driver.pageNumberingDiagnostics` は HTML、EPUB、プレーンテキストのいずれかを作る本で、注か傍注があれば G03259 の警告を一度出す。
その出力では本の通し番号を使う。
ロードマップの「ページを持たない出力の注の番号」は、この重大度と範囲、および章末注一覧の番号重複を知らせるかを未決として記録している。

## 実装すること

`[notes].numbering = "page"` を HTML、EPUB、プレーンテキストに使う場合は、現行どおり G03259 の警告を一冊につき一度出し、本の通し番号を使う。
注も傍注もない本では警告を出さない。
PDF を同時に作る場合も、PDF の番号は物理ページごととし、ほかの媒体の番号へ合わせない。

PDF の `placement = "chapter-end"` と組み合わせ、同じ章末注一覧に同じ番号の注が複数載る場合は、その章につき一度警告を出す。
警告は最初に番号が重なる注の原稿位置を指し、ページ別番号のために章末一覧で番号が重なることを説明する。
この警告でも PDF は生成し、選んだページ別番号を維持する。
HTML、EPUB、プレーンテキストには、この章末一覧の警告を出さない。

## 実装しないこと

章末注にページ番号の接頭辞を加えたり、番号確定後に再配置したりしない。
媒体間で同じ番号にするために PDF の指定を変更しない。

## 不変条件

I1: 固定ページを持たない出力の注番号は、同じ入力の本の通し番号と一致する。
I2: 固定ページを持たない出力を追加しても、PDF の注番号と配置は変わらない。
I3: 章末一覧の重複番号の警告は、同じ一覧に同じ番号の注が複数ある場合に限り、その章で一度だけ出る。

| 入力 | 期待 | 不変条件 |
| --- | --- | --- |
| 注なし | G03259 なし | I1 |
| HTML と EPUB とテキスト | G03259 一度、本の通し番号 | I1 |
| PDF と HTML の同時出力 | PDF は物理ページ別、HTML は本の通し番号 | I1, I2 |
| 章末注が同じ物理ページに二つ | 番号重複の警告なし | I3 |
| 同じ章の異なる物理ページに注 | 重なる最初の番号の位置で一度警告 | I3 |

## 受けいれ条件

A1: 通常 CLI で各媒体を出力し、警告があっても生成を完了する。

## テスト設計

root ADR 0402 I1、I2、I3 を名前の先頭に置いた試験で、注なし、一つの注、同じページに二つ、異なるページ、複数の章、PDF と固定ページのない媒体の同時出力を検査する。
警告の重大度、回数、原稿位置と、注番号を照合する。
root ADR 0402 A1 の通常 CLI 試験では生成ファイルと終了コードを確かめる。

## トレードオフ

固定ページを持たない媒体も生成できるが、PDF と同じ番号で注を参照する用途には向かない。
章末一覧の重複番号を警告にするため、ページ別番号を必要とする本も生成できるが、読み手が一覧内の番号だけで注を区別できない場合が残る。

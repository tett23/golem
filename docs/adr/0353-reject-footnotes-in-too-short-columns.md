# ADR 0353: 脚注を置けない段の diagnostic

ステータス: 採択

## 文脈

PDF のページ下の脚注には、注の印を含む本文の行、区切りの領域、脚注本文の最初の行が必要である。
段の容量が小さすぎると、次の段へ送っても三つを同じ段に置けない。
現行の改ページ処理には、この入力で終了しない経路がある。

## 調査した事項

`docs/specifications.md` の「注の配置」は、PDF のページ下の脚注を印のある行または見出しと同じ段に置き、残りに入らなければ一緒に次の段へ送ると定める。
同じ節は、脚注の区切りの領域を少なくとも格子の一行と定める。

`modules/golem-layout-spec/src/Golem/LayoutSpec.hs` の `pageGeometry` は、格子の行数が 1 以上ならその点では受け付ける。
`modules/golem-layout/src/Golem/Layout/Paginate.hs` の `paginateWithin` は、脚注の区切りを最低 1 行にする。

`modules/golem-layout/src/Golem/Layout/Paginate/State.hs` の `carryNote` は、段の容量から区切りと本文の一行を引いた残りを脚注に割り当てる。
残った脚注を処理する `flushDeferred` は、残りがなくなるまで次の段への移動を繰り返す。

`modules/golem-layout/test/PaginateSpec.hs` の回帰試験では、本文一行と脚注一行の入力で容量 1、2、3 をそれぞれ一秒まで実行した。
停止したかどうかは順に `False`、`False`、`True` だった。

## 実装すること

脚注の最初の一行を置けない空の段に達したときは、脚注の印の位置でエラー G07125 を返し、PDF を出力しない。
メッセージは `脚注の印、区切りの領域と脚注本文の一行が <N> 行の段に収まりません` とし、`<N>` にはその段の行数を入れる。
脚注のない一行または二行の段は引き続き使える。

基準の段が三行以上あり、`@page-lines` で現在の段だけを一行または二行に減らした場合は、脚注を次の段へ送ってから判定する。
次の段で通常の行数に戻るので、配置できればエラーにしない。

## 実装しないこと

`pageGeometry` で一行または二行の格子を一律に禁止しない。
脚注のない原稿まで拒むためである。
脚注の印と本文を別の段へ分けたり、区切りの領域を省いたりしない。

## 不変条件

1. 脚注の印を含む行と脚注本文の最初の行は、同じ段に収まるか、G07125 で停止する。段を進めるだけの処理を無限に繰り返さない。
2. 脚注のない有限の原稿では、容量一行または二行を理由に新たなエラーを出さない。

| 境界入力 | 結果 |
| --- | --- |
| 容量 1、本文一行と脚注一行 | G07125、PDF なし |
| 容量 2、本文一行と脚注一行 | G07125、PDF なし |
| 容量 3、本文一行と脚注一行 | 同じ段に配置 |
| 容量 1 または 2、脚注なし | 通常の改ページ |
| 基準容量 3 以上で `@page-lines` により現在の段を減らす | 次の段で配置できればエラーなし |

## テスト設計

不変条件 1 の試験として、本文一行と脚注一行を容量 1、2、3 の段に与え、制限時間内に終了することを確認する。
容量 1、2 は G07125 と PDF が作られないことを確認し、容量 3 は同じ段の配置を確認する。
`@page-lines` によって現在の段を減らした入力でも、次の段で配置できればエラーがないことを確認する。
不変条件 2 の試験として、脚注のない原稿が容量 1、2 で正常に改ページされることを確認する。

## トレードオフ

脚注の印と本文を別の段へ分ける案、区切りの領域を省く案は採らない。
小さな段でも出力を続けられるが、脚注の位置または区切りの領域の規則を変更するためである。
採択した diagnostic は既存の配置規則を保つ一方、以前は受け付けていた設定と原稿の組み合わせをエラーにする。

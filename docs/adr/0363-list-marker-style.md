# ADR 0363: リストの印に文字スタイルを指定する

ステータス: 採択

## 文脈

スタイルのうち、書き手が必要とする「リストの印」の扱いを決める。

## 調査した事項

Golem [ADR 0177](0177-note-mark-style-and-numerals.md) の調査は、次の扱いを記録している。
`listMarker` は印をただの `Text` にし、項目の段落の見た目で組む（[`Flow.hs`](https://github.com/tett23/golem/blob/50b9fca8a0744f6f9d92808db231e6c04ac35d2c/modules/golem-driver/src/Golem/Driver/Pdf/Flow.hs#L1212-L1228)）。
`[lists]` に文字スタイルの欄はない。

## 実装すること

lists の marker-style で印に使う文字スタイルを選ぶ。
省略時は項目の段落の見た目を引き継ぐ。
印は適用後の幅で測り、項目本文に印の文字スタイルを伝えない。

番号付きリストでは番号と書式が生成する前後の文字も印に含める。

## 実装しないこと

既存の原稿を新しい指定へ自動変換する機能は設けない。

## 不変条件

1. 印のスタイルだけを変更しても項目本文の文字スタイルは変わらない。

| 境界の入力 | 期待する結果 |
| --- | --- |
| 指定なし | 項目の書体 |
| 印だけ色を指定 | 本文の色は段落指定 |

## テスト設計

- `inv1_list_marker_style_property` で次の述語を検査する。印のスタイルだけを変更しても項目本文の文字スタイルは変わらない。
- `inv1_list_marker_style_case_1` は「指定なし」を入力とし、「項目の書体」を確かめる。
- `inv1_list_marker_style_case_2` は「印だけ色を指定」を入力とし、「本文の色は段落指定」を確かめる。

## トレードオフ

印の幅が変わると、本文の折り返し位置も変わりうる。

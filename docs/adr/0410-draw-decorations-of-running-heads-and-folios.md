# ADR 0410: 柱とノンブルにも、文字スタイルの下線、取り消し線、背景を描く

Status: proposed

## 文脈

[ADR 0364](0364-running-head-folio-style.md) は、柱とノンブルにそれぞれ文字スタイルを当てられるようにした。
ADR の文は「書体、大きさ、色」を当てると書くが、実装は文字スタイルの全体を当てる。
合成の太字と斜体、トラッキング、ベースラインシフト、OpenType の機能も当たる。

ただし、文字スタイルの下線、取り消し線、背景は、柱とノンブルには描かない。
仕様書はそう書いているが、書き手には何も知らせない。
指定した見た目が、黙って出力に表れない。

tett23 は 2026-11-23 に、指定されていれば指定のとおりに描くことを決めた。
この ADR は、その振る舞いと、[ADR 0364](0364-running-head-folio-style.md) の文と実装の範囲の食い違いを記録する。

## 調査した事項

いずれも `b540aa68a` で確かめた。

- 本文の行は、[`entryAt`](https://github.com/tett23/golem/blob/b540aa68a3bbb45ed4a8754f79852984152f6cf6/modules/golem-typeset/src/Golem/Typeset/Draw.hs#L1065-L1066) が、下線と取り消し線の帯（[`decorationBands`](https://github.com/tett23/golem/blob/b540aa68a3bbb45ed4a8754f79852984152f6cf6/modules/golem-typeset/src/Golem/Typeset/Draw.hs#L1082-L1083)）と背景の矩形（[`codeBackgrounds`](https://github.com/tett23/golem/blob/b540aa68a3bbb45ed4a8754f79852984152f6cf6/modules/golem-typeset/src/Golem/Typeset/Draw.hs#L1139-L1140)）を作って描く。
- 柱とノンブルは、[`masterMarks`](https://github.com/tett23/golem/blob/b540aa68a3bbb45ed4a8754f79852984152f6cf6/modules/golem-typeset/src/Golem/Typeset/Draw.hs#L1992-L1993) から [`textAt`](https://github.com/tett23/golem/blob/b540aa68a3bbb45ed4a8754f79852984152f6cf6/modules/golem-typeset/src/Golem/Typeset/Draw.hs#L1500-L1501) で描く。
  `textAt` は、文字スタイルの書体、大きさ、色などを解決して字を描くが、`decorationBands` も `codeBackgrounds` も呼ばない。
- 仕様書は、「文字スタイルの下線、取り消し線、背景は、柱とノンブルには描かない」（[docs/specifications.md](../specifications.md) の 4244 行）と書く。
  背景の節にも、「柱とノンブルには、文字スタイルを指定しても背景を描かない」（3396 行）とある。
- 下線と取り消し線は [ADR 0270](0270-underline-and-strikethrough.md) が、文字スタイルの背景と余白は [golem-driver ADR 0029](../golem-driver/adr/0029-inline-code-background.md) が決めた。
- [ADR 0364](0364-running-head-folio-style.md) の本文には、下線、取り消し線、背景を描かないことは書かれていない。

## 実装すること

- 柱とノンブルを描くときも、本文の行と同じ関数で、下線と取り消し線の帯と、背景の矩形を作って描く。
  描く順（背景、下線、字、取り消し線）は本文と同じにする。
  装飾は、柱とノンブルの全体と同じく `Pagination` のアーティファクトとして描く。
- 縦組みの本でも、柱とノンブルは横書きで描く（[docs/specifications.md](../specifications.md) の 4253 行）。
  そのため、下線、取り消し線、背景も、横組みの行の規則で描く。
- 背景の余白（`padding`）と、下線と取り消し線の位置、太さ、線種、色は、本文の行と同じ規則で決める。
- golem preflight に渡す行の記録（`LineRec`）の背景と装飾の欄も、本文の行と同じく埋める。
  背景のスウォッチは使ったスウォッチに入って総インキ量の検査（G09015）の対象になり、下線と取り消し線は本文の装飾と同じく罫線の検査の対象になる。
- 柱とノンブルの位置と字の配置は変えない。
  背景と下線は、字の位置を変えずに重ねて描く。
- 仕様書の 4244 行と 3396 行を、描く振る舞いに直す。
- [ADR 0364](0364-running-head-folio-style.md) の「書体、大きさ、色」を当てるという文は、実装どおり「文字スタイルの全体を当てる」に読み替える。
  採択したら、[ADR 0364](0364-running-head-folio-style.md) のステータスの行に、部分「柱とノンブルに当てる文字スタイルの範囲」を、この ADR による置き換え（`replace`）として足す。
  「書体、大きさ、色」から「文字スタイルの全体」へ意味を広げるので、補足ではなく置き換えとする。

## 実装しないこと

- HTML と EPUB には、柱とノンブルがない。そのため、この ADR は PDF だけを変える。
- 隠しノンブル（[ADR 0365](0365-hidden-folio-style.md)）は、この ADR の対象にしない。
  隠しノンブルは綴じの中に置く小さな字であり、下線や背景を描くかは別に決める。
- 柱とノンブルの行の高さや位置を、背景の余白で動かすことはしない。

## 不変条件

「柱とノンブルの行」は、`masterMarks` が描く一つの柱か一つのノンブルとする。

- I1：どの文字スタイルでも、柱とノンブルの行に描く下線、取り消し線、背景の集合は、同じ文字スタイルと同じ文字列を横組みの本文の一行として同じ位置に置いたときに描くものと等しい。
- I2：どの文字スタイルでも、下線、取り消し線、背景を描いても、柱とノンブルの字の位置と字形は、それらを持たない同じ文字スタイルのときと等しい。
- I3：下線、取り消し線、背景を持たない文字スタイルか、`character-style` を書かない柱とノンブルの PDF の内容は、この ADR の前と同じである。

| 入力 | 期待 | 不変条件 |
| --- | --- | --- |
| 柱だけに下線のスタイル | 柱に下線、ノンブルは前と同じ | I1, I3 |
| ノンブルだけに背景のスタイル | ノンブルに背景、柱は前と同じ | I1, I3 |
| 柱に取り消し線と背景、ノンブルに下線 | それぞれに描く | I1, I2 |
| 装飾のないスタイル | 前と同じ | I3 |
| 空の柱（見出しがないページ） | 何も描かない | I1 |
| 縦組みの本の柱とノンブル | 横組みの行の規則で描く | I1, I2 |

## 受けいれ条件

なし。
この ADR の振る舞いは、不変条件のテストで確かめる。

## テスト設計

- golem-driver の `PageElementsSpec` に、上の表の行ごとのテストを置く。
  名前は `root ADR 0410 I<番号>: ...` とする。
- I1 は、柱とノンブルの行の帯と矩形を、同じ文字スタイルと文字列を本文の一行に置いたときの帯と矩形と比べる。
  位置は行の始まりからの相対で比べる。
- I1 と I2 は、実装の前に、今の実装で下線と背景が描かれないことを確かめて失敗させる。
- I1 と I2 は、下線、取り消し線、背景の有無の 8 通りと、横組みの本と縦組みの本、奇数と偶数のページのすべての組で確かめる。
  縦組みの本でも、比べる本文の一行は横組みの行とする。
- I3 は、今ある [ADR 0364](0364-running-head-folio-style.md) のテストと、visual の基準が変わらないことで確かめる。
- golem preflight のテストに、柱の背景のスウォッチが使ったスウォッチに入ることを足す。

## トレードオフ

柱とノンブルに下線や背景を指定していた本は、出力が変わる。
今までは指定しても描かなかったので、意図して指定していた本は、ほぼないと見込む（確かめていない）。

柱とノンブルの背景の余白が大きいと、版面の外の余白にはみ出すことがある。
本文の行と同じく、はみ出しは検査しない。

# ADR 0422: 注にラベルを付けて、番号とページを参照する

Status: accepted

## 文脈

[ADR 0383](0383-page-local-note-numbers.md) は、注の番号をページごとに振る設定を決め、「ページ別の番号を持つ注を参照する箇所にも同じ予約幅を使う」と書いた。
しかし、注を参照する書き方はまだない。
本文で「注 3 を参照」と書きたいとき、書き手は番号を手で書くしかなく、注を足すと番号がずれる。

tett23 は 2026-11-18 に、注の参照の ADR を作ることを決めた。
G03259（ページを持たない出力でページごとの番号を使った警告）は、警告のまま残すと決めた。

## 調査した事項

`origin/main`（`2ac7fb273`）で確かめた。

- 相互参照は、`@label` で直後のブロックにラベルを付け、`[ref-number ...]`、`[ref-title ...]`、`[ref-page ...]` で参照する（[docs/specifications.md](../specifications.md) の「ラベルと相互参照」）。
  `@label` はブロックに付くので、インラインの注にはラベルを付けられない。
- 番号を持つのは、番号のある見出し、図版、キャプションのあるコードブロック、表である。
  番号を持たない要素を `[ref-number ...]` で参照するとエラーになる。
- ラベルは文書全体で一つの名前空間であり、重複はエラーになる。
- `[ref-page ...]` は、ページの表記を数（Number）として返す。
  ページの表記が行の幅を変える循環は、レイアウトの繰り返しで解く。
- 注の番号は、文書の組み立てでチャネルごとに振り、`numbering = "page"` のときは配置の後に物理ページごとに振り直す（[ADR 0383](0383-page-local-note-numbers.md)）。
  ページを持たない出力は、G03259 を出して本の通し番号で組む（[ADR 0402](0402-define-page-local-note-fallback-diagnostics.md)）。
- `[note 名前]` は、`@note 名前` の本文を引くためのもので、一つの本文を指せる印は一つだけである。
- 章末の注は、[ADR 0412](0412-a-separate-channel-for-endnotes.md) で別のチャネル `[endnote]` になる。

## 実装すること

### ラベル

- 注のインラインのコマンド `[note]`、`[sidenote]`、`[endnote]` に、名前付き引数 `label` を足す。
  例：`[note label=sources: 出典は…]`。
  `label` の値の書き方は、`@label` のラベルと同じ字の規則とする。
  `@note 名前` と `@endnote 名前` の名前はファイルの中の名前で、ラベルとは別である。
  `[ref-number 名前]` で、この名前は引けない。
  `@note` と `@endnote` の定義には、ラベルを付けない。
  `[note 名前]` と `[endnote 名前]`（`@note` と `@endnote` の本文を引く形）にも `label` を書ける。
- 注のラベルは、`@label` のラベルと同じ名前空間に入る。
  重複は、今のラベルの重複と同じコードのエラーにする。

### 参照

- `[ref-number ラベル]` は、ラベルの付いた注の番号を返す。
  返す値は、その出力で注の印に振った番号と等しい数（Number）とする。
  - PDF で `numbering = "page"` のときは、物理ページごとの番号である。
  - ページを持たない出力では、本の通し番号である（G03259 の警告は、注の印の側で一度だけ出し、参照の側では出さない）。
- 番号の表記（`mark-format` の前後の字）は付けない。
  書き手は、参照の前後に「注」などの字を書く。
- `[ref-page ラベル]` は、注の印のあるページの表記を返す。
- `[ref-title ラベル]` で注を参照すると、題を持たない要素の参照と同じコードのエラーにする。
- ページごとの番号を参照する箇所の幅は、参照の箇所の実効スタイルと縦横で、前後の字を付けずに 1 からチャネルの注の総数までの番号を測った最大の幅とする（[ADR 0383](0383-page-local-note-numbers.md) の予約の幅と同じ考え方）。
- `[endnote]` の参照は、[ADR 0412](0412-a-separate-channel-for-endnotes.md) の実装の後に実装する。

### 文書

- 仕様書の「ラベルと相互参照」と注の節、`docs/markup.md`、LSP の補完（`label` の引数と、注のラベルの参照先）、マニュアルを直す。
- 採択したら、[ADR 0383](0383-page-local-note-numbers.md) のステータスの行に、部分「注を参照する箇所の予約幅」をこの ADR による補足として足す。

## 実装しないこと

- 注の題（`[ref-title]`）は設けない。
- 注の本文の中の段落や行を参照する仕組みは設けない。
- 参照に番号の表記（印の書式）を付けるオプションは設けない。

## 不変条件

- I1：ラベルの付いたどの注でも、`[ref-number ラベル]` の値は、同じ出力でその注の印に振った番号に等しい。
- I2：`numbering = "page"` の PDF で、注の参照が置かれた行の幅は、参照する注の番号によらない（予約の幅で取る）。
- I3：`[ref-page ラベル]` の値は、その注の印のあるページの表記に等しい。
- I4：ラベルの付かない注しかない本の出力と diagnostic は、この ADR の前と同じである。
- I5：注を `[ref-title]` で参照した入力は題を持たない要素の参照のエラーを、注のラベルがほかのラベルと重なる入力はラベルの重複のエラーを、それぞれちょうど一つ含む。

| 入力 | 期待 | 不変条件 |
| --- | --- | --- |
| 脚注一つにラベル、本文で `[ref-number]` | 1 | I1 |
| 三つめの傍注にラベル | 3（傍注のチャネルの番号） | I1 |
| `[endnote]` にラベル、`numbering = "chapter"` | 章ごとの番号 | I1 |
| `numbering = "page"` の PDF、注が次のページにずれる | 新しいページの番号、行の幅は同じ | I1, I2 |
| 同じ本の HTML | 通し番号 | I1 |
| `[ref-page]` | 印のページの表記 | I3 |
| `[ref-title]` で注を参照 | 題を持たない要素の参照のエラー | I5 |
| 注のラベルと見出しのラベルが同じ | ラベルの重複のエラー | I5 |
| ラベルのない本 | 前と同じ | I4 |

## 受けいれ条件

なし。
この ADR の振る舞いは、不変条件のテストで確かめる。

## テスト設計

- 名前は `root ADR 0422 I<番号>: ...` とする。
  テストは、実装の前に失敗することを確かめてから実装する。
- I1 は、脚注、傍注、章末の注の三種を、長さ 0 から 4 のすべての並びで置き、そのうちの一つにラベルを付けて、`[notes].numbering` の四つの値、`[endnotes].numbering` の `"page"` を除く三つの値、出力（PDF、HTML、EPUB、プレーンテキスト）のすべての組で、参照の値と印の番号を比べる。
- I2 は、[ADR 0383](0383-page-local-note-numbers.md) の予約の幅のテストと同じ方法で、番号が 1 桁と 2 桁になる入力の行の幅を比べる。
- I3 は、注の印が改ページの前後に来る入力で確かめる。
- I4 は、今の注と相互参照のテストが変わらないことで確かめる。

## トレードオフ

注のラベルを見出しなどと同じ名前空間に入れるので、名前がぶつかりやすくなる。
名前空間を分けると、参照のコマンドを注のために別に設ける必要があり、書き手が覚えることが増える。
同じコマンドで参照できることを選ぶ。

# ADR 0375: 奥付の発行履歴をテンプレートで組む

ステータス: 採択（未実装）

## 文脈

スタイルのうち、書き手が必要とする「発行の履歴の書式」の扱いを決める。

## 調査した事項

`@printings` は、奥付の発行の履歴の行（`2026年10月16日　初版第1刷発行` の形）を、日本語の一つの書式に固定して組む（[docs/adr/0033](../adr/0033-colophon-contributors-and-printings.md)）。

## 実装すること

発行履歴の行を日付、版、刷の名前付き欄とリテラルで指定する。
数値欄は十進数字とし、日付は年、月、日の各欄も提供する。
指定時は記載順と空白を保存し、未知の欄を拒む。
省略時は既存の書式を保つ。

`[printings]` の format は {year}、{month}、{day}、{date}、{edition}、{printing} を受け付け、{date} は YYYY-MM-DD とする。
文字としての波括弧は {{ と }} で書く。
日本語以外の本も明示書式なら受け付け、省略時の G02076 は維持する。

## 実装しないこと

既存の原稿を新しい指定へ自動変換する機能は設けない。

## 不変条件

1. 明示書式で生成する行数は言語にかかわらず発行履歴の項目数に等しい。

| 境界の入力 | 期待する結果 |
| --- | --- |
| 既定の初版 | 初版と表示 |
| 第{edition}版 | 第1版 |
| 未知の欄 | 設定エラー |

## テスト設計

- `inv1_printings_format_property` で次の述語を検査する。明示書式で生成する行数は言語にかかわらず発行履歴の項目数に等しい。
- `inv1_printings_format_case_1` は「既定の初版」を入力とし、「初版と表示」を確かめる。
- `inv1_printings_format_case_2` は「第{edition}版」を入力とし、「第 1 版」を確かめる。
- `inv1_printings_format_case_3` は「未知の欄」を入力とし、「設定エラー」を確かめる。

## トレードオフ

欄の展開だけに限ると、言語ごとの複数形などの条件分岐は表せない。

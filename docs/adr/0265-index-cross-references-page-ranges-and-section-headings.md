# ADR 0265: 索引の参照、ページの範囲、見出し

ステータス: 採択

## 文脈

Golem の索引の項目は、語と読みの段（二段まで）しか持たない。
IR の `IndexEntry` は `ieTerms` と `ieReadings` の二つの列だけを持ち（[`IndexEntry`](https://github.com/tett23/golem/blob/87857c6e74c3494d5f23149101415cb566b2d850/modules/golem-doc/src/Golem/Doc/IR.hs#L349-L353)）、`[index]` の評価は `reading` のほかのキーを読まない（[`Fixed BIndex`](https://github.com/tett23/golem/blob/87857c6e74c3494d5f23149101415cb566b2d850/modules/golem-eval/src/Golem/Eval/File.hs#L2267-L2279)）。
仕様書は「〜を見よ」のような項目間の参照を v1 で扱わないと書いている（[仕様書の「索引」](../specifications.md#索引)）。
このため、学術書の索引に普通にある三つのものが書けない。

- **参照**：「タイプセッティング」の項目から「組版」の項目へ読者を送ること。送り先しか持たない項目（を見よ）と、ページを持ったうえで関連する項目を示す項目（をも見よ）がある。
- **ページの範囲**：一つの話題が数ページにわたるとき、「12–18」のようにまとめて示すこと。今は印を置いたページを一つずつ並べるので、範囲の両端と途中に印を置いても「12, 15, 18」になり、13 から 17 ページも同じ話題であることが伝わらない。
- **見出し**：五十音の行（「あ」「か」…）やラテン文字（「A」「B」…）ごとに項目をまとめ、その頭に見出しを置くこと。

[2026-10-17 の調査](../audits/2026-10-17-latex-gap-for-v1.md) の「11. 索引の参照、ページの範囲、見出し」は、これらを v2 の「索引と参考文献の拡張」から v1.0.0 に取り出すことを提案し、所有者は v1.0.0 に置くと決めた（同じ記録の「所有者の決定」）。
参照と範囲は `[index]` の記法と IR を変えるので、1.0.0 の前に決める必要がある（[ADR 0174](0174-compatibility-promises-for-1-0.md)）。

### 今の索引の作り方

索引の印は、評価で `IndexMark` になり、文書の組み立て（S1）で語と読みの組ごとにまとめられる。
`groupMarks` は、組ごとに出現位置の列を持つ `IndexGroup` を作り、読みの照合のキーで並べる（[`indexLists` と `groupMarks`](https://github.com/tett23/golem/blob/87857c6e74c3494d5f23149101415cb566b2d850/modules/golem-assemble/src/Golem/Assemble.hs#L776-L796)）。
`@index` が二つ以上あれば、印はその後にある最初の一覧に載る（[golem-doc ADR 0008](../golem-doc/adr/0008-multiple-index-and-bibliography.md)）。

照合のキーは JIS X 4061 を基礎にした自前の実装で、平仮名と片仮名を同一視し、濁点、半濁点、小書きの区別を二次と三次のキーに回す（[`collationKey`](https://github.com/tett23/golem/blob/87857c6e74c3494d5f23149101415cb566b2d850/modules/golem-assemble/src/Golem/Assemble/Collation.hs#L20-L24)、[golem-doc ADR 0002](../golem-doc/adr/0002-document-assembly.md)）。
一次のキーは字の種類で分かれ、記号（0）、数字（1）、ラテン文字（2）、仮名（3）、U+4E00 以上の字（4）の順に並ぶ（[`classify`](https://github.com/tett23/golem/blob/87857c6e74c3494d5f23149101415cb566b2d850/modules/golem-assemble/src/Golem/Assemble/Collation.hs#L68-L76)）。
仮名の一次のキーは、濁点と小書きを除いた清音の平仮名である。

PDF は、`indexLines` が項目ごとに語、全角の空白、ページ番号の列の段落を作る（[`indexLines`](https://github.com/tett23/golem/blob/87857c6e74c3494d5f23149101415cb566b2d850/modules/golem-typeset/src/Golem/Typeset/Flow.hs#L912-L930)、[golem-driver ADR 0007](../golem-driver/adr/0007-pdf-index-and-bibliography.md)）。
ページ番号は昇順で一度ずつ並び、区切りは横組みで `, `、縦組みで `、` である。
印のページは、レイアウトを繰り返して収束させる（S2）。
HTML と EPUB は、項目ごとに語と、出現位置へのリンクを 1 から数えた番号で出す（[`index`](https://github.com/tett23/golem/blob/87857c6e74c3494d5f23149101415cb566b2d850/modules/golem-html/src/Golem/Html.hs#L591-L602)）。
プレーンテキストは索引を出さない（[`Golem.Text`](https://github.com/tett23/golem/blob/87857c6e74c3494d5f23149101415cb566b2d850/modules/golem-text/src/Golem/Text.hs#L155)）。

### ほかの処理系

InDesign は、索引の項目の種類に「を見よ」「をも見よ」の参照と、ページの範囲（次のスタイルの変更まで、文書の終わりまで、など）を持つ。
ページを持つ項目には「をも見よ」、持たない項目には「を見よ」を自動で選ぶ種類がある。
索引を作るときに、見出しを入れるかどうかを選べる。
いずれも調査が検索の抜粋で確かめたことで、helpx.adobe.com の本文は読めていない。
既定でどちらが選ばれるか、範囲の区切りの既定の字、日本語版の見出しの区切り方は確かめていない。

makeindex は、`|see{...}` と `|seealso{...}` で参照を、`|(` と `|)` で範囲の始めと終わりを書く。
範囲の区切りの既定は `--`（en ダッシュ）である。
和文の索引は upmendex が読みで並べ、索引のスタイルファイルで見出しを入れる。

JLReq は、索引の版面と、縦組みの本の横組みの索引のノンブルを扱う（[JLReq](https://www.w3.org/TR/jlreq/)）が、項目の書式、参照の書き方、範囲の区切りの字は決めていない。
JLReq が区切りの字について決めているのは、ハイフン類（cl-03）に en ダッシュ（二分）と波ダッシュ（全角）の両方が入ることと、その字幅までである（[JLReq の A.3](https://www.w3.org/TR/jlreq/#cl-03)）。

### ほかの ADR との関係

この ADR は [ADR 0260](0260-front-matter-folios-and-page-labels.md) の後に実装する。
ページを指す値（ページラベル）と、それを書く規則（`pageLabelInlines`）は [ADR 0260](0260-front-matter-folios-and-page-labels.md) が決める。
この ADR は範囲の両端にその値をそのまま使い、書式を決め直さない。
[ADR 0260](0260-front-matter-folios-and-page-labels.md) のセクション（ノンブルの数え方を共有するページの並び）をまたぐ範囲の扱いは、この ADR が決める。

見出しの行を次の項目の行と離さないために、[ADR 0261](0261-keep-options-of-paragraph-styles.md) の段落の連動の仕組みを使う。
この ADR は [ADR 0261](0261-keep-options-of-paragraph-styles.md) の後に実装する。

索引のページ番号を PDF のリンクにすることは、[ADR 0267](0267-pdf-bookmarks-and-links-inside-the-document.md) が扱う。
この ADR は、リンクの行き先になる値（範囲の始めの印、参照先の項目）を IR と `Book` に残すところまでを決める。

## 実装すること

### 記法

`[index]` に二つのキーワード引数を足す。

```
[index reading=くみはん range=begin: 組版]
（組版について数ページ書く）
[index reading=くみはん range=end: 組版]

[index reading=たいぷせってぃんぐ see=組版: タイプセッティング]
[index reading=わぶんくみはん see=組版/和文組版: 和文組版]
```

- `range=begin` は範囲の始め、`range=end` は範囲の終わりの印である。`range` を書かない印は、今と同じく一つのページの印である。`range` のほかの値は G02144 とする。
- 範囲の始めと終わりは、語と読みの組が等しい印どうしで対にする。対にするのは、同じ `@index` の一覧に載る印の中だけである。
- 対の作り方は入れ子と同じで、文書の順にたどり、終わりの印をまだ閉じていない最も近い始めの印と対にする。同じ項目の範囲を入れ子に書いてもよく、その結果は下の「範囲を並べる規則」で一つにまとまる。
- 対のない始めの印は G04103、対のない終わりの印は G04104 とする。範囲が二つの `@index` の一覧の境をまたぐと、始めと終わりがそれぞれの一覧で対を持たないので、この二つのコードになる。
- `see` は、参照先の項目の語を `/` で区切って書く。参照先の段は一つか二つで、空の段を持たない。そうでなければ G02146 とする。
- `see` の印は、その項目のページを作らない。項目を作り、参照を足すだけである。印を置いた位置は、どの `@index` の一覧に載るかだけを決める。
- `see` と `range` を一つの印に書くと G02145 とする。
- 参照先の語が、同じ一覧のどの項目の語とも一致しなければ G04101 とする。読みは比べない。同じ語で読みの違う項目が二つあれば、どちらにも一致する。表示する文字列は語だけなので、どちらを指しても出力は変わらない。
- `reading` が引数であるのと同じく、`see` も引数なので、`\/` で `/` を書けない。語に `/` を含む項目（`a\/b`）は参照先にできない。

`see` の印が作る参照の種類は、InDesign の自動の種類にならう。
項目がページ（一つのページの印か範囲）を一つも持たなければ「を見よ」、持てば「をも見よ」とする。
ページを持たない項目どうしの「を見よ」の参照が輪になる（自分自身を指す場合を含む）と、読者は項目のあいだを回り続けるので、G04102 とする。
副項目を持つ主項目は、ページを持たなくても輪の頂点に数えない。
副項目を読めば行き先があるからである。

### データ構造

IR の `IndexEntry` に、印の種類を足す。

```haskell
data IndexEntry = IndexEntry
  { ieTerms :: ![Text], -- one or two levels
    ieReadings :: ![Text],
    ieKind :: !IndexKind
  }

data IndexKind
  = IndexPoint
  | IndexRangeBegin
  | IndexRangeEnd
  | -- | a cross reference to the terms of another entry, one or two levels
    IndexSee !SeeKind ![Text]

data SeeKind = SeeAuto | SeeOnly | SeeAlso
```

記法が作るのは `SeeAuto` だけである。
`SeeOnly`（を見よ）と `SeeAlso`（をも見よ）は、InDesign が種類を選ばせる場合に当たり、プラグインと Emet の関数が作れる。
出力は三つとも組む。
自動の種類だけを型に持つと、種類を選ぶ記法を後で足すときに IR をもう一度変えることになるので、型を先に広げておく。

CDDL の索引の印は、次の形になる（[golem-doc ADR 0006](../golem-doc/adr/0006-integer-range-in-ir.md) の CDDL の規則に従う）。

```
/ [14, span, terms: [1*2 tstr], readings: [1*2 tstr], kind: index-kind] ; index mark
index-kind = [0] / [1] / [2] / [3, see: 0..2, target: [1*2 tstr]]  ; point, range begin, range end, see
```

IR とプラグインの ABI が変わるので、`abiVersion` を上げる（[ADR 0052](0052-plugin-abi-version-bump-rule.md)）。
CBOR の読み書き（`Golem.Doc.Cbor`）、プラグインの出力の検査（`Golem.Doc.Validate`、参照先の段の数と空の段を検査する）、Emet の組み込みの型（`Golem.Emet.Builtins` の `IndexMark`）、IR の生成器（`Golem.DocGen`）を合わせて変える。

S1 の `IndexGroup` は、出現位置の列の代わりに、ページの指し方の列と参照の列を持つ。

```haskell
data IndexLocator
  = AtMark !(FileId, SrcSpan)
  | Between !(FileId, SrcSpan) !(FileId, SrcSpan) -- the begin mark and the end mark

data IndexGroup = IndexGroup
  { igTerms :: ![Text],
    igReadings :: ![Text],
    igLocators :: ![IndexLocator], -- in document order of their first mark
    igSee :: ![(SeeKind, [Text])] -- each once, in the collation order of the targets
  }

data IndexSection = IndexSection
  { isHeading :: !Text,
    isGroups :: ![IndexGroup]
  }
```

`bookIndexes` は、一覧ごとに `[IndexSection]` を持つ。
見出しを入れない本でも、組み立ては見出しを計算し、出力が見出しの行を出さない。
G07021 の語の表を作る `indexGroups` は、`AtMark` と `Between` の両端の印を数える。

### 見出し

項目の見出しは、主項目の読み（読みの一段め）の最初の字の照合の一次のキーから決める。

| 一次のキーの種類 | 見出し |
| --- | --- |
| 記号（0）と数字（1） | `記号と数字` |
| ラテン文字（2） | その字の大文字（`A` から `Z`） |
| 仮名（3） | 清音の平仮名の行の頭（`あ`、`か`、`さ`、`た`、`な`、`は`、`ま`、`や`、`ら`、`わ`） |
| U+4E00 以上の字（4） | `その他` |

- 仮名の行は、照合の一次のキー（濁点、半濁点、小書きを除き、片仮名を平仮名にした字）で決める。「ガ」も「が」も「ぁ」も、それぞれ「か」「か」「あ」の行になる。
- `わ` の行は、わ、ゐ、ゑ、を、んを含む。
- 見出しの等しい項目は、照合の順で必ず隣り合う。見出しは一次のキーの単調な関数であり、項目はそのキーで並んでいるからである。並べ替えの規則は変えない。
- 項目のない見出しは出さない。

`style.toml` の `[index]` に `section-headings` を足す。

| キー | 型 | 既定 | 意味 |
| --- | --- | --- | --- |
| `section-headings` | 真偽値 | `true` | 索引に見出しを入れる |

名前は InDesign の索引の生成の「索引セクションの見出し」（Include Index Section Headings）にならった。
真偽値でない値は、ほかの `[index]` の値と同じく G03025 とする。

### PDF の組版

`indexLines` は `[IndexSection]` を受け取る。

- 見出しを入れる本では、各見出しを一つの段落として、項目の行の前に置く。見出しの文字は組み込みの文字スタイル `strong` で組み、最初の見出しのほかは、前に索引の行の格子の一行分のアキを取る。
- 見出しの段落は、続く最初の項目の行と同じ段に置く。[ADR 0261](0261-keep-options-of-paragraph-styles.md) の連動（次の段落と離さない指定）を見出しの段落に付けて実現する。
- 見出しの段落のタグは、項目の行と同じ `P` とする（[仕様書の構造の表](../specifications.md) の「索引（`@index`）」の行は、すでに見出しの文字を `P` としている）。

ページの指し方は、印のページから次の規則で並べる。
ページは [ADR 0260](0260-front-matter-folios-and-page-labels.md) のページラベルであり、比べるときはその通し番号（PDF のページの位置）で比べる。
ノンブルの数字は、セクションごとに振り直されることがあるので、比べる材料にならない。

1. `AtMark` は印のページ p の一点、`Between` は始めの印のページ a から終わりの印のページ b までの区間[a, b]とする。
2. b が a より前のページなら G07118 とする。図版のキャプションの中の印が、送られた図版のページを指す場合に起こりうる。
3. a と b が [ADR 0260](0260-front-matter-folios-and-page-labels.md) の別のセクションにあれば G07119 とする。
4. 点と区間が覆うページの集まりを S とする。
5. S を、続くページの最も長い並びに分ける。ページ p と p + 1 がどちらも S にあり、p + 1 が [ADR 0260](0260-front-matter-folios-and-page-labels.md) のセクションの最初のページでなければ、二つは同じ並びに入る。
6. 二ページ以上の並びは、最初のページから最後のページまでの範囲として出す。一ページの並びは、そのページ一つとして出す。並びは始めのページの順に並べる。

5 と 6 が、連続するページの自動の圧縮である（2026-11-09 の tett23 の決定）。
二ページが続けば圧縮する。
「5, 6」は「5–6」に、「5, 6, 7」は「5–7」になる。
書いた範囲と、一点の印のページが続いてできた範囲は、出力では区別しない。
重なる区間と、区間の中の一点は、5 と 6 で一つの範囲になる。
セクションの境では、ページが続いていても並びを分ける。
前付けの最後のページ「xii」と本文の最初のページ「1」は、続くページでも「xii, 1」と組む。

区間の両端は、それぞれ [ADR 0260](0260-front-matter-folios-and-page-labels.md) の `pageLabelInlines` で書いたページラベルとし、あいだに区切りの字を置く。
区切りの字は、横組みで `–`（U+2013 EN DASH）、縦組みで `〜`（U+301C WAVE DASH）とする。
点と区間のあいだの区切りは、今の `, ` と `、` のままである。

参照は、ページの列の後（ページがなければ語の後）に置く。

| 種類 | 形（横組みの例） |
| --- | --- |
| を見よ | `タイプセッティング（組版を見よ）` |
| をも見よ | `組版　12–18, 25（印刷をも見よ）` |

- 参照先が二つ以上なら、`、` で区切って一つの括弧に入れる（`（組版、印刷を見よ）`）。並びは参照先の項目の照合の順で、同じ参照先は一度だけ出す。
- 二段の参照先は、段を `：`（U+FF1A）でつなぐ（`（組版：和文組版を見よ）`）。
- `SeeAuto` は、項目がページを持つかどうかで二つの形のどちらかになる。`SeeOnly` と `SeeAlso` は、ページの有無によらずその形になる。種類の違う参照が一つの項目にあれば、「を見よ」の括弧を先に、「をも見よ」の括弧を後に置く。
- 括弧と `を見よ` の字は、縦組みでも同じ字を使う。縦組みの括弧の字形は、本文と同じく縦組みの字形の機能が選ぶ。

範囲と参照の印のページも、今の印と同じく S2 の繰り返しで収束させる。
範囲の両端の印は、一点の印と同じ表（印からページへの表）に入るので、G07021 の判定にもそのまま入る。

### HTML と EPUB

- 見出しを入れる本では、見出しごとに `<p class="index-heading">あ</p>` と、その見出しの項目の `<ul>` を出す。見出しを入れない本は、今と同じく一つの `<ul>` である。`section-headings` の値は、ドライバーが `HtmlConfig` に渡す。
- 範囲は、始めの印へのリンクと終わりの印へのリンクを `–` でつないで出す。リンクの番号は、今と同じく出現位置を 1 から数えたもので、範囲は二つの番号を使う。HTML にはページがないので、範囲の中の一点の印もそのまま出す。
- 参照は、PDF と同じ文字列をリンクにせずに出す。

### プレーンテキスト

索引を出さないことは変わらない。
`[index]` の印は、今と同じく何も出さない。

- [docs/specifications.md](../specifications.md) の「索引」の節と `style.toml` の `[index]` の表。項目間の参照を v1 で扱わないとする文を消す。
- [docs/markup.md](../markup.md) の「索引」の節に、`range` と `see` を書く。
- [docs/diagnostics.md](../diagnostics.md) に、下の新しいコードを足し、G03025 の意味に `section-headings` を足す。
- マニュアルの索引の章に、範囲と参照の書き方を足す。

実装を終えたら、[docs/roadmap.md](../roadmap.md) から次の記述を消す。

- v1.0.0 の「LaTeX との差を埋める項目」の「索引の参照、ページの範囲、見出し」の項目。同じ節の冒頭の「記法、意味論の IR、プラグインの ABI を変える項目（…）」の括弧の中の「索引の参照」。
- v2 の「索引と参考文献の拡張」から、〜を見よのような項目間の参照の句と、索引の見出し（「あ」「か」のような行の区切り）の句。最初の句の「索引の三段以上の階層と」に続く部分が消え、「索引の三段以上の階層（v1 は二段まで）」が残る。
- v2 の「索引と参考文献の拡張」の「ページ番号の範囲の圧縮、」の句。連続するページを自動で範囲にまとめることは、この ADR が扱う（メンテナーが決めること 4）。

### diagnostic のコード

| コード | 段階 | 原因 |
| --- | --- | --- |
| G02144 | 評価 | `range` の値が `begin` でも `end` でもない |
| G02145 | 評価 | 一つの印に `see` と `range` を書いた |
| G02146 | 評価 | `see` の段が一つか二つでないか、空の段がある |
| G04101 | 組み立て | `see` の参照先の語が、同じ一覧のどの項目にもない |
| G04102 | 組み立て | ページを持たない項目どうしの「を見よ」の参照が輪になる |
| G04103 | 組み立て | 範囲の始めの印に、対になる終わりの印がない |
| G04104 | 組み立て | 範囲の終わりの印に、対になる始めの印がない |
| G07118 | レイアウト | 範囲の終わりの印のページが、始めの印のページより前にある |
| G07119 | レイアウト | 範囲の始めと終わりが、[ADR 0260](0260-front-matter-folios-and-page-labels.md) の別のセクションにある |

いずれもエラーとする。
位置は、評価のコードは印、G04101 と G04102 は参照を書いた印（輪では文書の順で最初の印）、G04103 と G04104 は対のない印、G07118 と G07119 は範囲の始めの印である。
コードの番号は、採択のときに、使われていない番号であり同じ時期の ADR と重ならないことを確かめて振り直した（「決めたことの記録」）。

## 実装しないこと

- **三段以上の階層**：v2 の「索引と参考文献の拡張」に残す。
- **縦組みの本の索引を横組みにして巻末から始めること**：v2 の「縦組みの本の中の横組みの部分」に残す。
- **自動の圧縮を止める設定**：makeindex の `-r` にあたる、連続するページを範囲にしない設定は作らない。要る本が出てから足す。
- **範囲の終わりの数字の省略**：「112–118」を「112–8」と組むような、範囲の終わりの数字の共通の桁を省く書き方は作らない。
- **InDesign の範囲の種類**：「次のスタイルの変更まで」「文書の終わりまで」「次の n 段落まで」のように、終わりの印を書かずに範囲を決める種類。始めと終わりの印で同じことを書ける。
- **見出しと参照の文言を変えるキー**：見出しの文字列、「を見よ」の文言、範囲の区切りの字、見出しの文字スタイルを `style.toml` で変えること。和文でない本の文言（`see`、`see also`）も含む。v1.0.0 の既定を使ってみてから決める。
- **HTML と EPUB の参照のリンク**：参照先の項目に `id` を付けて参照をリンクにすること。PDF のリンクは [ADR 0267](0267-pdf-bookmarks-and-links-inside-the-document.md) が扱う。
- **照合の規則の変更**：全角のラテン文字や半角の片仮名で書いた読みは、今の照合で一次のキーの種類 4 になり、見出しは `その他` になる。読みの正規化は照合の規則（[golem-doc ADR 0002](../golem-doc/adr/0002-document-assembly.md)）の側で決める。

## 不変条件

一つの `@index` の一覧について述べる。
印の列は、文書の順に並べた、その一覧に載る索引の印の列とする。

- **I1 見出しは項目を分ける**：組み立てが返す見出しの列を平らにした項目の列は、見出しを入れる前の項目の列と等しい。隣り合う見出しの文字列は異なり、どの見出しも項目を一つ以上持つ。
- **I2 見出しは一次のキーで決まる**：二つの項目の読みの最初の字の照合の一次のキーが等しければ、二つの見出しは等しい。とくに、平仮名、片仮名、濁音、半濁音、小書きの仮名で一次のキーの等しい字は、同じ見出しになる。
- **I3 範囲の対は入れ子の対である**：始めの印を `(`、終わりの印を `)` と読むと、項目ごとに、対にした印の組は括弧の対応と一致する。対を持たない始めの印と終わりの印はちょうど一度ずつ報告され（G04103、G04104）、ほかの印は報告されない。
- **I4 ページの列は重ならず、続くページは範囲になる**：PDF の項目のページの指し方の列は、始めのページの通し番号に真に増え、どの二つも同じページを共有しない。入力の点と区間が覆うページの集まりは、出力の点と区間が覆うページの集まりと等しい。隣り合う二つの要素では、前の要素の最後のページと後の要素の最初のページの通し番号の差が 2 以上であるか、後の要素の最初のページがセクションの最初のページである。出力の区間は、どれも二ページ以上を覆い、セクションの境をまたがない。
- **I5 参照の種類**：`SeeAuto` の参照は、項目がページの指し方を一つも持たないときに限り「を見よ」の形になる。
- **I6 参照先はある**：エラーなく組み立てた索引のすべての参照先の語は、同じ一覧のいずれかの項目の語と等しい。
- **I7 新しい記法を使わない本の変わり方**：`range` と `see` を書かず、`section-headings = false` の本の索引は、HTML では今と同じ行になる。PDF では、今の行のページの列のうち、同じセクションで続くページの最も長い並び（二ページ以上）を範囲に置き換えたものになる。続くページを持たない項目の行は、今と同じである。
- **I8 IR の往復**：どの `IndexEntry` も、CBOR に書いて読むと元に戻り、CDDL に合う。

境界の入力：

| 量 | 調べる値 |
| --- | --- |
| 一つの項目の印の列 | 空、点だけ、始めだけ、終わりだけ、始めと終わり、始め二つと終わり一つ、終わりが始めより先 |
| 区間と点のページ | 点が区間の始めのページ、終わりのページ、中、外の隣のページ |
| 二つの区間 | 離れる、隣り合う、一ページを共有する、一方が他方を含む、等しい |
| 二つの点 | 同じページ、隣のページ、一ページ空けたページ、セクションの境をはさむ隣のページ |
| 続く点の数 | 1、2（最も短い圧縮）、3 |
| 点と区間 | 点が区間の始めの前の隣のページ、終わりの後の隣のページ |
| 区間の両端 | 同じページ、隣のページ、終わりが前のページ、別のセクション |
| 見出し | 項目なし、一つの見出し、すべての見出し、行の境の字（`お` と `か`、`ん`、`ゔ`、`ー` で始まる読み） |
| 参照 | ページなしの項目、ページありの項目、参照先なし、参照先が二つ、自分自身、二つの項目の輪、副項目を持つ主項目を通る輪 |
| 一覧 | 一つ、二つ（範囲が境をまたぐ） |

## テスト設計

テストを先に書き、今の実装で失敗することを確かめてから実装する。
テストの名前には不変条件の番号を入れる。

- **golem-eval のテスト**：`range` と `see` の評価が `IndexKind` を作ること。G02144、G02145、G02146 の各原因の原稿が、そのコードだけを出すこと。
- **golem-doc のテスト**：I8。四つの種類と三つの `SeeKind` の `IndexEntry` の CBOR の往復と、CDDL の検査。プラグインの出力の検査が、段の数の誤った参照先を不正とすること。
- **golem-assemble のテスト**：I1、I2、I3、I5、I6。I3 は、一つの項目の印の列を長さ 5 まで（点、始め、終わりの三種）すべて列挙し、括弧の対応で作った素朴な対と、報告の数を比べる。golem-assemble のテストは golem-test-support に依存していないので、列挙はテストの中にリストの内包表記で書き、依存を足さない。I2 は、平仮名と片仮名の全字について見出しを求め、清音の行の表と比べる。G04101 から G04104 の原稿の結合のテストも置く。
- **golem-typeset のテスト**：I4、I5、I7。I4 は、ページ 1 から 5 の点と区間の組を項目あたり三つまで列挙し、セクションの最初のページが 1 だけの本と 1 と 3 の本の二つで組む。覆うページの集まりの一致、出力の列が真に増え重ならないこと、続くページが範囲になりセクションの境で分かれることを確かめる。I7 は、今の `indexLines` のテストの入力を `section-headings = false` で組み、続くページを持たない項目は今の期待値のまま通り、続くページを持つ項目は範囲に置き換えた期待値になること。区切りの字の横組みと縦組みの期待値も置く。
- **golem-html のテスト**：見出しの `<p class="index-heading">` と `<ul>` の組、範囲の二つのリンク、参照の文字列。
- **golem-driver のテスト**：G07118（送られる図版のキャプションに始めの印を置く）と、[ADR 0260](0260-front-matter-folios-and-page-labels.md) のセクションを持つ本で G07119 が出ること。範囲と参照と見出しを持つ索引の PDF のゴールデンのテスト。

## トレードオフ

- 範囲を始めと終わりの印で書くので、印を書き忘れると範囲が閉じない。ブロックの本体で範囲を囲む書き方なら閉じ忘れは起こらないが、ファイルをまたぐ範囲と、二つの範囲の交差を書けない（メンテナーが決めること 1）。閉じ忘れは G04103 で必ず報告されるので、黙って誤った索引になることはない。
- 終わりの印に、始めの印と同じ語と読みをもう一度書く。対の作り方を語と読みの一致だけにして、名前を付ける仕組みを足さないためである。
- `section-headings` の既定を `true` にするので、今の索引を持つ本の PDF と HTML は、実装の後に見出しの行が増える。ゴールデンのテストの期待値も変わる。
- 連続するページを自動で範囲にするので、続くページを持つ項目のある今の索引の PDF は、すべて変わる。二ページの続きも範囲にするので、「5, 6」と組みたい本は組めない。止める設定は作らず、要る本が出てから足す。
- 範囲の始めと終わりを `[index]` のキーワード引数で書くので、インラインの命令に始めと終わりの対が増える。ほかのインラインの命令にも始めと終わりの対が増えれば、文法を見直して記法を変えることがある（2026-11-09 の tett23 の注記）。そのときは新しい ADR で決める。
- 見出しの文言（`記号と数字`、`その他`）と参照の文言は和文に固定する。和文でない本の索引には合わない。
- 参照を括弧と文言で組むので、矢印（`→`）で組む索引より一行が長い。二段に組んだ狭い索引の段では、参照で行が折り返すことが増える（メンテナーが決めること 2）。
- 範囲の終わりが始めより前のページに来る場合（G07118）と、セクションをまたぐ場合（G07119）をエラーにするので、原稿の位置は正しくても、図版の送りや部分の切り方によって組めなくなる場合がある。どちらも黙って組むと読者に誤ったページを示すので、エラーを採る。

## メンテナーが決めること

1. **範囲の書き方**
   - 推奨：始めと終わりの二つの印（`range=begin`、`range=end`）。makeindex の `|(` と `|)` と同じ形で、ファイルをまたぐ範囲と交差する範囲を書け、閉じ忘れは G04103 で報告される。
   - 退けた案：ブロックの本体で範囲を囲む書き方（`@index-range` の本体）。閉じ忘れは起こらないが、章のファイルをまたぐ範囲と、二つの項目の範囲の交差を書けない。本文の構造に索引のための入れ子が入る。
   - 退けた案：ラベルの組（`from=` と `to=` に `@label` の名前を書く）。ファイルをまたげるが、終わりのページを「ラベルを付けたブロックの最後の行のページ」として新しく求める仕組みが要る。ラベルは相互参照の名前空間なので、索引のためにラベルが増える。
   - 退けた案：InDesign の「次のスタイルの変更まで」のような、終わりを書かない種類。終わりが原稿から読み取れず、終わりの位置を決める規則（どのスタイルの変更か、見出しの階層か）を別に決める必要がある。
2. **参照の文言**
   - 推奨：括弧と「を見よ」「をも見よ」（`（組版を見よ）`、`（印刷をも見よ）`）。種類が字で読み取れ、縦組みでも字の向きの問題が起きない。
   - 退けた案：矢印（`→組版`）。短いが、縦組みで矢印が行の方向を向くかどうかは、字の向きの扱い（UTR #50）とフォントに依存し、確かめていない。「を見よ」と「をも見よ」の違いも字に出ない。
   - 退けた案：英語の `see` と `see also`。和文の本に合わない。
3. **見出しの既定**
   - 推奨：既定で入れる（`section-headings = true`）。学術書の索引は見出しを持つのが普通で、既定だけで整った索引にするという方針に合う。
   - 退けた案：既定で入れない。今の出力を変えずに済むが、多くの本が同じキーを書くことになる。
   - 退けた案：見出しを仮名ごと（`あ`、`い`、`う`…）に分ける。項目の少ない索引で見出しが項目の数に近くなる。調査とロードマップの「あ」「か」の例は、行の見出しを指している。
4. **連続するページの自動の圧縮**
   - 推奨（2026-11-09 の tett23 の決定で改めた）：この ADR で入れ、二ページ以上続けば範囲にする。makeindex も既定で連続するページを範囲にする（`-r` で止める）。今の索引の出力と期待値は変わるが、1.0.0 の前に変える。
   - 退けた案：v2 に残す（草案の推奨）。今の出力を変えずに済むが、続くページを並べた索引が 1.0.0 に残る。
   - 退けた案：三ページ以上続けば範囲にする。「5, 6」を残す組み方もあるが、tett23 は二ページで圧縮すると決めた。
5. **範囲の区切りの字**
   - 推奨：横組みで en ダッシュ（U+2013）、縦組みで波ダッシュ（U+301C）。JLReq のハイフン類（cl-03）に両方が入り、横組みの算用数字には二分の en ダッシュ（makeindex の既定でもある）が釣り合い、縦組みの漢数字には全角で字を回さずに組める波ダッシュが釣り合う。今のページ番号の区切りも横組みと縦組みで字を変えている。
   - 退けた案：どちらも波ダッシュ。横組みの算用数字のあいだで全角の字幅を取る。
   - 退けた案：どちらも en ダッシュ。縦組みでは字を回して組む必要がある。
6. **セクションをまたぐ範囲**
   - 推奨：エラー（G07119）。前付けと本文のように様式の違うページ番号を「xii–3」とつなぐと、読者に意味の通らない範囲を示す。
   - 退けた案：両端を別のページとして「xii, 3」と組む。範囲であったことが消え、警告なしでは出力を黙って変えることになる。

## 決めたことの記録

2026-11-09 に、tett23 が次のとおり決めた。

1. 範囲は、推奨のとおり始めと終わりの二つの印（`range=begin`、`range=end`）で書く。tett23 は、インラインの命令に始めと終わりが増えるので、後で文法を変える可能性があると述べた。「トレードオフ」に書いた。
2. 参照の文言は、推奨のとおり括弧と「を見よ」「をも見よ」とする。
3. 見出しは、推奨のとおり既定で入れる（`section-headings = true`）。
4. 連続するページの自動の圧縮は、草案の推奨（v2 に残す）を改め、この ADR で入れる。二ページ続けば圧縮する（「5, 6」は「5–6」）。ページの指し方の規則、I4、I7、境界の入力、テスト、「実装しないこと」、ロードマップの扱いを改めた。セクションの境では、続くページでも圧縮しない。これは採択のときの判断であり、書いた範囲がセクションをまたぐ G07119 と同じく、様式の違うページ番号をつながないためである。
5. 範囲の区切りの字は、推奨のとおり横組みで en ダッシュ、縦組みで波ダッシュとする。
6. セクションをまたぐ範囲は、推奨のとおりエラー（G07119）とする。
7. diagnostic のコードは、採択のときに、docs/diagnostics.md と origin/main のコードで使われていない番号であり、同じ時期の ADR と重ならないことを確かめて、G02144、G02145、G02146、G04101、G04102、G04103、G04104、G07118、G07119 とした。
草案の仮の番号から振り直した。G04 の新しいコードは、docs/diagnostics.md の「番号の区分」のとおり 100 から振る。

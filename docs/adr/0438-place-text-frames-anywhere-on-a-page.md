# ADR 0438: ページの任意の位置にテキストフレームを置く

Status: superseded [{"part":"IR と ABI","by":[],"kind":"note","note":"メンテナーは 2026-11-25 に、IR と ABI の検査をすべての実装の後に行うと決め、この ADR を先に実装してよいとした。"},{"part":"実装すること","by":["docs/adr/0456-keep-every-block-off-around-frames.md"],"kind":"supplement"}]

## 文脈

今の Golem が文字を組む場所は、本文を流し込むフレーム（版面と段）と、柱とノンブルと傍注だけである。
InDesign のように、ページの任意の位置にテキストフレームを置き、その中に文字を組むことはできない。
扉の飾りの文、章の扉の引用、本文の外に置く囲み記事などは、テキストフレームが要る。

指示者は 2026-11-09 に、この機能を v1.0.0 に置くと決めた。
テキストフレームは、[root ADR 0437](0437-paths-and-the-box-model.md) の閉じたパスのボックスとして表し、その内側に文字を置く。
この ADR は、フレームを置く書き方、位置と大きさ、本文の流れとの関係、各ターゲットでの扱いを決める。

## 調査した事項

origin/main（[9efdc4f89](https://github.com/tett23/golem/commit/9efdc4f89b3fec75abcd37c11abb3e1d909c6725)）で、次のことを確かめた。

- マスターページ（`[masters.<名前>]`）が持つのは、柱とノンブルと、その文字スタイルだけである。
  柱とノンブルの位置は、`even` と `odd` の別と、`outside`、`inside` などの基準で、左右のページを分ける。
  仕様書に、ページの上の自由な座標で何かを置く書き方は無い。
- 仕様書の「幾何の隔離」は、意味論の IR が幾何を持たないと決めている。
- 回り込みの除外の領域は、段の始まりか終わりの側に寄せた幅で、図版の直後の段落の行だけを短くする。
  脇の行が本文の文字の大きさの 8 字に満たないときは G07022 にする。
  HTML と EPUB では、回り込ませる図版も回り込ませない図版として置く。
- フレームのレベルは、レベル 1 が一つの流れと段と除外の領域、レベル 2 が名前の付いたフレームのあいだを利用者の決めた順に流すこと、レベル 3 がフレームをまたぐ行の位置の合わせと見開きの制約である（仕様書の脚注）。
  [golem-project ADR 0002](../golem-project/adr/0002-style-toml.md) は、レベル 2 と 3 のフレームを「型として定義するが、値を書いた場合はエラーとする」と決めたが、golem-project のソースにフレームの型は無く、`[frames]` は知らないキーとして G03006 になる。
- 書字の方向は、`[page]` の `writing-mode`（`horizontal`、`vertical`）で決める。
- 左右固定モード（`[page]` の `layout = "single"`）では、ページの偶奇で左右を反転せず、柱とノンブルの `inside` と `outside` は G03018 になる（仕様書の 2113 行から）。
- `style.toml` のスタイルの名前と、プラグインと `.gm` のコマンドの名前は、英小文字で始まり、英小文字、数字、`-` だけからなる（仕様書の 2668 行と 8908 行）。
  `frame` という名前のコマンドは、リポジトリの中に無い。
- 原稿の統計は、独立したフレームの文字を本文の文字数から除く（[root ADR 0355](0355-manuscript-statistics.md)）。
  0355 の「マスターフレーム」は、本文の流れを受け持つフレームのことである。
- ロードマップは、記法、IR、ABI を変える項目を、「IR と ABI の設計と妥当性の検査」の後に扱うと決めている。

指示者は 2026-11-23 に、この項目の ADR を書くよう求めた。

## 実装すること

### フレームの定義

テキストフレームの形と位置は、`style.toml` の `[frames.<名前>]` で決める。
名前は、スタイルの名前と同じく、英小文字で始まり、英小文字、数字、`-` だけからなる。
フレームは、次のどちらかで形を持つ。

- `x`、`y`、`width`、`height`: 矩形のフレーム。
- `path` と `unit`: [root ADR 0437](0437-paths-and-the-box-model.md) のパスの書き方の閉じたパスと、その座標の単位。

座標の原点は、仕上がりの寸法（TrimBox）の上の端とし、`y` は下へ増える。
横の基準は `x-from` のキーで決め、`left`（既定、左の端から右へ）、`inside`（のどの端から小口へ）、`outside`（小口の端からのどへ）のどれかとする。
`inside` と `outside` では、左右のページでフレームを鏡に映して置く。
左右固定モード（`layout = "single"`）では、ページの偶奇で左右を反転しないので、`x-from` の `inside` と `outside` をエラーにする。
`path` の座標も、同じ原点と向きとし、`x-from` に従って鏡に映す。

長さは `style.toml` のほかの長さと同じ単位と、[root ADR 0346](0346-revise-named-layout-values.md) の値の名前で書く。
`zw` は、フレームの段落スタイルの文字の大きさで解く。
`path` の `unit` は、0437 のとおり `mm`、`pt`、`Q` のどれかとする。

フレームは、段落スタイル（`paragraph-style`）と、書字の方向（`writing-mode`、既定は `[page]` の値）を持つ。
行の位置は、[root ADR 0437](0437-paths-and-the-box-model.md) のボックスの規則のとおり、フレームの行の始まりの辺から、段落スタイルの行送りで並べる。
本文の行の位置には合わせない。

### レベル 2 と 3 のフレームとの関係

`[frames]` の表のフレームは、ほかのフレームへ文字を流さない、独立したフレームである。
[golem-project ADR 0002](../golem-project/adr/0002-style-toml.md) が決めたレベル 2 と 3 のフレームとは別のものとし、レベル 2 と 3 を入れるときは、別のキーの名前を使う。

### フレームを置く

フレームは、二つの方法で置く。

- マスターページ: `[masters.<名前>]` の `frames = ["<名前>", …]` に挙げたフレームは、そのマスターページを使うすべてのページに置く。
  中身は、`[frames.<名前>]` の `text` に書いた文字（式を含まない文字列）とする。
- 原稿: ブロックのコマンド `@frame <名前>` と、その中の段落を書くと、フレームを一つのページに置き、中身をそのフレームに組む。
  原稿に書くのはフレームの名前だけで、位置と形は書かない（幾何の隔離）。

`@frame` のフレームを置くページは、`@frame` より前にあって行を持つブロックのうち、最も近いものの最後の行が置かれたページとする。
行を持たないブロック（図版、別の `@frame`、改ページの命令など）は飛ばして数える。
前に行を持つブロックが無ければ、`@frame` より後にあって行を持つブロックのうち、最も近いものの最初の行が置かれたページとする。
どちらも無ければ、そのソースファイルの出力の最初のページとする。
`@frame` のブロックは、本文の流れで場所を占めない。
前後の段落の間隔と `@need-lines` は、`@frame` が無いときと同じに当てる。

マスターページが置くフレームを、0355 の「マスターフレーム」と区別するため、この ADR では「マスターページが置くフレーム」と呼ぶ。

一つのページに同じ名前のフレームが二つ置かれるときは、エラーにする。

`frame` は、組み込みのコマンドの名前とする。
`.gm` の関数とプラグインが `frame` を定義したときは、ほかの組み込みの名前と同じ diagnostic にする。

### IR と ABI

`@frame` の中身を各ターゲットに渡すため、意味論の IR に、フレームの名前と中のブロックを持つブロックを足す。
プラグインの ABI（`golem-doc.cddl`）と Emet の `Block` の構成子も、同じく足す。
版の上げ方は [root ADR 0052](0052-plugin-abi-version-bump-rule.md) に従う。
この ADR の実装は、ロードマップの「IR と ABI の設計と妥当性の検査」の後に行う。

### 本文の流れとの関係

フレームの `wrap` のキーで、本文との関係を決める。

- `wrap = "none"`（既定）: 本文は、フレームを無いものとして組み、フレームと重なってよい。
- `wrap = "around"`: フレームの外接矩形と重なる段ごとに、その段の本文の行のうち外接矩形の行の範囲に入る行を、段と外接矩形の重なりの幅の分だけ短くする。

`wrap = "around"` は、マスターページが置くフレームだけが使える。
外接矩形と重なる段のそれぞれで、重なりは、段の始まりか終わりの辺を含まなければならない。
含まないとき（行の途中を切るとき）と、`@frame` のフレームで `around` を書いたときは、エラーにする。
外接矩形が段の外（余白）にはみ出した部分は、行を短くしない。
ページを組み終えた後に置く `@frame` のフレームで本文を組み直すと、ページの割り付けが前後してしまうためである。
今の除外の領域（図版の直後の段落だけを短くする規則）とは別の規則とする。
短くした本文の行が、本文の文字の大きさの 8 字に満たないときは、エラーにする。
回り込む図版の G07022 とは原因が違うので、別のコードにする。

### 収まらないとき

フレームの中身が形に収まらないときは、エラーにして、そのフレームに中身を置かない。
ほかのページの組版は続け、diagnostic を集める。
マスターページが置くフレームのエラーは、フレームごとに一度だけ報告する。
ほかのフレームへ続きを流すこと（スレッド）はしない。

### 各ターゲット

HTML と EPUB は、フレームの位置と形を使わない。
`@frame` の中身は、コマンドの位置に、`<aside class="frame frame-<名前>">` の中の段落として書く。
プレーンテキストは、`@frame` の中身を、コマンドの位置の段落として書く。
マスターページが置くフレームの中身は、HTML、EPUB、プレーンテキストに書かない。
ページの飾りであり、リフローの本文に入れると読み手の流れを切るためである。

### diagnostic

次の原因に、それぞれ新しいコードを一つずつ足す。
コードの番号は、実装のときに空き番号から決める。

| 原因 | 重大度 |
| --- | --- |
| `[frames.<名前>]` が矩形のキー（`x`、`y`、`width`、`height`）と `path` を両方持つか、どちらも持たない | エラー |
| 矩形のキーの一部だけがある | エラー |
| `path` が閉じていない部分パスを持つ | エラー |
| 左右固定モードで `x-from` が `inside` か `outside` | エラー |
| `@frame` か `[masters.<名前>]` の `frames` に、`[frames]` に無い名前を書いた | エラー |
| `wrap = "around"` の重なりが段の辺を含まない | エラー |
| `@frame` のフレームに `wrap = "around"` を書いた | エラー |
| `wrap = "around"` で短くした本文の行が 8 字に満たない | エラー |
| フレームの中身が形に収まらない | エラー |
| 一つのページに同じ名前のフレームが二つ置かれる | エラー |

`style.toml` の値の誤り（上の四つ）は `style.toml` を読むときに、ほかは組むときに出す。
`style.toml` の値の誤りと、`[frames]` に無い名前は、LSP でも出す。

### 統計と LSP

原稿の統計は、[root ADR 0355](0355-manuscript-statistics.md) のとおり、フレームの中身を本文の文字数から除く。
LSP は、`@frame` のフレームの名前と、`[frames]` のキーを補完する。

### 文書とステータスの行

仕様書にテキストフレームの節を足し、マニュアルに使い方の節を足す。
`docs/diagnostics.md` と、マニュアルの diagnostic の付録に、「diagnostic」の表のコードを足す。
ロードマップの「任意のテキストフレームの配置」の項目を消す。
仕様書のフレームの節に、レベル 2 と 3 のフレームの型が無いことと、`[frames]` の表がそれとは別のものであることを書く。
採択したら、[golem-project ADR 0002](../golem-project/adr/0002-style-toml.md) のステータスに、`[frames]` のキーの使い方をこの ADR が補ったことを記録する。

## 実装しないこと

フレームのあいだで文字を流すこと（レベル 2）はしない。
フレームの行を本文の行の位置に合わせること（レベル 3）はしない。
フレームを回転させない。
画像のフレーム（画像だけを置くフレーム）は、この ADR では足さない。
固定レイアウトの EPUB は作らない。
`@frame` のフレームで本文を回り込ませることはしない。

## 不変条件

- I1: 矩形のフレームを置いたページで、フレームの文字は、すべて `x`、`y`、`width`、`height` と `x-from` で決まる矩形の内側にある。
- I2: `path` のフレームの文字は、すべて閉じたパスの内側にある（[root ADR 0437](0437-paths-and-the-box-model.md) の I2）。
- I3: `wrap = "none"` のフレームを置いても、本文の行の位置と行の中身は、`@frame` のブロックを消した原稿（マスターページが置くフレームでは、フレームを挙げないマスターページ）と等しい。
- I4: `wrap = "around"` のフレームを置いたページで、本文の文字はフレームの外接矩形と重ならない。
- I5: フレームの中身が形に収まらないとき、エラーになり、そのフレームに中身は置かれず、ほかのページは組まれる。
- I6: HTML と EPUB では、`@frame` の中身はコマンドの位置の `aside` の中にあり、マスターページが置くフレームの中身は無い。
  プレーンテキストでは、`@frame` の中身はコマンドの位置の段落である。
- I7: 原稿の統計の本文の文字数は、フレームの中身を含まない。
- I8: 一つのページに同じ名前のフレームが二つ置かれるとき、エラーになる。
- I9: `x-from = "inside"` のフレームは、左右のページで、のどの端から同じ距離にあり、`x-from = "outside"` のフレームは、左右のページで、小口の端から同じ距離にある。
- I10: 節 diagnostic の表の各原因は、その原因のコードだけを出す。
- I11: LSP は、`@frame` の名前の位置で、`[frames]` のすべての名前を補完の候補に出す。

| 入力 | 期待 | 不変条件 |
| --- | --- | --- |
| マスターページに矩形のフレームを一つ | 各ページの同じ位置にフレームの文字 | I1 |
| `x-from = "inside"` のフレームを持つマスターページ | 左右のページで鏡に映った位置 | I1, I9 |
| `x-from = "outside"` のフレームを持つマスターページ | 左右のページで鏡に映った位置 | I1, I9 |
| 左右固定モードで `x-from = "inside"` | エラー | I10 |
| 矩形のキーと `path` を両方持つフレーム | エラー | I10 |
| 矩形のキーも `path` も無いフレーム | エラー | I10 |
| 閉じていない `path` | エラー | I10 |
| `@frame` に `[frames]` に無い名前 | エラー | I10 |
| 直前が図版で、その前が段落の `@frame` | 段落の最後の行のページに置く | I1 |
| `@frame` が二つ続く | どちらも前の段落の最後の行のページに置く | I1 |
| 二つの段にかかる `wrap = "around"` のフレーム | 段ごとに重なりの幅だけ短くする | I4 |
| 余白にはみ出した `wrap = "around"` のフレーム | 段との重なりの幅だけ短くする | I4 |
| `wrap = "around"` で本文の行が 7 字になる | エラー | I10 |
| LSP で `@frame ` の後に補完を求める | `[frames]` の名前がすべて出る | I11 |
| `@frame quote` と 2 段落 | そのページのフレームに 2 段落 | I1 |
| ページの最後の行の直後の `@frame` | その行のページに置く | I1 |
| ページの最初の `@frame`（前に行を持つブロックが無い） | 後の最も近い行を持つブロックの最初の行のページに置く | I1 |
| 円の `path` のフレーム | 文字が円の内側 | I2 |
| `wrap = "none"` で本文と重なる位置 | 本文は `@frame` を消した原稿と同じ | I3 |
| マスターページの `wrap = "around"`、段の終わりの辺に接する | 本文がフレームを避ける | I4 |
| `wrap = "around"` で段の辺に接しない | エラー | I4 |
| `@frame` のフレームに `wrap = "around"` | エラー | I4 |
| フレームにちょうど収まる中身 | 組める | I5 |
| フレームに一行あふれる中身 | エラーで、ほかのページは組まれる | I5 |
| 同じページに同じフレームを二回 | エラー | I8 |
| HTML の出力 | `@frame` の中身が `aside` にあり、マスターページが置くフレームは無い | I6 |
| プレーンテキストの出力 | `@frame` の中身がコマンドの位置の段落 | I6 |
| フレームだけに文字がある原稿 | 本文の文字数が 0 | I7 |

## 受けいれ条件

A1: 扉の飾りの文（マスターページが置くフレーム）と、章の引用（`@frame`）を持つ見本を組み、PDF を目で見て、フレームの位置と本文の回り込みを確かめる。
見本は、見た目の回帰テストの見本に足す。

## テスト設計

root ADR 0438 I1 から I11 を名前の先頭に置いたテストを、golem-project、golem-typeset、golem-html、golem-text、golem-driver、golem-lsp に足す。
境界の表の各行を、小さなプロジェクトで組んで確かめる。
I3 は、`@frame` のブロックの有無の二つの原稿で、本文の行の位置と中身を比べる。
root ADR 0438 A1 は、見た目の回帰テストの見本で確かめる。

## トレードオフ

フレームの形と位置を `style.toml` に置き、原稿には名前だけを書くので、ページごとに少しずつ違う位置に置くには、フレームを位置ごとに定義する必要がある。
その代わりに、意味論の IR が幾何を持たず、HTML と EPUB の出力が変わらない。

`wrap = "around"` を、マスターページが置く、段の辺に接するフレームに限るので、本文の途中に置いた引用のまわりに本文を回り込ませることはできない。
その代わりに、ページを組み終えた後に組み直すことが無く、割り付けが決まる。

フレームのあいだで流さないので、長い囲み記事を複数のページのフレームに分けて置くことはできない。
収まらない中身はエラーにして、黙って切らない。

マスターページが置くフレームの中身を HTML と EPUB に書かないので、ページの飾りの文は、リフローの出力では読めない。

`[frames]` の名前をこの ADR が使うので、レベル 2 と 3 のフレームは別の名前のキーにする必要がある。

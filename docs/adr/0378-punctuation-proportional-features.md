# ADR 0378: 約物にも palt と vpal を適用できるようにする

ステータス: 採択

## 文脈

ルビと和文組版の拡張のうち、書き手が必要とする「約物のプロポーショナルメトリクスの逃げ道」の扱いを決める。

## 調査した事項

Golem [ADR 0053](0053-no-palt-on-jlreq-punctuation.md) は PDF の始め括弧類、終わり括弧類、句点類、読点類、中点類から palt と vpal を外す。

## 実装すること

書体の役割ごとに約物への比例幅機能の適用を許す真偽値を設ける。
既定は偽とし、真なら対象約物で指定済みの palt または vpal を抑制しない。
PDF 用のシェーピングに適用する。
HTML と EPUB は現行の CSS の機能指定に従う。
許可だけでは機能を有効にしない。

役割の punctuation-proportional が真で方向に対応する比例幅機能が有効なら、対象字には自動の fwid を追加しない。
書き手が明示した幅の機能は保つ。
kerning が japanese-equal-width のときは、従来の強制全角を優先して比例幅機能を無効にする。
以下の許可例は強制全角を指定していない場合とする。

## 実装しないこと

既存の原稿を新しい指定へ自動変換する機能は設けない。

## 不変条件

1. 許可した比例幅機能は計測と描画で同じ機能列に現れる。

| 境界の入力 | 期待する結果 |
| --- | --- |
| 許可だけ | 機能を追加しない |
| 許可と palt | 約物にも palt |

## テスト設計

- `inv1_punctuation_proportional_features_property` で次の述語を検査する。許可した比例幅機能は計測と描画で同じ機能列に現れる。
- `inv1_punctuation_proportional_features_case_1` は「許可だけ」を入力とし、「機能を追加しない」を確かめる。
- `inv1_punctuation_proportional_features_case_2` は「許可と palt」を入力とし、「約物にも palt」を確かめる。

## トレードオフ

フォント側の幅を使うと、JLReq のアキ量で設計した行長からずれる場合がある。

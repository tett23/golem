# ADR 0453: 組み込みのコマンドを、名前を並べた取り込みとプラグインで上書きできるようにする

Status: accepted

## 文脈

[root ADR 0451](0451-import-listed-names-without-a-namespace.md) は、名前を並べて取り込んだ名前が組み込みのコマンドの名前と同じなら G02270 のエラーにした。
プラグインは、組み込みのインラインのコマンドのうち表示に関わるものを、マニフェストの `overrides` で宣言して上書きできる（仕様書の「プラグイン」の節）。
一方、組み込みのブロックコマンドは、プラグインが上書きできない。

0451 の実装の後、組み込みのブロックコマンドの扱いが二か所で食い違うことが分かった。
G02270 は `@separator` を組み込みのブロックコマンドとして数えるが、プラグインが使えない名前の一覧には `@separator` が無い。
そのため、プラグインは `@separator` を宣言できるが、評価は組み込みの `@separator` を先に調べるので、プラグインの `@separator` は呼ばれない。

メンテナーは、2026-11-26 に次のことを決めた。

- 組み込みのコマンドに限り、名前を並べた取り込みとプラグインで上書きできるようにする。
- 評価や組版の構造を決めるコマンド（`@import`、`@set`、`@style`、`@frame` など）は、上書きできない。
- 組み込みの式の名前（`join`、`pi`、`e` など）は上書きできない。
  今の G02277 のままとする。
- 同じ組み込みのコマンドを、プラグインと名前を並べた取り込みの両方が上書きしたら、エラーにする。

この ADR は、上書きできるコマンドの一覧、上書きの書き方、名前が重なったときの diagnostic、評価の順を決める。

## 調査した事項

origin/main（[3d8d5a9](https://github.com/tett23/golem/commit/3d8d5a9caf94abafc7b58980bc6aa656e4a2084b)）で、次のことを確かめた。

- 組み込みのインラインのコマンドは、プラグインが上書きできる `OverridableBuiltin` と、できない `FixedBuiltin` に分かれる（[Builtin.hs#L31-L63](https://github.com/tett23/golem/blob/3d8d5a9caf94abafc7b58980bc6aa656e4a2084b/modules/golem-eval/src/Golem/Eval/Builtin.hs#L31-L63)）。
  上書きできるのは `strong`、`bold`、`italic`、`code`、`ruby`、`kenten`、`color`、`style`、`warichu`、`upright`、`tcy`、`number-text` の十二である。
  仕様書は十と書き、`warichu` と `upright` を挙げていない。
- 評価は、インラインのコマンドを、上書きを宣言したプラグイン、組み込み、プラグイン、名前空間つきの関数、名前を並べて取り込んだ関数の順に探す（[File.hs#L2815-L2823](https://github.com/tett23/golem/blob/3d8d5a9caf94abafc7b58980bc6aa656e4a2084b/modules/golem-eval/src/Golem/Eval/File.hs#L2815-L2823)）。
- プラグインが使えないブロックコマンドの名前の一覧 `builtinBlockCommands` に、`separator` は無い（[Builtin.hs#L157-L196](https://github.com/tett23/golem/blob/3d8d5a9caf94abafc7b58980bc6aa656e4a2084b/modules/golem-eval/src/Golem/Eval/Builtin.hs#L157-L196)）。
  この一覧の名前を宣言したプラグインは、G06005 の読み込みの誤りになる（[Plugin.hs#L409-L411](https://github.com/tett23/golem/blob/3d8d5a9caf94abafc7b58980bc6aa656e4a2084b/modules/golem-plugin/src/Golem/Plugin.hs#L409-L411)）。
- 評価は、ブロックコマンドを、組み込み（`separator` と `frame` を含む）、ファイルの設定、属性、プラグイン、名前空間つきの関数、名前を並べて取り込んだ関数の順に探す（[File.hs#L626-L689](https://github.com/tett23/golem/blob/3d8d5a9caf94abafc7b58980bc6aa656e4a2084b/modules/golem-eval/src/Golem/Eval/File.hs#L626-L689)）。
  そのため、プラグインの `@separator` は呼ばれない。
- G02270 が組み込みとして数える名前は、インラインでは組み込みのインラインのコマンドのすべて、ブロックでは `builtinBlockCommands`、ファイルの設定、属性と `separator` である（[File.hs#L735-L739](https://github.com/tett23/golem/blob/3d8d5a9caf94abafc7b58980bc6aa656e4a2084b/modules/golem-eval/src/Golem/Eval/File.hs#L735-L739)）。
- プラグインの上書きの宣言の誤りは G06007 と G06008 である。
  G06007 は、組み込みのコマンドと同じ名前を提供し `overrides` に書いていないときと、上書きできない組み込みのコマンドと同じ名前を提供したときに出る。
  G06008 は、`overrides` に、プラグインが提供していない名前か、上書きできる組み込みのコマンドでない名前を書いたときに出る（`docs/diagnostics.md` の G06007 と G06008）。

## 実装すること

### 上書きできるコマンド

組み込みのコマンドを、上書きできるものと、上書きできないものに分ける。

| 使う場所 | 上書きできる | 上書きできない |
| --- | --- | --- |
| インライン | 今の `OverridableBuiltin` の十二（`strong`、`bold`、`italic`、`code`、`ruby`、`kenten`、`color`、`style`、`warichu`、`upright`、`tcy`、`number-text`） | 今の `FixedBuiltin` の十二（`ref-number`、`ref-title`、`ref-page`、`note`、`sidenote`、`endnote`、`index`、`cite`、`aki`、`link`、`lang`、`shy`） |
| ブロック | 出力の中身を作るコマンド（`toc`、`index`、`bibliography`、`printings`、`separator`） | 上の五つのほかのすべて。取り込みと変数（`import`、`set`）、スタイル（`style`、`style-def`）、ファイルの設定（`manifest`、`hyphenation-exceptions`）、属性、チャネル（`channel`）、図表とコード（`figure`、`table`、`listing`。番号と参照の対象になる）、注（`note`、`endnote`）、フレーム（`frame`）、改ページと行の指定（`page-break`、`column-break`、`no-page-break`、`need-lines`、`page-lines`、`blank-line`）、言語（`lang`） |

上書きできないコマンドは、評価、ページ分割、参照、チャネルの仕組みが、そのコマンドの意味を前提にするものである。
上書きできるコマンドは、出力の中身だけを作り、ほかの仕組みがその中身を読まないものである。

`builtinBlockCommands` に `separator` を足し、組み込みのブロックコマンドの名前の一覧を、評価が組み込みとして扱う名前と一致させる。
この一覧は、上書きできる五つと、上書きできない名前に分かれる。
プラグインは、上書きできない名前を使えず、上書きできる五つを `block-overrides` で宣言したときだけ使える。
G02270 がブロックで数える名前は、上書きできない名前である。

### 名前を並べた取り込みでの上書き

名前を並べて取り込んだ名前が、その使う場所で上書きできる組み込みのコマンドと同じなら、エラーにしない。
その名前は、`@import` の行より後で、組み込みのコマンドの代わりに、取り込んだ関数を呼ぶ。
上書きは、`@import` を書いたファイルの中だけに適用される。

G02270 は、上書きできない組み込みのコマンドと同じ名前を並べたときだけに出す。
メッセージは `上書きできない組み込みのコマンドと同じ名前は取り込めません: <名前>` にする。

組み込みの式の名前（G02277）、予約語（G02275）、ほかの取り込み（G02272）、同じ並び（G02273）、`@set` の変数（G02274）の扱いは、0451 のまま変えない。

### プラグインでの上書き

プラグインは、上書きできる組み込みのブロックコマンドを、マニフェストの `[plugins.<名前>]` の新しいキー `block-overrides` で宣言して上書きできる。
`block-overrides` は、上書きする組み込みのブロックコマンドの名前の配列である。
インラインのコマンドの `overrides` と別のキーにするのは、`style` のように、インラインとブロックの両方にある名前があるためである。

`block-overrides` の宣言の誤りは、インラインの `overrides` と同じ原因なので、同じコードにする。
どちらも、golem-evaluate がマニフェストとプラグインの `golem_describe` の結果を照らして出す。

- 組み込みのブロックコマンドと同じ名前を提供し、`block-overrides` に書いていない。
  または、上書きできない組み込みのブロックコマンドと同じ名前を提供した。
  どちらも G06007 とし、提供した名前ごとに一つ出す。
- `block-overrides` に、プラグインが提供していないブロックコマンドか、上書きできる組み込みのブロックコマンドでない名前を書いた。
  G06008 とし、書いた名前ごとに一つ出す。

今は、組み込みのブロックコマンドと同じ名前を提供したプラグインは、golem-plugin の `golem_describe` の検査で G06005（`組み込みのブロックコマンドの名前です: <名前>`）になる。
この原因は G06007 と同じなので、G06005 のこの文言をやめ、G06007 に移す。
G06005 のほかの原因（名前の形の誤り、二度書いた名前）は変えない。

評価は、ブロックコマンドを、`block-overrides` で上書きを宣言したプラグイン、組み込み、ファイルの設定、属性、プラグイン、名前空間つきの関数、名前を並べて取り込んだ関数の順に探す。
インラインのコマンドを探す順と同じ形である。

### 上書きが重なったとき

同じ組み込みのコマンドを、プラグインが上書きを宣言し（`overrides` か `block-overrides`）、名前を並べた取り込みも上書きしたら、G02271 とする。
G02271 は、名前を並べた名前がプラグインのコマンドの名前と同じときのコードで、上書きを宣言したプラグインのコマンドも、プラグインのコマンドの名前として数える。
メッセージは今と同じ `プラグインのコマンドと同じ名前は取り込めません: <名前>` にする。
どちらを呼ぶかを、評価が探す順で決めないためである。

G02271 になった名前は、その使う場所に取り込まない。
そのため、呼び出しは上書きを宣言したプラグインのコマンドを呼ぶ。

### 名前を探す順

名前を並べた取り込みが上書きした組み込みのコマンドの呼び出しは、そのファイルの中で、取り込んだ関数を呼ぶ。
探す順は、使う場所ごとに次のとおりである。

1. 上書きを宣言したプラグインのコマンド
2. 名前を並べた取り込みが上書きした、上書きできる組み込みのコマンドの名前
3. 組み込みのコマンド（ブロックでは、ファイルの設定と属性も）
4. プラグインのコマンド
5. 名前空間つきの関数
6. 名前を並べて取り込んだ、ほかの名前の関数

1 と 2 は G02271 で同時には成り立たないので、この二つの順は結果を変えない。

2 の名前には、そのファイルで並べて、その使う場所に取り込んだ名前のすべてを含む。
0451 で何も出力しない呼び出しとして取り込む名前（読み込めなかった `.emet` から並べた名前と、G02272 になった名前）も含む。
そのため、これらの名前の呼び出しは、組み込みのコマンドを呼ばず、何も出力しない。
書き手が上書きを意図して並べた名前で、組み込みのコマンドの出力が黙って出ないようにするためである。

上書きした名前の呼び出しは、組み込みのコマンドの名前で決まる前処理と短縮記法を、組み込みのコマンドと同じく受ける。

- `##N##` は `[number-text N]` として読むので、`number-text` を上書きした取り込みの関数を呼ぶ。
  プラグインの上書きで `##N##` も変わるのと同じである。
- `[code …]` と、第一引数が `code` の `[style …]` の散文スロットは、組み込みのコマンドと同じく、短縮記法を文字のまま渡す。

### ツール

- **LSP**：上書きした名前の呼び出しで、定義への移動は取り込んだ関数の定義へ移る。
  補完は、組み込みのコマンドと取り込んだ名前を一つの候補にまとめる。
- **golem lint**：上書きした名前の呼び出しを、G05003 の検査で使われたと数える。

### 文書

仕様書の次の箇所を書き換える。

- 「プラグイン」の節の上書きできるコマンドの一覧を、上の表にする。
  インラインは十二と書き、`warichu` と `upright` を足す。
- 「プラグイン」の節の「組み込みのブロックコマンドは上書きできない」を、`block-overrides` の記述にする。
- 「プラグイン」の節の、`golem_describe` のブロックコマンドの名前の誤り（G06005）の箇条から、組み込みのブロックコマンドの名前を除く。
- マニフェストの節に `block-overrides` を足す。
- 「定義の取り込み」の名前の重なりの表で、G02270 を「上書きできない組み込みのコマンドの名前」にし、G02271 の相手に上書きを宣言したプラグインのコマンドを足す。

`docs/diagnostics.md` の G02270、G02271、G06005、G06007、G06008 の説明を直す。

採択したら、0451 のステータスに `{"part":"名前が重なったとき","by":["docs/adr/0453-override-built-in-commands-by-listed-imports-and-plugins.md"],"kind":"replace"}` を記録する。
[docs/adr/0122](0122-block-commands-in-plugins.md) のステータスにも、`{"part":"宣言","by":["docs/adr/0453-override-built-in-commands-by-listed-imports-and-plugins.md"],"kind":"replace"}` を記録する。
0122 の「宣言」の節の、組み込みのブロックコマンドの名前を G06005 とした部分と、組み込みのブロックコマンドを上書きできないとした部分を、この ADR が置き換える。

## 実装しないこと

組み込みの式の名前の上書きはしない。
名前空間つきの取り込み（`* as`）では、上書きは起きない（名前空間を通して呼ぶので、組み込みの名前と重ならない）。
上書きした名前の中から、元の組み込みのコマンドを呼ぶ書き方は足さない。
`.emet` の `pub block` で上書きできない組み込みの名前を公開することは、今と同じく禁じない（名前を並べたときに G02270 になる）。

## 不変条件

- I1: 読み込めた `.emet` から、上書きできる組み込みのコマンド c と同じ名前を並べ、重なりの diagnostic が無いファイルを考える。
  そのファイルの `@import` の行より後で、c を上書きした使う場所の c の呼び出しの結果は、同じ関数を `* as ns` で取り込んだ `ns.c` の呼び出しの結果と同じであり、G02270 は出ない。
  ただし、散文スロットに短縮記法を含む `[code …]` と、第一引数が `code` の `[style …]` は除く。
- I2: 上書きできない組み込みのコマンドと同じ名前を並べると、その名前の位置に G02270 がちょうど一つ出て、その使う場所の呼び出しは組み込みのコマンドを呼ぶ。
- I3: 名前を並べた取り込みが上書きした名前の、`@import` の行より前の呼び出しと、ほかのファイルの呼び出しは、組み込みのコマンドを呼ぶ。
- I4: `block-overrides` で上書きを宣言したプラグインのブロックコマンドの名前の呼び出しは、プラグインを呼ぶ。
- I5: 同じ組み込みのコマンドを、上書きを宣言したプラグインと名前を並べた取り込みの両方が上書きすると、その名前の位置に G02271 がちょうど一つ出て、その呼び出しはプラグインを呼ぶ。
- I6: プラグインも取り込みも無い原稿で、組み込みのブロックコマンドの名前の一覧の各名前のブロックコマンドは G02009 にならず、一覧に無い名前は G02009 になる。
  一覧は、上書きできる五つと、G02270 がブロックで数える名前の、交わらない和である。
- I7: 実装することの G06007 の原因に当たる名前ごとに G06007 がちょうど一つ出て、G06008 の原因に当たる `block-overrides` の名前ごとに G06008 がちょうど一つ出る。
  どちらの原因にも当たらなければ、どちらも出ない。
- I8: 上書きできる組み込みのコマンドの名前を、読み込めなかった `.emet` から並べたときと、G02272 になったときは、その使う場所の `@import` の行より後の呼び出しは何も出力しない。
- I9: `number-text` を名前を並べて上書きしたファイルで、`##N##` は `[number-text N]` と同じ結果になる。

## 受けいれ条件

なし。
不変条件のテストで足りるためである。

## テスト設計

root ADR 0453 I1 から I9 を名前の先頭に置いたテストを足す。
golem-eval のテストで、上書きできるコマンドとできないコマンドを、インラインとブロックのそれぞれで列挙し、I1、I2、I3、I8、I9 を確かめる。
I1 は、上書きできる十七のコマンドのすべてで確かめる。
I6 は、一覧の各名前と一覧に無い名前のブロックコマンドを評価して G02009 の有無を確かめ、二つに分けた一覧の和と交わりを確かめる。
golem-evaluate のテストで、`block-overrides` の宣言と誤り（I4、I7）と、上書きの重なり（I5）を確かめる。
golem-plugin のテストで、組み込みのブロックコマンドの名前を `blocks` に持つプラグインを、`golem_describe` の検査で拒まない（G06005 にしない）ことを確かめる。
golem-lsp のテストで、上書きした名前の定義への移動と補完を、golem-lint のテストで、上書きした名前の呼び出しを G05003 の検査で使われたと数えることを確かめる。
テストは、実装の前に書いて落ちることを確かめる。

## トレードオフ

上書きできるブロックコマンドを出力の中身を作る五つに限るので、改ページや注の扱いを取り込んだ関数で変えることはできない。
その代わりに、ページ分割、参照、チャネルの仕組みが前提にするコマンドの意味は、どの原稿でも変わらない。

上書きを `@import` の行で名前を並べるだけで許すので、原稿の読み手は、`@toc` が組み込みの目次かどうかを、そのファイルの `@import` の行を見ないと知れない。
名前を並べた取り込みは、0451 で、名前の出どころを `@import` の行から読めるようにした形なので、この読み方に合う。
プラグインの上書きはマニフェストで宣言するので、原稿を見ても分からない。
今のインラインの `overrides` と同じ扱いである。

`block-overrides` を `overrides` と別のキーにするので、マニフェストのキーが一つ増える。
一つのキーにまとめると、`style` のように両方にある名前で、どちらを上書きするかを書き分けられない。

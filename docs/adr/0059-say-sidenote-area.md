# ADR 0059: 「傍注欄」を「傍注の領域」と言い換える

ステータス: 採択

## 文脈

マニュアルの用語を直す作業（プルリクエスト #284）で、「欄」の語を見直した。
引数やキーの意味の「欄」は直したが、版面の外に設ける傍注の置き場所を指す「傍注欄」は残した。

メンテナーは、「傍注欄」も言い換えると決めた。
「欄」は、表の列や書式の項目を指す語としても使っており、紙面の場所を指す語と紛れるためである。
置き換える語は「傍注の領域」とした。
仕様書が紙面の場所を「版面」「余白」のように呼ぶのにそろえる。

「傍注欄」は、diagnostic のメッセージにも入っている。

- G0734：`傍注欄（style.toml の [sidenotes]）のない版面では傍注を使えません`
- G0733：`傍注が傍注欄より高く、収まりません`、`このページの傍注が傍注欄に収まりません`
- G0701：`縦組みの版面には傍注欄を設けられません`、`段組みの版面には傍注欄を設けられません`、`版面と傍注欄の合計がページからはみ出しています`

メッセージを変えるので、この ADR を起こす。

## 実装すること

- 次のメッセージの「傍注欄」を「傍注の領域」にする。ほかの語とコードは変えない。

| コード | 新しいメッセージ |
|---|---|
| G0734 | `傍注の領域（style.toml の [sidenotes]）のない版面では傍注を使えません` |
| G0733 | `傍注が傍注の領域より高く、収まりません`、`このページの傍注が傍注の領域に収まりません` |
| G0701 | `縦組みの版面には傍注の領域を設けられません`、`段組みの版面には傍注の領域を設けられません`、`版面と傍注の領域の合計がページからはみ出しています` |

- 書き換える場所は、golem-driver の `Golem.Driver.Pdf` と golem-layout-spec の `Golem.LayoutSpec` と、それぞれのテストである。
- 次の文書の「傍注欄」を「傍注の領域」にする。コミット済みの ADR と監査の記録（`docs/audits/`）は変えない。
  - docs/specifications.md、docs/markup.md、docs/diagnostics.md、docs/glossary.md、docs/roadmap.md、docs/manual-policy.md、README.md
  - 使い手のマニュアル（第 3 章、第 5 章、付録 C、付録 E、`manual/style.toml` のコメント）
  - 開発者のマニュアル（第 6 章）
- 用語集の見出しの語を「傍注の領域」にし、旧い ADR が「傍注欄」と書いていることを添える。
- textlint の review-words に、「傍注欄」を報告する語を足す。「」で囲んだ引用は報告しない。

## 実装しないこと

- G0733 の二つのメッセージを、別のコードに分けること。二つは原因が違う（一つの傍注が領域より高いことと、ページの傍注の合計が領域に収まらないこと）ので、仕様書の「設計原則」の「一つのコードに一つの原因」に照らせば分けるべきだが、ロードマップの v1.0.0 の「一つのコードに一つの原因の監査」で G0701 などと合わせて扱う。
- コミット済みの ADR の「傍注欄」を変えること。
- `style.toml` のキー（`[sidenotes]`）の名前を変えること。

## テスト設計

テストを先に新しいメッセージに改め、今の実装で失敗することを確かめる。

- golem-layout-spec の `test/Main.hs`：縦組みの版面と傍注、版面と傍注の領域のはみ出しの二つのテストの期待するメッセージ。
- golem-driver：G0733 と G0734 のメッセージを確かめるテスト（なければ、`TooTall`、`DoesNotFit`、`[sidenotes]` のない版面の三つを足す）。
- golem-driver の diagnostics.md とソースの一致の検査（`explanations`）が、新しいメッセージで通ること。
- textlint の規則のテスト（`tools/textlint/test/`）に、「傍注欄」を報告し、「」の中の「傍注欄」を報告しない二つの項目を足す。

## トレードオフ

- 語が長くなり、メッセージも長くなる。
- 旧い ADR と監査の記録は「傍注欄」のまま残るので、文書のあいだで語が揺れる。用語集で旧い語を引けるようにして補う。

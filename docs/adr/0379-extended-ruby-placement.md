# ADR 0379: ルビのかけ方、置く側、両側の読みを指定する

ステータス: 採択（未実装）

## 文脈

ルビと和文組版の拡張のうち、書き手が必要とする「ルビの拡張」の扱いを決める。

## 調査した事項

ロードマップの「ルビと和文組版の拡張」は「ルビの拡張」を v1.0.0 の対象に挙げている。

## 実装すること

熟語の各部分を配置できず読みの総幅が親の総幅を超える場合は一つのグループとして組み直す。
前後それぞれのかけを許可でき、約物には実際の空きまでかける。
行端側のかけを 0 にして親を行端にそろえる。
ルビごとの指定はスタイルの配置、読みのサイズ、置く側を上書きする。
両側の読みは別々に測り、圏点は各読みの外側に置く。

例は `[ruby side=before overhang-side=start: 東/京|とう/きょう]` とし、side は before、after、both、overhang-side は none、start、end、both とする。
before は横組みで上、縦組みで右である。
both では二つ目の読みを第 3 スロットに書く。
読みの size は正の寸法とし、読みが足りない場合と余分な場合は原稿位置で拒む。

## 実装しないこと

既存の原稿を新しい指定へ自動変換する機能は設けない。

## 不変条件

1. 各側で隣の字にかかる幅は、その側で許された上限以下である。

| 境界の入力 | 期待する結果 |
| --- | --- |
| 片側だけ許可 | 反対側のかけ0 |
| 行端 | 外側のかけ0 |
| 両側ルビ | 各側に一つの読み |

## テスト設計

- `inv1_extended_ruby_placement_property` で次の述語を検査する。各側で隣の字にかかる幅は、その側で許された上限以下である。
- `inv1_extended_ruby_placement_case_1` は「片側だけ許可」を入力とし、「反対側のかけ 0」を確かめる。
- `inv1_extended_ruby_placement_case_2` は「行端」を入力とし、「外側のかけ 0」を確かめる。
- `inv1_extended_ruby_placement_case_3` は「両側ルビ」を入力とし、「各側に一つの読み」を確かめる。

## トレードオフ

両側の読みと圏点のために、隣の行との間に必要な寸法が増える。

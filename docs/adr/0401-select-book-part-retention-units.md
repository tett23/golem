# ADR 0401: 本の部品を保つ単位を本全体で指定する

Status: proposed

## 文脈

[root ADR 0377](0377-keep-book-parts.md) はページと見開きを単位に部品を保つと決めた。
保持単位を指定する場所と、段組みの版面での扱いを補足する。

## 調査した事項

現在のロードマップの「部品を保つ単位の指定」は、指定場所、省略時の単位、段の間の分割、項目内分割の通知を未決としている。
root [ADR 0377](0377-keep-book-parts.md) は、空の保持単位にも収まらない部品を次の単位へ一度だけ移し、通常の分割位置を使うと定めている。

## 実装すること

[composition]の keep-parts に column、page、spread のいずれかを指定する。
本全体の表、リスト項目、定義リストの用語と最初の説明行、図とキャプションに適用する。
省略時は column とし、現在の段を単位にした組み方を保つ。
不正な値は設定の読み込みで拒む。

page では同じ物理ページの段の間で部品を分けられる。
spread では同じ見開きの段の間とページの間で部品を分けられる。
保持単位の境界で分ける位置と、空の単位にも収まらない場合の処理は root [ADR 0377](0377-keep-book-parts.md) に従う。
見開きは、物理ページの 2 と 3、4 と 5 のような偶数ページとその次の奇数ページの組とする。
最初のページと、対応する相手がない最後のページは、それぞれ一ページの単位として扱う。
ノンブルの番号、表記と付け直しは、この組み合わせを変えない。

部品を空の保持単位に移しても保てず、通常の分割位置を使ったときは、専用の notice を一度出す。
notice には部品の原稿位置と種類、選んだ保持単位を書く。
分割不能の図や単独の表の行が空の領域にも収まらない場合は、既存の寸法エラーに従う。

## 実装しないこと

部品ごとの設定と原稿内での保持単位の切り替えは追加しない。
複数の見開きを比較して過去の分割位置を選び直す探索は行わない。

## 不変条件

I1: keep-parts を省略した入力のページ配置は、変更前の同じ入力と一致する。
I2: 一つの保持単位内での段の移動だけでは、保持単位を越えた扱いをしない。
I3: 一度空の保持単位で失敗した同じ部品を、同じ条件の空の単位へ繰り返し送らない。

| 入力 | 期待 | 不変条件 |
| --- | --- | --- |
| 指定なし | 従来の段単位 | I1 |
| page、二段のページの段境界 | 同じ単位の中で続ける | I2 |
| spread、物理ページ2と3 | 同じ単位の中で続ける | I2 |
| spread、物理ページ3と4 | 新しい単位へ移る | I2 |
| 空の単位にも収まらない項目 | 通常の分割を使いnotice一度 | I3 |

## 受けいれ条件

A1: 通常 CLI の PDF 出力で、表、リスト、定義リスト、図とキャプションに選択した保持単位が適用される。

## テスト設計

root ADR 0401 I1、I2、I3 を先頭に置いた試験で、各保持単位と段数、物理ページ境界、空の部品、ちょうど収まる部品、一行あふれる部品、空の単位にも収まらない部品を検査する。
notice の原稿位置と回数、寸法エラー、終了することも検査する。
root ADR 0401 A1 の通常 CLI 試験で各種類の部品を含む原稿を生成し、ページと段の配置を照合する。

## トレードオフ

本全体に一つの設定を使うため、設定箇所が少ない。
一部の部品だけを別の単位で保つ用途は、今回の設定では表せない。

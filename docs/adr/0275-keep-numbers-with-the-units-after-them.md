# ADR 0275: 数とその後の単位や助数詞を、行末と次の行頭に分けない

ステータス: 採択→（数と単位の組のコードの境、縦組みの全角の数字の並び、W2 の読み方）は [ADR 0282](0282-record-what-the-implementations-of-adr-0274-and-0275-decided.md)

## 文脈

### ロードマップの項目

[docs/roadmap.md](../roadmap.md) の v1.0.0 の「行分割と禁則」に、次の項目がある。

- **語句の泣き別れの禁止**：数と単位（`100｜円`）、人名、熟語のように、一続きに読ませたい語句が、行末と次の行頭に分かれないようにする。どの語句を自動の規則で分けないか（数と単位、助数詞など）と、書き手が分けない範囲を指定する記法を ADR で決める。分けないために行の調整がどれだけ崩れてよいか（追い込みと追い出し、字のあいだの空きの上限）も合わせて決める。書き手が分けない範囲は、文字スタイル `no-break`（[ADR 0272](0272-discretionary-hyphens-hyphenation-exceptions-and-no-break.md)）で書く。「追い込みと追い出しの設定」の後に扱う。

「追い込みと追い出しの設定」は [ADR 0274](0274-prefer-pulling-in-and-limit-the-stretch-of-lines.md) が扱う。
数の字と省略記号の分割禁止（`100％`、`￥１００`、全角の数字の並び）は、JLReq の 3.1.10 の規定として [golem-layout ADR 0049](../golem-layout/adr/0049-align-the-character-classes-and-unbreakable-pairs-with-jlreq.md) が扱う。
この ADR は、JLReq が分割禁止としない語句を扱う。

### 今の振る舞い

半角の数字は欧文の字なので、`100` は一つの語の箱になり、字のあいだでは分けない。
数の後の和字（`円`、`人`、`年`）とのあいだは、和欧間の空きのグルーが分割の候補になる（[`between`](https://github.com/tett23/golem/blob/9608953da3806ab63cb82abf091bfc1e04b76533/modules/golem-layout/src/Golem/Layout/Japanese.hs#L1722-L1755)）。
全角の数字の後の和字とのあいだも、漢字等どうしの字のあいだとして分割の候補になる。
そのため、`100｜円`、`3｜人`、`2026｜年` の形で行が分かれうる。

JLReq は、数と和字の単位や助数詞のあいだを分割禁止としない。
3.1.10 は、`50パーセント` の `0` と `パ` のあいだを分割してよい例として挙げる。
分けないのは、読みやすさのための組版の選択であり、JLReq の規定ではない。
InDesign でこの位置がどう扱われるかは確かめていない。

### 書き手が範囲を指定する手段は、すでにある

[ADR 0272](0272-discretionary-hyphens-hyphenation-exceptions-and-no-break.md) が、文字スタイルの欄 `no-break` と、組み込みの文字スタイル `no-break` を入れた。
`[style no-break: 夏目漱石]` と書けば、範囲の中では改行しない（[`keepRanges`](https://github.com/tett23/golem/blob/9608953da3806ab63cb82abf091bfc1e04b76533/modules/golem-layout/src/Golem/Layout/Japanese.hs#L501-L534)）。
範囲が行に収まらなければ、はみ出す行を作って G07122 で報告する。

正規表現スタイル（[docs/adr/0015](0015-regex-styles.md)）で `no-break` の文字スタイルを当てれば、書き手の決めた語句を自動で分けないこともできる。
たとえば、段落スタイルに `{ pattern = '第[0-9０-９]+[章節]', style = "no-break" }` を書けば、`第3章` を分けない。
ただし、正規表現スタイルは見出し、定義リストの用語、注の本文には当たらない（[docs/specifications.md](../specifications.md) の正規表現スタイルの段落）。

人名と熟語は、字の分類からは見分けられない。
見分けるには辞書か形態素の解析が要り、辞書の版で出力が変わる。

### 分けないと、どれだけ崩れるか

分割の候補を消すと、行分割は前後の候補で行を終える。
行長に収まる分割が許容度の範囲になければ、最後の段階で数を次の行へ送り出し、前の行の字のあいだを空ける（[docs/specifications.md](../specifications.md) の「行分割」）。
[ADR 0274](0274-prefer-pulling-in-and-limit-the-stretch-of-lines.md) の後は、まず約物の空きを詰めて単位を前の行に追い込むことを試み、送り出した行の空きは段落スタイルの `stretch-limit` で頭打ちにできる。
分けない規則の強さを罰点で決めれば、分けるか崩すかの釣り合いを、ほかの分割の候補と同じ罰点の和で量れる。
罰点の値の読み方は、地の文の明示のハイフンの後の候補（`explicit-hyphen-penalty`）と同じである。

## 実装すること

### 1. 数と単位を分けない規則

`normalize` の `between` に、隣り合う二つの箱の、前の箱の最後の字 a と後の箱の最初の字 b について、次の規則を足す。

- a がアラビア数字（[golem-layout ADR 0049](../golem-layout/adr/0049-align-the-character-classes-and-unbreakable-pairs-with-jlreq.md) の `isArabicDigit`。半角と全角）で、b の分類が仮名か漢字等（`Kana` か `Ideograph`）なら、その位置の分割の候補の罰点を `[composition]` の `number-unit-penalty` にする。

`100円`、`3人`、`2026年`、`１０冊`、`3つ`、`5パーセント` の数と次の一字のあいだが当たる。
次の一字の後（`2026年｜に`）は、今のとおり分けてよい。
漢数字（`三人`）には当てない（「メンテナーが決めること」の 3）。

隣り合う字にだけ当て、語間の空白とコードの空白を挟む組（`100 円`）には当てない。
本文の中のコード（`lkCode`）と URL（`lkUrl`）の箱どうしのあいだには当てない。
ルビの箱の端の字は、今の禁則と同じく字として見ない。
縦組みでも横組みと同じに当てる。

### 2. `[composition]` の `number-unit-penalty`

罰点は `[composition]` の `number-unit-penalty` で決める。
値は −9999 から 10000 までの整数で、既定は 10000 とする。
10000 なら、その位置を分割の候補にしない。
10000 より小さい値なら、その位置の候補を、その罰点で幅 0 の罰点の項目にする。
あいだに空きのグルーがあれば、罰点の項目をグルーの前に置き、グルーは候補にしない（前の項目が箱でないグルーは候補にならない）。
空きのグルーの幅と伸び縮みは変えない。

範囲外の値と整数でない値は、その値の位置で G03006 とする（`explicit-hyphen-penalty` と同じ）。
`@style-def` では書けない。

### 3. 書き手が分けない範囲

書き手が分けない範囲は、[ADR 0272](0272-discretionary-hyphens-hyphenation-exceptions-and-no-break.md) の文字スタイル `no-break` で書き、新しい記法は足さない。
人名と熟語の自動の規則は持たない。
[docs/markup.md](../markup.md) の文字スタイルの節に、人名と熟語を `[style no-break: …]` で包む例と、正規表現スタイルで `第3章` のような語句を分けない例を足す。

### 4. はみ出す行の報告

`number-unit-penalty` が 10000 で、数と単位の組を分けないために行長に収まる分割がなくなった行は、ほかの禁則で分けられない行と同じく G07105 で報告する（[docs/adr/0210](0210-warn-overfull-lines-in-build.md)）。
はみ出しを測る位置の箱が改行しない範囲の箱なら、今のとおり G07122 とする。
新しいコードは足さない（「メンテナーが決めること」の 5）。

### 5. HTML と EPUB

HTML と EPUB には書き出さない。
ブラウザーの改行は UAX #14 によるので、数と和字のあいだで分けうる。
`no-break` の範囲は、今のとおり `white-space: nowrap` で分けない。

### 6. 文書

- [docs/specifications.md](../specifications.md) の「行分割」の節に、数と単位の規則、`number-unit-penalty` の値と既定、空白を挟む組とコードと URL に当てないことを書く。`[composition]` の欄の段落にも足す。
- [docs/markup.md](../markup.md) に、3 の例を足す。
- [docs/roadmap.md](../roadmap.md) の v1.0.0 の「行分割と禁則」から「**語句の泣き別れの禁止**」の行を消す。
- [TeX と InDesign との差異](../differences-from-tex-and-indesign.md) に、JLReq が分割禁止としない位置を既定で分けないこと、InDesign の振る舞いを確かめていないことを書く。

### 7. 出力の変化

数の後に和字が続く箇所を含む段落の行の分け方が変わりうる。
二つのマニュアル、golden、complex fixture、kanikosen の PDF と決定性のハッシュが変わりうる。
実装のプルリクエストで、この規則で候補を消した位置の数と、その位置で分けていた行の数を、二つのマニュアルと kanikosen で数えて説明に書く。

## 実装しないこと

- **人名と熟語の自動の規則**：辞書か形態素の解析が要り、辞書の版で出力が変わる。書き手が `no-break` で書く（「メンテナーが決めること」の 4）。
- **新しい記法**：`no-break` の文字スタイルで書ける。
- **数の前の語との組（`第｜3`、`約｜100`）**：正規表現スタイルで書き手が決める（「メンテナーが決めること」の 2）。
- **数と単位を分けないために空きを詰める量の上限**：詰める量はアキ量のセットの最小が決め、空ける量は [ADR 0274](0274-prefer-pulling-in-and-limit-the-stretch-of-lines.md) の `stretch-limit` が決める。この ADR は罰点だけを決める。
- **正規表現スタイルを見出しと注の本文に当てること**：ロードマップの「組版の自由の原則に反する箇所」の「正規表現スタイルの届かない文字」で扱う。

## 不変条件

「隣り合う字の組」は、[golem-layout ADR 0049](../golem-layout/adr/0049-align-the-character-classes-and-unbreakable-pairs-with-jlreq.md) の不変条件と同じく、項目の並びで隣り合う二つの箱（あいだに罰点とアキのグルーだけがある）の、前の箱の最後の字 a と後の箱の最初の字 b とする。
「数と単位の組」は、a が `isArabicDigit` で b の分類が `Kana` か `Ideograph` の組で、二つの箱がどちらも `lkCode` でも `lkUrl` でもないものとする。
P は `number-unit-penalty` の値とする。

- **W1 分けない**：P が 10000 なら、数と単位の組の位置には分割の候補がない。
- **W2 罰点**：P が 10000 より小さければ、数と単位の組の位置の分割の候補は、罰点 P、幅 0、`NoHyphen` の罰点の項目ちょうど一つである。その位置の空きのグルーは候補ではない。
- **W3 幅は変わらない**：数と単位の組の位置の箱とグルーの幅と伸び縮みは、この ADR の前と同じである。
- **W4 ほかの位置**：数と単位の組を含まない段落の項目は、この ADR の前と同じである。空白を挟む数と和字（`100 円`）の項目も同じである。
- **W5 改行しない範囲が勝つ**：数と単位の組の位置が改行しない範囲の中なら、P によらず候補がない（[ADR 0272](0272-discretionary-hyphens-hyphenation-exceptions-and-no-break.md) の I7 と I8 は、そのまま成り立つ）。
- **W6 はみ出しの報告**：はみ出したどの行にも、G07105 か G07122 のどちらか一つだけを出す（0272 の I9）。
- **W7 欄の検査**：`number-unit-penalty` の範囲外の値と整数でない値のそれぞれに、G03006 がちょうど一つ出る。範囲の中の値には diagnostic を出さない。
- **W8 HTML と EPUB**：`number-unit-penalty` をどう書いても、HTML と EPUB の出力のバイト列は、書かない入力と同じである。

[ADR 0209](../adr/0209-line-breaking-invariants-by-exhaustive-small-inputs.md) の L1 から L13 との関わりは次のとおりである。

- L4（分離禁止）は、P が 10000 の入力で、[golem-layout ADR 0049](../golem-layout/adr/0049-align-the-character-classes-and-unbreakable-pairs-with-jlreq.md) の B2 から B4 の組に、数と単位の組を足して読む。
- L7（最適）は、P が 10000 より小さい入力でも、罰点の項目が増えるだけなので、そのまま成り立つ。
- ほかの不変条件は、候補が減るか罰点が変わるだけなので、そのまま成り立つ。

[golem-layout ADR 0034](../golem-layout/adr/0034-line-breaks-between-japanese-characters-in-inline-code.md) の C1 から C8 と [golem-layout ADR 0045](../golem-layout/adr/0045-break-inline-code-after-hyphens-and-full-stops-to-avoid-loose-lines.md) の J1 から J7 は、コードの箱に当てないので、そのまま成り立つ。

境界の入力：

| 量 | 調べる値 |
| --- | --- |
| 数の字 | 半角（`1`）、全角（`１`）、漢数字（`一`。当てない）、語の終わりの数（`v1`） |
| 次の字 | 漢字（`円`）、平仮名（`つ`）、片仮名（`パ`）、句読点（`。`、禁則で今も分けない）、欧文（`km`、同じ語の箱） |
| あいだ | なし、語間の空白、`[aki]` |
| P | −9999、0、50、9999、10000、10001、`1.5` |
| 範囲 | 改行しない範囲の外、中、範囲の端に組がまたがる |
| 行の残りの幅 | 数の後でちょうど終わる、単位まで入る、単位が入らない |
| 組方向 | 横組み、縦組み |
| 文字スタイル | なし、`code`、`url` |

## テスト設計

テストを先に書き、今の実装で失敗することを確かめてから実装する。
テストの名前には、W1 から W8 の番号を入れる。

- **W1**：`あ100円` を `100` の後で行が終わる幅で組み、`100` と `円` のあいだで分けず、`円` まで前の行に追い込むか、`100円` を次の行に送ること。今は `100` の後で分けるので失敗する。字の送りと行の幅は実装の最初に決める。`１０冊`、`3つ`、`5パーセント` の数と次の字のあいだに候補がないことも確かめる。
- **W2**：`number-unit-penalty = 500` の本で、`100円` の `100` と `円` のあいだに、罰点 500 の幅 0 の罰点の項目がちょうど一つあり、その後のグルーの前の項目が箱でないこと。
- **W3**：W1 と W2 の入力の箱とグルーが、この ADR の前の実装の項目と同じであること。
- **W4**：[ADR 0209](../adr/0209-line-breaking-invariants-by-exhaustive-small-inputs.md) の 24 の部品の列挙の入力のすべてと、`100 円`、`三人` の項目が、この ADR の前と同じであること。
- **W5**：`[style no-break: 100円]` を `number-unit-penalty = 0` で組み、候補がないこと。
- **W6**：2 字の行に `１２３円` を組み、はみ出した行に G07105 だけが出ること。`[style no-break: １２３円]` では G07122 だけが出ること。
- **W7**：`number-unit-penalty = 10001`、`-10000`、`1.5`、`"10"` がそれぞれ G03006 を一つ出すこと。
- **W8**：W1 の本を `number-unit-penalty` の値を変えて組み、HTML と EPUB のバイト列が同じであること。
- **列挙**：24 の部品の列挙に `円` を足し（[golem-layout ADR 0049](../golem-layout/adr/0049-align-the-character-classes-and-unbreakable-pairs-with-jlreq.md) の `１` と合わせて数と単位の組を作る）、組み方の環境に P の 10000 と 50 を足して、L1 から L13 と W1 から W5 がすべての入力で成り立つことを確かめる。プルリクエストの段の時間が範囲ごとの予算 10 秒（[ADR 0208](0208-widen-lightweight-formal-methods.md) の 4）を超えるなら、P の 50 は毎晩のジョブの段だけで足す。

## トレードオフ

JLReq が分割してよいとする位置を、既定で分けない。
分割の候補が減るので、数の多い段落と狭い表のセルでは、行の調整の余地が減り、空いた行かはみ出す行が増えうる。
既定を 10000 にしたので、はみ出す行の原因に、この規則が加わる。

規則は数の後の一字だけを見る。
`100万円` は `100` と `万` のあいだだけを分けず、`万｜円` では分けうる。
助数詞と単位の一覧を持たないので、`3年｜間` は分けうるが、`3｜つ` と同じく `100｜を` のような助詞との組も分けない。
一覧を持てば当たる語を絞れるが、一覧の保守と、一覧にない助数詞の扱いが要る。

人名と熟語は自動では分けないので、分けたくない書き手が `no-break` を書く手間が残る。

## メンテナーが決めること

1. **規則の既定の強さ**：推奨は、`number-unit-penalty` の既定を 10000（分けない）にすることである。ロードマップの項目が数と単位を分けないことを求めており、既定のまま組んで分かれない組版を優先する。
   - 退けた案の一つは、既定を 10000 より小さい値（たとえば 5000）にすることである。分けるか崩すかを罰点の和で量れるが、どの入力で分けるかを書き手が予想しにくい。
   - もう一つは、既定を 0（今の振る舞い）にし、書き手が欄を書いたときだけ分けないことである。JLReq には合うが、既定の組版が変わらない。
2. **当てる字の組**：推奨は、アラビア数字と、その後の仮名か漢字等の一字の組にすることである。単位と助数詞の一覧を持たずに、`円`、`人`、`年`、`つ` を一つの規則で覆える。
   - 退けた案の一つは、単位と助数詞の一覧（`円`、`人`、`個`、`冊`…）を持つことである。一覧の保守が要り、一覧にない助数詞は分かれる。
   - もう一つは、数の前の語（`第`、`約`）との組も含めることである。`約｜100` を分けないと、`約` を含む熟語の後の数でも候補が消える。`第3章` のような形は正規表現スタイルで書ける。
3. **漢数字**：推奨は、当てないことである。漢数字は熟語の字にも使い（`一緒`、`統一`）、`一` の後の候補を消すと、数でない語の候補まで消える。
   - 退けた案は、漢数字にも当てることである。
4. **人名と熟語**：推奨は、自動の規則を持たず、書き手が `no-break` で書くことである。辞書の版で出力が変わることを避ける（決定性）。
   - 退けた案は、辞書を同梱して見分けることである。依存と辞書の版の管理が要り、辞書にない語は分かれる。
5. **はみ出す行のコード**：推奨は、G07105 を使い、新しいコードを足さないことである。行頭禁則、行末禁則、分離禁止で分けられない行と同じく、組版の規則が候補を消した行である。原因ごとにコードを分けるかは、ロードマップの「一つのコードに一つの原因の監査」で、禁則によるはみ出しと合わせて決める。
   - 退けた案は、この規則によるはみ出しに新しい警告（G07125）を足すことである。行の候補を消した規則が一つに決まらない行（数の並びと禁則が重なる行）で、どちらのコードを出すかの規則が要る。
6. **欄の置き場所**：推奨は、`kinsoku` と `explicit-hyphen-penalty` と同じく `[composition]` に置くことである。表のセル、注の本文、見出しにも同じ規則が当たる。
   - 退けた案は、段落スタイルの欄にすることである。段落スタイルを持たない組版（柱、目次）の扱いを別に決めることになる。

## 決めたことの記録

2026-11-10 に、tett23 がすべて推奨のとおりに決めた。

1. `number-unit-penalty` の既定は、推奨のとおり 10000（分けない）とする。
2. 当てる字の組は、推奨のとおりアラビア数字と、その後の仮名か漢字等の一字の組とする。
3. 漢数字には、推奨のとおり当てない。
4. 人名と熟語は、推奨のとおり自動の規則を持たず、書き手が `no-break` で書く。
5. はみ出す行は、推奨のとおり G07105 で報告し、新しいコードを足さない。
6. 欄は、推奨のとおり `[composition]` に置く。

この ADR は新しい diagnostic のコードを足さない。

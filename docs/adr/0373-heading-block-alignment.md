# ADR 0373: 行取りの中で見出しを前、中央、後ろに寄せる

ステータス: 採択

## 文脈

スタイルのうち、書き手が必要とする「見出しの行取りの中の位置」の扱いを決める。

## 調査した事項

ロードマップの「スタイル」は「見出しの行取りの中の位置」を v1.0.0 の対象に挙げている。

## 実装すること

headings の階層ごとに block-align を start、center、end から選ぶ。
余りを行送り方向で測り、先頭側の空きを順に 0、余りの半分、余り全体とする。
既定は center とし、余りが負なら空きを 0 とする。

前後は横組みでは上と下、縦組みでは行が進む向きの始まりと終わりを指す。

## 実装しないこと

既存の原稿を新しい指定へ自動変換する機能は設けない。

## 不変条件

1. 先頭側の空きと末尾側の空きの和は max(0, 行取りの寸法 − 見出しの寸法) に等しい。

| 境界の入力 | 期待する結果 |
| --- | --- |
| 余り0 | 全設定が一致 |
| 余り2行で end | 先頭側2行 |

## テスト設計

- `inv1_heading_block_alignment_property` で次の述語を検査する。先頭側の空きと末尾側の空きの和は max(0, 行取りの寸法 − 見出しの寸法) に等しい。
- `inv1_heading_block_alignment_case_1` は「余り 0」を入力とし、「全設定が一致」を確かめる。
- `inv1_heading_block_alignment_case_2` は「余り 2 行で end」を入力とし、「先頭側 2 行」を確かめる。

## トレードオフ

行取りを固定するので、寄せ方を変えても後続の本文には空きが戻らない。

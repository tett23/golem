# ADR 0355: 本文の分量を数え、指定した字数と行数でページ数に換算する

ステータス: 採択（未実装）

## 文脈

diagnostics とビルドの結果のうち、書き手が必要とする「原稿の分量を調べるコマンド」の扱いを決める。

## 調査した事項

[ロードマップ](../roadmap.md) の「箱の単位と書記素クラスタの食い違い」は、行分割の箱が ZWJ でつないだ絵文字と一致しない場合を挙げている。
そのため、文字数をレイアウトの箱の個数から求めると、家族の絵文字を一文字とする要件を満たせない。

## 実装すること

本文文字数は、各ページのマスターフレームに流し込んだ本文から求める。
ここでいうマスターフレームは、本文の流れを受け持つフレームである。
柱、ノンブル、独立して配置したテキストフレームは、マスターフレームと座標が重なっても集計に入らない。
マスターフレームをまたぐ段落は原稿順に一度だけ読み、表示文字列の拡張書記素クラスタを数える。
ワード数は Unicode の既定の単語境界で区切り、文字か数字を含む区間だけを数える。
PDF 用の行ボックスを数え、明示的な空行も含める。
換算ページ数は、書き手が指定する 1 行の文字数と 1 ページの行数から求める。
たとえば 400 字詰め原稿用紙は `golem stats --chars-per-line 20 --lines-per-page 20`、40 字×32 行の印刷ページは `golem stats --chars-per-line 40 --lines-per-page 32` と指定する。
両方とも正の整数を取り、省略した値はそれぞれ 20 とする。
結果には、換算に使った字数と行数を併記する。

ワード数、組版後の行数、換算ページ数も同じマスターフレームの本文を対象とする。
換算では段落の先頭と明示的な改行で新しい行を始め、各行の表示文字列を指定字数で折り返す。
組版の都合で生じた折り返しは引き継がず、明示的に空けた行は 1 行ずつ数える。
最後に換算した総行数を 1 ページの行数で割り、端数を切り上げる。
PDF は生成しない。

書記素と単語の境界には同じビルドに固定した Unicode の規則を使う。
段落をまたいで文字を結合せず、ルビは親文字だけを数える。
印刷用の柱、読み、版面に追加したハイフンは本文に含めない。

## 実装しないこと

原稿ファイル全体の文字数は集計しない。

## 不変条件

1. 段落ごとの拡張書記素数の和は、同じ表示文字列を複数の文字スタイルに分けても変わらない。
2. 1 行を C 字としたとき、明示的な行の寄与は、空行なら 1、本文が n 文字なら n/C の切り上げである。
3. 1 ページを L 行としたとき、換算ページ数は換算した総行数を L で割った切り上げに等しく、本文も空行もなければ 0 である。
4. 換算条件を変えても、文字数、ワード数、実際に組版した行数は変わらない。

5. マスターフレームの本文が同じなら、他のフレームの文字を増減しても本文文字数は変わらない。

| 入力 | 換算条件 | 期待する結果 |
| --- | --- | --- |
| マスターフレームに「本文」、重なる別フレームに「補足」 | 20字×20行 | 本文文字数2 |
| 独立したフレームにだけ本文がある | 40字×32行 | 本文文字数0、換算0ページ |
| 本文も空行もない | 40字×32行 | 0ページ |
| 家族の絵文字一つ | 1字×1行 | 1文字、0ワード、1ページ |
| 途中に明示改行のない41字 | 40字×1行 | 2ページ |
| 40字の段落が32個 | 40字×32行 | 1ページ |
| 同じ32段落の途中に明示的な空行を1行追加 | 40字×32行 | 2ページ |
| 40字の段落が32個 | 20字×20行（既定） | 64行分で4ページ |
| いずれかの寸法が0、負数、小数 | 指定エラー | 換算を実行しない |

## テスト設計

- `inv1_grapheme_count` は同じ段落を文字スタイルで分割し、書記素数が変わらないことを確かめる。
- `inv2_grid_lines` は空行、C 字、C+1 字、短い二段落の入力で、段落境界と折り返しを確かめる。
- `inv3_grid_pages` は表の空、ちょうど 1 ページ、1 行超過、既定の寸法を CLI から確かめる。不正な寸法は引数のエラーになることも確かめる。
- `inv4_independent_counts` は同じ原稿を二つの換算条件で集計し、換算ページ数だけが変わり、文字数、ワード数、組版後の行数が一致することを確かめる。

- `inv5_master_frame` は別フレームに「補足」を足しても本文文字数が 2 であり、同じ 2 字をマスターフレームに移すと 4 になることを確かめる。

## トレードオフ

換算ページ数は指定した字詰めと行数による見積もりであり、図版、見出しの行取り、改ページ位置によって実際の印刷ページ数とは差が生じる。
PDF を保存せずに済むが、行数を得るには組版に使う書体が必要になる。

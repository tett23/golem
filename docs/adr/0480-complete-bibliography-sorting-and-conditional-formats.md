# ADR 0480: 文献宣言の並べ替えと条件付きの書式を補う

Status: superseded-pending [{"part":"I7（既定出力の互換性）の注欠落修正の例外","by":["docs/adr/0482-fix-note-loss-as-a-default-output-compatibility-exception.md"],"kind":"supplement"}]

## 文脈

[root ADR 0470](0470-bibliography-styles-by-name-and-by-declaration.md) と [root ADR 0475](0475-complete-bibliography-declarations-and-citation-delimiters.md) の実装中に、同梱する文献スタイルを宣言だけでは表せない点と、省略した値の扱いが決まっていない点が見つかった。
名前を表示しない宣言の著者順、位置ラベルの前後と区切り、文献の種類による引用の違い、引用の著者順、欄が無い場合だけ組む片、英語の序数の六つである。
処理系に投稿先ごとの分岐を加えず、宣言でこれらを指定できるようにする。

## 調査した事項

main の `fd1936c2a43a2a392541d156c544ac70edb7e88b` の両 ADR と研究文書、および実装途中のコミット `865956deb` の宣言の読み取りと組版を調べた。
後者は、未マージの実装ブランチ `codex/impl-root-0470-renderer-nov27` のコードであり、main の振る舞いとは区別する。
実装を受け持つエージェントが `rg -n` と `nl -ba` で返した箇所は、次のとおりである。

- root [ADR 0475](0475-complete-bibliography-declarations-and-citation-delimiters.md) の必須項目の表では、名前を表示しなければ `names.author` を省け、`given-family` では `part-delimiter` を省ける。
  一方、root [ADR 0470](0470-bibliography-styles-by-name-and-by-declaration.md) の著者順のキーは、姓と名を `part-delimiter` でつなぐ。
  実装でも、`Golem/Project/BibliographyRequirements.hs` の 43 から 59 行と、`Golem/Assemble/BibliographySort.hs` の 59 から 65 行にこの違いがある。
- root [ADR 0470](0470-bibliography-styles-by-name-and-by-declaration.md) は `page = ["頁", "頁"]` と `page=5` の期待を `5頁` とするが、ラベルの位置と区切りを宣言するキーはない。
  `Golem/Doc/Citation.hs` の 103 行の実装は、ラベル、空白、値の順である。
- `types.<種類>` は一覧の `pieces` と `char-styles` だけを持つ。
  `Golem/Assemble/BibliographyStyle.hs` の 69 から 72 行と `Golem/Project/BibliographyRecords.hs` の 38 行にも、種類ごとの引用の書式はない。
  出版者の有無では、出版者を持つ書籍と論文を区別できない。
- 引用の順は `written` と `year` だけである。
  De Gruyter Mouton Journal Style Sheet v1.3 の 4 ページは、異なる著者をアルファベット順、同じ著者を年の順とする。
- `Golem/Assemble/BibliographyFormats.hs` の 33 から 50 行と 87 から 88 行は、必須の差し込みが欠けた片を省くが、別の欄があるときに片を省く条件を持たない。
  `pieces = ["https://doi.org/{DOI}", "{URL}"]` は、両方の欄があると両方を出す。
- [文献スタイルの調査](../research/bibliography-styles.md) の APA と Vancouver の書籍の例には、`2nd ed.` と `4th ed.` がある。
  `golem-numerals` と `Golem/Assemble/Formats.hs` の `ordinal` の検索結果は 0 件であり、数値 2 を `2nd` にする表記はない。

## 実装すること

### 著者順に必要な区切り

一覧の `sort` が `author` を含む宣言では、`names.author.part-delimiter` を必須にする。
後述の `citation-sort = "author-year"` でも、同じキーを必須にする。
名前を表示しない場合と、名前の表示が `given-family` の場合も省けない。
この条件だけのために、名前の `order`、`initials` や名前どうしの区切りまで要求しない。

`golem-sort-key` の前後の空白を除いた結果が空でない名前では、その値を使う既存の規則を保つ。
空か空白だけのキーは、キーの無い場合と同じに扱い、姓と名を明示した `part-delimiter` でつなぐ。
空でないキーの前後の空白は、実際の比較に渡す値から取り除かない。
区切りの空文字列は有効な指定であり、空白などへ読み替えない。
宣言の不足は、既存の G03006 で項目のパスを報告する。

必須条件は、基礎の宣言と言語別の宣言を検査するときに加え、実際に使う本の言語と文献の言語を合成した後にも検査する。
並べ方は本の言語、名前の区切りは文献の言語の宣言から選び、区切りを別の言語から借りない。
たとえば基礎が `written`、`ja` の上書きだけが `author-year` と区切りを持つ場合、日本語の本が英語の文献を引くと、英語の文献へ当てる区切りが無いので G03006 にする。
書誌データに明示したキーがあっても、宣言の必須項目を省く理由にはしない。

### 位置ラベルの前後と区切り

位置の種類をキーにする表 `locator-positions` と `locator-delimiters` をスタイルへ足す。
`locator-positions` の値は `before` と `after`、`locator-delimiters` の値は文字列である。
省いた種類の値は、それぞれ `before` と U+0020 一つにする。
値の前後の空白を取り除かず、空文字列もそのまま使う。

`before` は「ラベル、区切り、値」、`after` は「値、区切り、ラベル」の順で組む。
単数と複数のラベルの選択、値と範囲の表記は、既存の規則を使う。
たとえば、次の指定は `page=5` を `5頁` にする。

```toml
[bibliography.styles.example.locator-labels]
page = ["頁", "頁"]
[bibliography.styles.example.locator-positions]
page = "after"
[bibliography.styles.example.locator-delimiters]
page = ""
```

従来の `page = ["p.", "pp."]` だけなら `p. 5` になる。
root [ADR 0470](0470-bibliography-styles-by-name-and-by-declaration.md) の `5頁` の境界例には、上記の `after` と空文字列の指定を必要とする。
ラベルの文字や本の言語から、位置と区切りを推測しない。
二つの表は、文献の言語による上書きの対象にする。
未知の種類、位置の未知の値、区切りの文字列でない値は G03006 にする。
必要な位置ラベルが無い場合のエラーは保つ。

### 種類ごとの引用の書式

`types.<種類>` と `types.default` に、任意の `citation`、`citation-year`、`subsequent` を足す。
値は、スタイル全体の同名の項目と同じ、片の配列である。
まず文献の種類に一致する表を選び、無ければ `types.default` を選ぶ。
選んだ表にその引用の項目があれば使い、無ければスタイル全体の同名の書式を使う。
空配列は指定した値として保ち、全体の書式へ戻さない。

これにより、書籍には `『{title}』`、論文には `「{title}」` を使える。
値の有無から種類を推測しない。
モード、注のチャネル、引用全体の囲みと順序は、引き続き本の言語から選ぶ。
種類の表と書式は、文献の言語から選ぶ。
年だけの引用と二度目以降の注の選択も、既存の規則のままである。

宣言した種類の表の `pieces` の必須条件は変えない。
一覧の無い本で、引用のためだけに種類の表を宣言する場合は、使わない一覧の `pieces = []` を明示できる。
スタイル全体の `citation` と、`author-year` の `citation-year` の必須条件も保つ。
種類ごとの引用の書式も、未使用のものを含めて構文と必要な名前の表を検査する。

### 引用の著者順

`citation-sort` に `author-year` を足す。
一つの引用の印にある文献を、第一著者の並べ替えのキー、年の順に比べ、同順位は書いた順を保つ。
著者のキーの比較は、root [ADR 0470](0470-bibliography-styles-by-name-and-by-declaration.md) の一覧の `author` と同じにする。
年が欠けた文献と文字列の日付を持つ文献は年不明とし、著者のキーが同じなら、数値の年を持つ文献より前に置く。
著者のキーが同じ年不明の文献どうしは、書いた順を保つ。
これは、実装途中の `citation-sort = "year"` が使う年の比較と同じ順である。
位置、前置き、後置きは、並べ替えた文献と一緒に移す。

言語別の選択は、既存の `citation-sort` と同じく本の言語を使う。
G03306 の発火条件は増やさず、一覧の著者順に関する既存の警告を保つ。
漢字やかなの読みは推し量らず、必要なら `golem-sort-key` を書く。

### 欄が無い場合だけ組む片

片の文字列に、値を出力しない不在条件 `{!欄}` を足す。
その欄に利用可能な値があれば片全体を省き、無ければ、その条件自体は文字を出さずに残りを組む。
利用可能な値の判定は、同じ欄の通常の差し込みが欠落しているかを調べる既存の判定と同じにする。
一つの片に複数の不在条件があれば、すべての欄が欠落した場合だけ組む。

```toml
pieces = ["https://doi.org/{DOI}", "{!DOI}{URL}"]
```

この例は、DOI があれば DOI だけを、DOI が無く URL があれば URL だけを出す。
両方が無ければ、どちらの片も出さない。
`{!DOI}{!URL}.` は、両方が無い場合だけピリオドを出す。
不在条件にも、通常の差し込みと同じ欄の名前の検査と、必要な名前の表の検査を当てる。
不在条件に `?` や数の表記を重ねる書き方は認めず、書式の構文の誤りは既存の G03304 にする。
通常の必須の差し込み、任意の差し込み、文字どおりの波括弧の既存の書き方は保つ。
条件式や、出力後の句読点の自動修正は加えない。

### 英語の序数

文献の数の差し込みに、明示する表記 `ordinal-en` を足す。
`{edition:ordinal-en}` と書いた場合、欄の文字列全体を符号付きの十進整数として読み、正整数になった値に英語の序数の接尾辞を付ける。
末尾二桁が 11、12、13 なら `th`、それ以外は末尾一桁の 1、2、3 に `st`、`nd`、`rd`、残りに `th` を付ける。
算用数字は先頭の 0 を付けない整数の表記にする。
固定幅の整数への切り詰めや、浮動小数点への変換はしない。

0 と負数は、この表記で表せない数として、既存の G03006 でエラーにする。
整数として読めない非整数や `2nd` などは、root [ADR 0470](0470-bibliography-styles-by-name-and-by-declaration.md) I8 のとおり、元の欄の文字列を保つ。
ほかの表記や、表記を書いていない `edition` を、暗黙に序数へ変えない。
`number-text` の `style` に新しい値を足す変更ではない。

### 文書と採択の記録

仕様書、README、利用者マニュアル、開発者マニュアルと同梱の宣言を、六つの規則に合わせて更新する。
root [ADR 0470](0470-bibliography-styles-by-name-and-by-declaration.md) のステータスには、「位置ラベルの前後と区切り」の置換と、ほかの五つの規則の補足を記録する。
root [ADR 0475](0475-complete-bibliography-declarations-and-citation-delimiters.md) のステータスには、「著者順での part-delimiter の必須条件」の補足を記録する。
各 ADR の実装済みか未実装かの区別は保つ。

## 実装しないこと

CSL の XML スタイルの取り込み、投稿先を名前で判定する処理系内の分岐、漢字の読みの推定は行わない。
任意の条件式、句読点の自動修正、英語以外の序数の新設は行わない。
既定の `golem` スタイルの出力と、メンテナーが三つの見本の論文を見る root [ADR 0470](0470-bibliography-styles-by-name-and-by-declaration.md) A1 は変更しない。

## 不変条件

- I1: 著者のキーを使う宣言は `part-delimiter` を明示し、名前の表示の有無によらず同じ規則でキーを作る。
- I2: 位置ラベルは明示した前後と区切りだけで組み、ラベルの文字や言語から位置を推測しない。
- I3: 引用の種類ごとの書式は、種類、言語、明示した項目の有無で選び、文献の欄の偶然の有無には依存しない。
- I4: `author-year` の引用は、著者のキー、年、書いた順で決定的に並び、各文献の位置と前後の文字列を保つ。
- I5: 不在条件を持つ片は、不在条件が参照するすべての欄が欠落し、通常の必須の差し込みも満たす場合だけ、不在条件自体の文字を出さずに組む。
- I6: `ordinal-en` は正整数だけを定めた接尾辞で組み、0 と負数をエラーにし、整数として読めない値と明示していない欄を変えない。
- I7: 既存の宣言のうち、新しい必須条件に関係しないものと、既定の `golem` の出力は変わらない。

## 受けいれ条件

- A1: 通常の CLI で、六つの規則を使う宣言を名前で選んだ本と、その宣言を写して別名にした本を、PDF、HTML、EPUB、テキストへ出し、対応する内容が一致する。
- A2: 同梱のスタイルの、DOI と URL、書籍と論文、複数引用、数値の版の境界例を、文献スタイルの研究の出典と照合する。

## テスト設計

実装前に I1 から I7 の回帰テストを追加し、少なくとも不足していた位置ラベル、種類別引用、著者順、不在条件、英語序数が失敗することを確認する。
著者のキーは、`golem-sort-key` の有無、名前の表示の有無、空の姓や名、区切りの空文字列と空白を組み合わせる。
本の言語だけが著者順を要求する場合も、文献の言語の名前の表との合成後に不足を検出することを確かめる。
位置ラベルは、26 種類、単数と複数、前後と空の区切り、言語の段階的な上書きを比較する。
種類の引用は、三つの書式、全体への委譲、空配列、未知の種類と `default`、複数言語を比較する。
不在条件は、二つの欄の有無を総当たりにし、通常の必須と任意の差し込みとの組み合わせ、波括弧の文字どおりの出力、不正な構文を確かめる。
英語序数は、表の境界と大きな正整数、数字の文字列、整形済みの文字列、0、負数、非整数を試験する。
A1 では、全媒体の文字列、リンク、並び順を比較し、PDF を描画して確認する。
root [ADR 0470](0470-bibliography-styles-by-name-and-by-declaration.md) の同梱スタイル、三つの論文、CI、メンテナーの目視の条件は、別に全範囲を満たすまで未実装として残す。

## トレードオフ

ソートに区切りの明示を要求するため、名前の表示が無い一部の宣言にもキーを足す必要がある。
位置ラベルと種類別引用の指定も増えるが、文字や欠けた欄から書式を推測しなくて済む。
不在条件は文字列の片の型を保つ小さな構文の追加であり、任意の条件式を持つ言語にはしない。
英語序数を明示する表記にすることで、整形済みの文字列と数値の版の両方を扱える。

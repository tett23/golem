# ADR 0403: 単色図版の色指定に白黒の濃淡を含める

Status: superseded-pending [{"part":"JPEG の色変換で復号する方式と非対応時の扱い","by":["docs/adr/0406-limit-jpeg-figure-color-decoding.md"],"kind":"supplement"},{"part":"SVG の色を判定または置換できない場合","by":["docs/adr/0407-reject-svg-figures-that-cannot-be-recolored.md"],"kind":"supplement"}]

## 文脈

[root ADR 0386](0386-page-list-and-page-colors.md) は、単色図版の描画色を独立に指定し、多色画像の画素を保存すると決めた。
白い背景に黒い線を描いた図や、灰色の写真を単色と呼ぶかを補足する。

## 調査した事項

指示者は 2026-11-22 に、白黒の濃淡を単色図版に含めると決めた。
白を白のまま、黒を指定した色、灰色をその中間の濃さにし、色付き写真を保持するという案を選択した。

## 実装すること

図版の描画色を指定したとき、既存の一色の図形に加え、白黒の濃淡だけを持つ図版もその色で描く。
白い背景と黒い線の線画、灰色の写真を含める。
色を指定しない場合の出力は変えない。

白は白のまま、黒は指定したスウォッチの色とする。
灰色はその明るさに応じて白と指定色の間へ写す。
正規化した灰色の値を g（黒が 0、白が 1）とすると、出力 CMYK の各成分はスウォッチの各成分の `1 - g` 倍とする。
HTML と EPUB は、その CMYK の近似色を使う。
透明部分と各位置の不透明度、図版の寸法、配置は変えない。

この規則は SVG、PNG、JPEG、取り込んだ PDF の図版に適用する。
ラスター画像はグレースケールの画素、または各画素の R、G、B が等しい画像を白黒の濃淡として扱う。
グレースケールの PNG や JPEG に限らず、RGB で保存した白黒の図版も対象とする。
白黒の濃淡ではなく、透明部分を除いて一つの色だけを持つ画像は、その色を指定色に置き換える。
白黒の濃淡の規則を優先するので、白だけの画像は白のままにする。
それ以外の色付き写真には、この色の置き換えをしない。
多色画像の元の色を保つという root [ADR 0386](0386-page-list-and-page-colors.md) の規則を維持する。

## 実装しないこと

色付き写真を灰色へ変換したり、近い RGB の値を同じ灰色と判定したりしない。

## 不変条件

I1: 白黒の濃淡の白と黒は、それぞれ白と指定スウォッチの色に写る。
I2: 色の置き換えは各画素の不透明度、図版の寸法と配置を変えない。
I3: 濃淡ではない多色画像の画素は変更前と一致する。

| 入力 | 期待 | 不変条件 |
| --- | --- | --- |
| 白と黒の線画 | 白を保持し、黒を指定色にする | I1 |
| 灰色の写真 | 明るさに応じた指定色の濃淡 | I1 |
| 半透明の灰色 | 色を変え、不透明度を保つ | I1, I2 |
| RGB の白黒画像 | グレースケール形式と同じ変換 | I1 |
| 色付き写真 | 元の画素を保持 | I3 |

## 受けいれ条件

A1: 通常 CLI の PDF、HTML、EPUB 出力で、線画と灰色写真が指定色の濃淡になる。

## テスト設計

root ADR 0403 I1、I2、I3 を名前の先頭に置いた試験で、白、黒、中間の灰色、透明、半透明、多色を検査する。
SVG、PNG、JPEG、取り込んだ PDF と、RGB で保存した白黒画像を含める。
root ADR 0403 A1 は、実際の生成物の色、透明度と配置を照合する。

## トレードオフ

白黒の線画や写真も一色刷りのように扱えるが、単純な色数の比較だけでは単色を判定できない。
圧縮したラスター画像では、画素を調べるための復号も必要になる。

# ADR 0374: 段落ごとの上書きと先頭文字の組み方を定める

ステータス: 採択（未実装）

## 文脈

スタイルのうち、書き手が必要とする「段落スタイルの拡張」の扱いを決める。

## 調査した事項

ロードマップの「スタイル」は「段落スタイルの拡張」を v1.0.0 の対象に挙げている。

## 実装すること

見出しとリストを含む段落に行送り、次の段落の既定スタイル、先頭の書記素に使う文字スタイルを指定する。
明示した段落スタイルを次スタイルより優先し、@style の名前付き引数を最後に重ねる。
ドロップキャップは先頭 1 書記素を指定行数の高さで置き、その行だけ本文幅を減らす。
字取りは指定字数の幅に字間を均等配分する。
始め括弧の字下げは通常の字下げから半角分を引く方式を選択でき、下限は 0 とする。

段落スタイルに line-height（正の寸法）、next-style、initial-style、drop-lines（0 より大きい自然数）、fit-characters（0 より大きい自然数）、opening-indent（normal または half）を設ける。
例は `@style body line-height="16pt"` とする。
drop-lines と fit-characters の併用、未知のスタイル名、型や範囲の誤りは設定位置で拒む。
次スタイルは直後の一段落にだけ適用し、参照だけでは段落を生成しない。

## 実装しないこと

既存の原稿を新しい指定へ自動変換する機能は設けない。

## 不変条件

1. 同じ欄の実効値は、段落ごとの指定、段落スタイル、継承値の順で最初に定義された値に等しい。

2. drop-lines と fit-characters は、値が自然数かつ 0 より大きい場合だけ受理する。

| 境界の入力 | 期待する結果 |
| --- | --- |
| drop-lines または fit-characters が0 | 設定位置でエラー |
| 同じ欄が1 | 最小値として受理 |
| 空段落 | 先頭文字の装飾0 |
| 字取り1文字 | 領域中央 |
| 明示指定と次スタイルが競合 | 明示指定 |

## テスト設計

- `inv1_paragraph_style_controls_property` で次の述語を検査する。同じ欄の実効値は、段落ごとの指定、段落スタイル、継承値の順で最初に定義された値に等しい。
- `inv1_paragraph_style_controls_case_1` は「空段落」を入力とし、「先頭文字の装飾 0」を確かめる。
- `inv1_paragraph_style_controls_case_2` は「字取り 1 文字」を入力とし、「領域中央」を確かめる。
- `inv1_paragraph_style_controls_case_3` は「明示指定と次スタイルが競合」を入力とし、「明示指定」を確かめる。

- `inv2_positive_natural` は両方の欄で 0 と 1 の境界を検査する。

## トレードオフ

段落単位の上書きを許すと、スタイル定義だけでは個々の段落の見た目が決まらない。

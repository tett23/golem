# ADR 0320: 組版に使う寸法、アキ量、行数を名前で参照する

ステータス: 採択→[ADR 0346](0346-revise-named-layout-values.md)

## 文脈

二つの段落スタイルが同じ字下げを使っていても、継承関係にないスタイルではそれぞれの欄に値を書く。
スタイルの `based-on` はスタイル全体の既定値を継承するが、字下げだけを索引の段間や別の字下げと共有する目的には使えない。
ここで名前を付ける対象は、組版の欄に入れる個々の値である。

## 実装すること

`style.toml` に次の三つの表を設ける。
キーは英小文字で始まり、後は英小文字、数字、ハイフンを許す。
同じ名前を別の種類に再登録した場合も重複とする。

```toml
[values.length]
indent = "1zw"
rule-gap = "3mm"

[values.aki]
half = "二分"

[values.count]
lines = 2

[paragraph-styles.quote]
indent = "indent"
```

長さは既存の長さのリテラル、アキ量はアキ量のリテラル、行数は 0 から 2147483647 までの整数とする。
宣言の右辺と値の使用箇所は同じ式の構文を使う。
整数、単位付き寸法、アキ量、識別子を式の項として読み、宣言の表または使用する欄から期待する型を得て各項を解決する。
欄に渡すときは接頭辞を付けずに名前を書く。
整数の 0 は期待型に従って絶対長のゼロ、ベタ、行数のゼロになる。
識別子なら対応する宣言の型を照合して右辺を評価する。
TOML の文字列に式を書く。
整数のリテラルは TOML の整数も受け付ける。
ファイルの宣言をすべて読んでから名前を引くので、宣言の順は問わない。
宣言の評価中に同じ宣言を再び訪れた場合は G03256 とし、循環に含まれる名前を表示する。

`style.toml` と原稿の `@style-def` で、もともと長さ、アキ量、行数を取る欄が参照を受け付ける。
欄の種類に合う値だけを渡し、各欄に課される正の値などの条件は参照先の値にも適用する。
`zw` は宣言時に絶対長へ変換せず、同じ欄にリテラルを直接書いた場合と同じ文字の大きさで解決する。
文字サイズ自体など基準が決まっていない欄では、その欄がすでに認める単位だけを受け付ける。
絶対長しか取れない欄に `zw` を渡すときは直接書いたときと同じエラーを参照位置に出す。

名前の重複は G03254、名前の字面の誤りは G03255、宣言値の誤りは G03256 とする。
参照先がない場合は G03257、種類が違う場合は G03258 を参照位置に出す。
メッセージに名前を示し、種類が違うときは要求された種類と実際の種類も示す。
`1zw` や `二分` のような組み込みのリテラルは今の意味を保つ。
長さのリテラルに数が必要な欄で `zw` とだけ書けば、宣言名として引く。

LSP の補完は値の入力位置で、その欄の種類に合う宣言を提示する。
名前の変更は宣言と、その宣言を指すスタイルおよび読み込み対象の原稿の参照を一つの編集に含める。
コメント、本文、同じ綴りの段落スタイル名を編集しない。
変更先がすでに宣言されていれば編集を返さない。

行数の加算には既存の数の加算と同じ規則を使い、結果にも行数の上限を適用する。

## 実装しないこと

プリフライト規則は組版用のスタイルに依存しないので、`preflight.toml` からこの宣言を読まない。
`[vars]` は原稿の値に使い、この表の検索対象に加えない。
段落スタイルと文字スタイルについては、既存の名前と `based-on` を使う。
長さやアキ量の演算子、原稿内での組版用の値の宣言、別ファイルによる上書きは対象外とする。
原稿の式で使える関数や `doc` の値をスタイルの評価環境には持ち込まない。

## 不変条件

1. 同じ型の名前をリテラルへ展開した結果は、値を使う欄と文字の大きさが同じなら、直接そのリテラルを書いた結果と一致する。
2. 補完は受け入れる種類の名前だけを返し、名前の変更はその宣言に結び付いた参照だけを更新する。
3. 一つの名前に登録できる式は一つであり、無効な宣言を参照可能な状態にしない。
4. `style.toml` と `@style-def` には同じ宣言が見え、`preflight.toml` からは見えない。

| 入力 | 結果 |
| --- | --- |
| 宣言なし、参照なし | 現行と同じ |
| 未定義の `indent`、行数の欄に長さの `indent` | G03257、G03258 |
| 文字サイズが 10 pt と 12 pt の箇所で `1zw` を参照 | それぞれ 10 pt、12 pt |
| `[values.length]` の名 `zw` を `zw` で読む | 宣言した長さを得る |
| 二つの表で同名、宣言間の循環 | G03254、G03256 |
| 行数の宣言 `more = "rows + 1"`、後の宣言で `rows = 2` | `more` は 3 |
| 長さの名前を既存の名前に変更 | 編集を返さない |
| `preflight.toml` の長さに `"indent"` | 現行の規則の値のエラー |

## テスト設計

[裸の名前の試験](../../experiments/syntax/review/review.test.mjs) で型が一致する場合、別の型、未宣言、旧草案のドル記号付き入力、リテラルを区別する。
式を同じ項として読んだ後に試した前方参照、行数の加算、循環の [試験結果](../../experiments/syntax/review/green.log) も記録した。
以下の初回の試作は接頭辞があった時点の記録である。

`node --test experiments/syntax/test.mjs` で、[試作の宣言、参照、補完、名前変更](../../experiments/syntax/proposal.mjs) の I1 から I4 を実行する。
`node experiments/syntax/cli.mjs /path/to/golem` は 10 pt と 12 pt に展開した字下げをコミット `0a8d21a0` の CLI に渡す。
[照合結果](../../experiments/syntax/cli.log) ではどちらも終了コード 0 だった。
Haskell の [宣言の読み込み](../../experiments/syntax/names/Names.hs) は実際に TOML を読み、長さとアキ量を既存の関数でパースする。
`sh experiments/syntax/names.sh` は変更前に 9 件中 8 件が失敗し、[変更後の 9 件](../../experiments/syntax/names-green.log) はすべて成功した。
LSP の編集対象は参照のリストで検査した。
実際の TOML の位置、複数の開いたファイルに対する LSP の編集、PDF の配置の比較は本実装で検査する。

## トレードオフ

型ごとに宣言を分けると、`0` を長さと行数のどちらと読むかを宣言だけで決められる。
一方、同じ名前を三つの表に置けないので、同じ綴りを使いたい場合には別名が必要になる。
プリフライトの絶対長は共有できないが、プリフライト規則の誤りは従来どおりスタイルを読む前に報告できる。

# ADR 0381: 縦組みの漢数字の注番号を平字で組む

ステータス: 採択（未実装）

## 文脈

本の部品の拡張のうち、書き手が必要とする「平字の注の印」の扱いを決める。

## 調査した事項

ロードマップの「本の部品の拡張」は「平字の注の印」を v1.0.0 の対象に挙げている。

## 実装すること

平字を選んだ縦組みの漢数字の印では各字の行方向の字形と送りをともに半分にする。
直交方向の寸法を保ち、番号の前後の装飾文字には縮小を適用しない。

チャネルに mark-shape = "flat" を指定する。
本文側と注本文側で漢数字を組む箇所に同じ変換を適用し、アラビア数字には適用しない。

## 実装しないこと

既存の原稿を新しい指定へ自動変換する機能は設けない。

## 不変条件

1. 平字の各漢数字の行方向の送りは同じ指定で通常の漢数字を組んだ送りの半分に等しい。

| 境界の入力 | 期待する結果 |
| --- | --- |
| 漢数字1字 | 半字送り |
| 漢数字2字 | 全角1字分 |
| 横組み | 通常の印 |

## テスト設計

- `inv1_compressed_note_marks_property` で次の述語を検査する。平字の各漢数字の行方向の送りは同じ指定で通常の漢数字を組んだ送りの半分に等しい。
- `inv1_compressed_note_marks_case_1` は「漢数字 1 字」を入力とし、「半字送り」を確かめる。
- `inv1_compressed_note_marks_case_2` は「漢数字 2 字」を入力とし、「全角 1 字分」を確かめる。
- `inv1_compressed_note_marks_case_3` は「横組み」を入力とし、「通常の印」を確かめる。

## トレードオフ

印を短くできる一方で、漢数字の縦方向の字形も縮む。

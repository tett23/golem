# ADR 0400: 綴じない資料の左右を固定するページモード

Status: accepted

## 文脈

綴じない配布資料では、全ページで左の余白を広く取り、ページ番号を右下に置く、といった指定が要る。
現在の PDF は一枚ずつのページとして出力するが、版面と柱の配置は綴じる本を前提とし、ノドと小口が奇数ページと偶数ページで入れ替わる。
左右の余白を等しくすれば本文の位置は揃うものの、左右の余白を異なる値にした資料には使えない。

ここでは、ページの偶奇で配置を反転しない **左右固定モード** を追加する。
左右は、仕上がりのページを正立させたときの物理的な左と右を指し、縦組みでも変わらない。
このモードは印刷機の片面印刷設定や、PDF ビューアーの表示方法を指定するものではない。

## 実装すること

### モードと版面の位置

`style.toml` の `[page]` に `layout = "single" | "facing"` を追加する。
`single` は左右固定モード、`facing` は既存の見開きを前提とするモードであり、省略時は `facing` とする。
文書の途中でモードを切り替えることはできない。

左右固定モードでは `binding` を書かず、`[page.grid].position` に `top` と、`left` または `right` のちょうど一方を書く。
`left` は仕上がりの左端から版面の左端まで、`right` は仕上がりの右端から版面の右端までの距離である。
版面の幅と高さは、従来どおり字数、行数、文字の大きさ、行送り、段数、段間から求める。
反対側の余白は残りとして求めるので、左右の余白と版面の幅を重複して指定しない。

```toml
[page]
size = "A4"
layout = "single"
writing-mode = "horizontal"

[page.grid]
font-size = "10pt"
characters = 40
lines = 40
line-pitch = "16pt"
position = { top = "20mm", left = "25mm" }

[masters.default]
running-head = { position = "top-center", content = "title" }
folio = { position = "bottom-center", format = "{n}" }
```

この例は設定の抜粋であり、フォントとプロジェクトの設定は別に要る。
`right = "25mm"` を使えば、右の余白を基準に版面を置ける。
寸法は既存の `top` と `gutter` と同じ単位と丸め方で扱い、負の余白と仕上がりからのはみ出しは G07001 とする。
ちょうど仕上がりに収まる版面は許す。

`facing` では、`binding` と `top`、`gutter` の既存の意味と省略時の動作を保つ。
`single` に `binding` や `gutter` を書くこと、`facing` に版面の `left` や `right` を書くことは G03006 とする。
`single` で `left` と `right` を両方書いた場合、またはどちらも書かなかった場合も G03006 とする。
`[page.grid]` 自体を省ける場面は従来どおりであり、位置の必須検査はそのテーブルがある場合に行う。

### 柱、ノンブル、傍注

柱とノンブルの `position` に `top-left`、`top-right`、`bottom-left`、`bottom-right` を追加し、両モードで使えるようにする。
左指定は版面の左端に左揃え、右指定は版面の右端に右揃えで置く。
上下の位置は既存と同じく天または地の余白の中央とし、`top-center` と `bottom-center` も引き続き使える。
`top-center` と `bottom-center` は柱とノンブルのどちらにも使え、版面の左右の中央に中央揃えで置く。
左右の余白が非対称でも、中央の基準は用紙の中央ではなく版面の中央とする。
複数行の柱にも同じ揃えを適用する。

左右固定モードでは、柱とノンブルの `inside` と `outside` を含む位置を G03018 とする。
柱の内容の `odd` と `even` はページの通し番号の偶奇による内容指定として残す。
内容を切り替えても、同じマスターページのアンカーは動かない。
章ごとのマスターページの切り替えと、白ページや章頭で柱を抑える既存の規則は変えない。

傍注の `side` に `left` と `right` を追加し、両モードで物理的な側として扱う。
左右固定モードで `[sidenotes]` を使う場合は、このどちらかを明記する。
`outside` と `side` の省略は、左右固定モードでは G03006 とする。
見開きモードの省略値は従来どおり `outside` である。
幅、版面との間隔、はみ出しの検査、および縦組みと段組みでの傍注の禁止は変えない。

左右固定モードでは、段落の `towards-spine` と `away-from-spine` を G03006 とし、`left`、`right`、`center` など既存の揃えを使う。
書字方向によらず G03006 を出し、同じ指定に既存の縦組みの G03118 を重ねない。
見開きモードの縦組みでは従来どおり G03118 とする。
ノドを仮の左右に読み替えることはしない。
これらのモードとの組み合わせの検査は、継承を解決した後のすべての段落スタイルとマスターページに対して行い、未使用の定義も対象とする。
原稿内の `@style-def` による定義も同じモードの検査対象とする。
スタイルの継承で禁止値を受け継いだ場合は、禁止値を明示した継承元の定義の diagnostic を出し、その値を受け継ぐ子の数によって diagnostic を増やさない。
`style.toml` のエラーは禁止値を明示した位置に出し、必須キーの不足は親テーブルの位置に出す。
原稿内の定義に明示した禁止値は、既存どおりその `@style-def` の位置に出す。

### 改ページとページ番号

左右固定モードでも、明示した `recto` と `verso` は既存どおり通し番号が奇数または偶数のページから始める指定とする。
原稿の `@page-break` と段落や見出しの `page-break` のいずれにも適用し、必要なら白ページを入れる。
利用者が左右固定モードへ移行するとき、偶奇を揃える意図のない見出しは `page-break = "page"` に変更する。

一方、左右固定モードの `page-numbering.start` では、開始番号の偶奇に合わせる白ページを入れない。
セクションは、今のページが空ならそこで、内容があれば次のページで始める。
開始番号はラベルの値として適用し、ページの通し番号とは切り離す。
後続の明示的な `recto` と `verso` は引き続き通し番号を見る。
見開きモードでは、開始番号と通し番号の偶奇を揃える既存の規則を保つ。

### 印刷用の要素と出力

左右固定モードでは、隠しノンブルの既定値を無効にする。
`[hidden-folio].enabled = true` は、トンボの有無によらず G03006 とする。
`false` は許し、そのほかの値の型と範囲は既存どおり検査する。
通常のノンブル、トンボ、塗り足しは引き続き使える。

プリフライトでは、左右固定モードの横方向の端を「左」「右」と表示する。
天と地の名称、距離、しきい値、重大度は変えず、検査順は天、地、左、右とする。
図版の配置など、版面と仕上がりの距離から位置を選ぶ処理には固定した版面を渡す。
ページの偶奇だけを理由とする横方向の反転を左右固定モードには残さない。

PDF は従来どおり一ページずつ出力する。
PDF ビューアーに単ページ表示を強制する設定、面付け、印刷機の両面印刷設定は追加しない。
HTML と EPUB のレイアウトにはこのモードを反映しないが、共通のスタイルの読み込みでは上記の設定検査を行う。

### 実在する文章を使う fixture

`modules/golem-driver/test/fixtures/single-page/` に、左右固定モードの PDF を作る独立した fixture を追加する。
本文には既存の『蟹工船』（小林多喜二）の fixture から、冒頭の連続した段落を抜粋する。
青空文庫由来の本文とルビを保ち、架空の文章、同じ段落の反復、ページ数を増やすための白ページは使わない。

横組みの A4、一段組み、左右非対称の余白とし、柱は `top-center`、ノンブルは `bottom-center` に置く。
本文の量と版面を実際に組んで調整し、出力を 10 ページを目安とする 9〜11 ページに収める。
抜粋の終わりは段落の境界とし、調整後は抜粋範囲と設定を固定する。
実装前にページ数を確認済みとは扱わない。

fixture には原稿、マニフェスト、スタイル、出典と再生成手順を記した README を置く。
README には著者、作品名、青空文庫の図書カード No.1465、既存の取得スクリプトが使う配布 URL と SHA-256、抜粋元のコミット、最初と最後の段落を特定できる情報を記録する。
フォントは既存 fixture の Noto Serif JP とその配布手順を使い、通常のテスト実行時に本文をネットワークから取得しない。

この fixture を PDF の統合テストと目視確認に使い、総ページ数、白ページがないこと、奇数ページと偶数ページでの版面の一致を検査する。
柱とノンブルのアンカーが版面の中央にあることも検査する。
柱を `bottom-center`、ノンブルを `top-center` に入れ替えた組み合わせは、別の小さな自動テストで確かめる。

### データ構造と実装の分担

ページモードと綴じ方向を一つの代数的データ型で表し、左右固定モードに架空の綴じ方向を持たせない。
版面の位置も、ノド基準、左基準、右基準を区別する型にする。
読み込み時にモードと位置の組み合わせを検査し、座標計算では検査済みの値を使う。

左右固定モードの版面の座標は、ページ幅を `W`、ページ高を `H`、版面幅を `w`、版面高を `h`、天の余白を `t` とすると、左指定 `l` では `(l, H - t - h)`、右指定 `r` では `(W - r - w, H - t - h)` とする。
既存の奇数用と偶数用の幾何を保持する実装では、双方に同じ座標を格納する。
段の読む順序は書字方向に従う既存の規則を保つ。

`golem-project` はキー、型、設定検査、LSP に渡すスキーマを更新する。
`golem-layout-spec` と `golem-typeset` は版面、柱、傍注、隠しノンブル、およびセクション開始を更新する。
`golem-preflight` のページ情報ではノドの側が存在しない状態を表し、diagnostic の端の名前に反映する。
`golem-lsp` の補完に新しいキーと値を加え、実装時に仕様書、README、マニュアル、diagnostics の一覧を同時に更新する。

## 実装しないこと

- ページごとのモード、判型、版面の変更。
- 余白の指定から字数と行数を自動的に求める機能。
- 原稿やスタイルの自動移行、綴じない資料の専用テンプレート。
- 明示した `recto` と `verso` を通常の改ページへ読み替えること。

## 不変条件

- `I1`: `layout` を省いた既存の有効な入力の組版結果は、変更前と等しい。
- `I2`: 左右固定モードで同じ版面設定、段組み設定、縦方向の対象領域、マスターを使い、正の通し番号だけを変えて計算した版面、段、傍注の矩形と柱およびノンブルのアンカーは等しい。
- `I3`: 左右固定モードで左指定なら版面の左余白が指定値に等しく、右指定なら右余白が指定値に等しい。
- `I4`: 左右固定モードで禁止した設定の組み合わせは、本文の有無やその定義の使用の有無によらず、指定したコードのエラーになる。
- `I5`: 左右固定モードのセクション開始位置は、`page-numbering.start` の値の偶奇に依存しない。
- `I6`: 両モードの明示した `recto` と `verso` は、既存と同じ通し番号の偶奇を満たす。
- `I7`: 左右固定モードでは、トンボと通常のノンブルの有無によらず隠しノンブルを描かない。
- `I8`: 左右固定モードのプリフライトの横方向の距離と端の名前は、同じ矩形ならページの偶奇によらず等しい。

| 入力 | 期待 | 不変条件 |
| --- | --- | --- |
| 既存の設定で `layout` を省略 | 既存の結果と一致 | I1 |
| 空原稿と禁止した設定 | 本文を組む前に設定エラー | I4 |
| 一ページと二ページ、左右非対称の余白 | 二ページ目も同じ版面 | I2, I3 |
| `left` と `right` の両方、または両方なし | G03006 | I4 |
| 版面が仕上がりにちょうど収まる | 幾何の計算に成功 | I3 |
| 版面が仕上がりを 1 sp 超える | G07001 | I3 |
| 空ページと内容のあるページで、開始番号 1 と 2 | 同じ位置でセクションを開始 | I5 |
| 次の通し番号が奇数と偶数で `recto`、`verso` | 必要なときだけ白ページ | I6 |
| トンボあり、通常のノンブルなし | 隠しノンブルなし | I7 |
| 同じ左端の安全域違反を一ページ目と二ページ目に配置 | 両方とも「左」と同じ距離 | I8 |

## 受けいれ条件

- `A1`: 横組みと縦組みの左右非対称の資料を三ページ以上出力し、本文と右下のノンブルが全ページで同じ側に揃う。
- `A2`: 左右固定モードで左右それぞれの傍注、複数行の柱、段組みを、それぞれ許される組み合わせで出力できる。
- `A3`: ノンブルを 1 に戻すセクションで偶奇合わせの白ページが入らず、PDF のページラベルとページ参照が新しい番号を示す。
- `A4`: マニュアルの設定例と移行説明から、左右固定モードの資料をビルドでき、LSP が新しいキーと値を補完する。

- `A5`: 柱とノンブルのそれぞれで `top-center` と `bottom-center` を指定でき、アンカーが版面の中央に一致する。
- `A6`: 本文に『蟹工船』からの連続した抜粋を使う fixture が、白ページを含まない 9〜11 ページの左右固定 PDF になり、出典と抜粋範囲から再生成できる。

## テスト設計

実装の前に失敗するテストを書き、各テスト名を `root ADR 0400 I2: ...` のように対象の番号で始める。
既存のモードの回帰テストと新しいモードのテストを分ける。

| 範囲 | テスト | 対象 |
| --- | --- | --- |
| 設定 | モード省略と明示、未知のモード、左右指定の排他、禁止した綴じ設定、継承した揃え、未使用のマスター、傍注の省略値、隠しノンブルの明示有効化を調べる。縦組みとの diagnostic の優先順位、継承での diagnostics の重複排除、原稿内の定義を含め、コードと位置も検査する | I1, I4 |
| 幾何 | 横組みと縦組み、左右基準、1 段と複数段、非対称の余白で通し番号 1〜4 の矩形を比較する。索引で段数が変わる場合にも、同じ対象領域なら偶奇で反転しないことを調べる。収まる境界と 1 sp のはみ出しも調べる | I2, I3 |
| 柱と傍注 | 左右と中央のアンカー、揃え、柱とノンブルそれぞれの `top-center` と `bottom-center`、複数行の柱、内容だけが odd/even で変わる柱を確認する | I2, A2, A5 |
| ページ分割 | 空ページと内容のあるページ、奇数と偶数の開始番号、明示した改丁、後続の見出し、送った図版と続きの脚注を組み合わせる | I5, I6 |
| PDF 統合 | トンボと通常ノンブルの有無、隠しノンブル、左右固定の描画座標、セクションのページラベルと参照を調べる | I2, I7, A1, A3 |
| プリフライト | 同じ安全域違反と塗り足し不足を奇数と偶数のページへ置き、端の名前と距離を比較する | I8 |
| LSP と文書の例 | 新しいキーと値の補完を検査し、設定例を既存の最小プロジェクトへ組み込んでビルドする | A4 |

A6 は fixture をビルドしてページ数と白ページの有無を自動で検査し、出力した全ページをレンダリングして、本文の欠落、ルビ、柱、ノンブルを目で確かめる。
再生成した原稿がコミットした原稿と一致することも検査する。

A1 と A2 は、自動テストに加えて出力 PDF の一ページ目から三ページ目をレンダリングして確かめる。
横組みと縦組みの例を別に用意し、版面の左右、柱、ノンブル、傍注、段の順序を確認する。
A4 の移行説明には `binding` と `gutter` の置き換え、相対位置の置き換え、`recto` と `verso` を残す場合の白ページを含める。

## トレードオフ

`binding = "none"` を加える案では、綴じ方向の有無とページの配置を一つのキーで表せる。
しかし、版面の位置や柱にもモード別の制約が要るため、この案ではページの配置を `layout` として明示する。
省略時の挙動を維持し、既存の書籍の移行を不要にする。

ノドと小口を左右へ暗黙に読み替えれば、既存のスタイルを少ない変更で流用できる。
この案では、意図しない側への配置を避けるため、左右固定モードで相対位置を拒否する。
その分、既存のスタイルから移行するときには柱や段落の揃えも書き直す必要がある。

明示した `recto` と `verso` は、綴じない資料でもページの偶奇を指定する用途のために残す。
一方、ノンブルの開始番号だけを変更したときには、左右を揃えるための白ページを入れない。
配置と番号付けの目的を分ける代わりに、モードによるセクション開始規則の差が生じる。

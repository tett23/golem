# ADR 0325: プリフライトでは欠けた字の重大度を glyph-missing で決める

ステータス: 採択

## 文脈

`golem preflight` は prod で PDF をメモリに組み、その内容を検査する。
書体にない字があっても、現行実装は検査用のページの情報を取り出せる。
試作では U+E000 を持たない書体を使い、欠けた字の G08100 と同時に塗り足し不足の G09010 が出た。
問題は検査の中断ではなく、プリフライトが同じ字について常に prod ビルドの G08100 を併記し、終了コードが 1 になることである。

DTP オペレーターが一回の実行で残作業を見積もれるよう、書体にない字以外のエラーでも、検査に必要な入力がそろっているかを個別に判定する。

## 実装すること

プリフライトでは検査用のページ情報を作れたとき、欠けた字を `glyph-missing` の G09002 で報告する。
同じ原因のビルド用 G08100 はプリフライトの diagnostic に加えない。
ほかの検査をすべて実行し、集めた結果にエラーがあれば 1、なければ 0 で終了する。
PDF ファイルを出力する `golem build --profile prod` は従来どおり G08100 を出して PDF を書かない。

ページ情報を作れなかったときも、誤りのある箇所に依存しない検査を続ける。
たとえば壊れた PNG を PDF に置けない場合でも、読み取れた `style.toml` の塗り足しと有効なプリフライト設定の最小値は比較できる。
G08010 と G09010 を両方報告する。
ページ上の字形、画像の配置や断裁線との距離を必要とする検査については、ページ情報を作れた場合だけ結果を報告する。
最終表示には検出したエラー件数と、前提がそろわず実行できなかった検査名と理由を併記する。
エラーのある入力を書き換えず、不完全な PDF を出力しない。

## 実装しないこと

壊れた画像などで検査用のページ情報そのものが得られないときに、仮の PDF を作って検査を続けない。
フォントにある別の字への差し替えや代替フォントの選択も行わない。

## 不変条件

1. P1：グリフ番号 0 で描いた文字について、G09002 の重大度と件数は `glyph-missing` に従う。
2. P2：欠けた字だけが問題のとき、終了コードが 1 になるのは `glyph-missing` が error の場合だけである。
3. P3：別の検査がエラーになれば、`glyph-missing` が off でも終了コードは 1 である。

4. P4：有効な規則と版面設定だけで決まる違反は、別の図版の失敗でページを作れなくても報告する。

| 字の状態 | glyph-missing | その他の diagnostic | 終了コード |
| --- | --- | --- | --- |
| 欠けなし | error | なし | 0 |
| 一字欠ける | off | なし | 0 |
| 一字欠ける | warning | なし | 0 |
| 一字欠ける | error | なし | 1 |
| 一字欠ける | off | 塗り足し不足のエラー | 1 |
| ページを作れない | 任意 | 壊れた PNG と塗り足し不足 | 1、G08010 と G09010 |

## テスト設計

`experiments/diagnostics/baseline.mjs` は実際のフォントを置き、U+E000 を組む。
P2 用の設定は `based-on = "none"` から始め、一つの検査の重大度だけを変える。
現行版の終了コードは off、warning、error の順に 1、1、1 だった。
P3 用には print の設定を使い、G09010 が残ることを検査する。
本実装では G09002 のメッセージ、位置、件数、ページ情報も既存の期待値と照合する。

P4 の [試作](../../experiments/diagnostics-review/probe.mjs) はヘッダーだけの PNG と塗り足しのない版面を一緒にビルドする。
変更前は原稿の三行目の G08010 だけだった。
変更後は終了コード 1 のまま、同じ G08010 とスタイルの一行目の G09010 を得た。
未検査名を人間向け表示や JSON で渡す処理は本実装に残る。

## トレードオフ

プリフライトの G08100 をコードで拾っていた自動検査は G09002 に切り替える必要がある。
一方、既にある `glyph-missing` の設定が、画面に出る diagnostic だけでなくコマンドの終了値にも反映される。

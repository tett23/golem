# ADR 0001: プレーンテキストの出力

ステータス: 採択→注の本文をまとめる場所と一覧の見出しは [golem-driver ADR 0026](../../golem-driver/adr/0026-chapter-end-notes.md)、見出し、目次、キャプションの番号と題のあいだの区切りは [golem-html ADR 0002](../../golem-html/adr/0002-heading-number-spacing.md)

## 文脈

プレーンテキストは、意味論 IR からテキストを取り出すだけの最も軽い出力であり、縦書きと横書きの二つの変種を持つ（specifications.md）。
横書きの変種は、ブログなどへの転載に使う。
ルビは「漢字（かんじ）」の形で併記し、圏点、強調、色は出力しない。
数の表記は、縦書きの変種で漢数字、横書きの変種で算用数字にする。

プレーンテキストにはページがないので、ページに由来するもの（ページ番号への参照、柱）は媒体契約に従って別の形にする必要がある。
この ADR はその扱いも定める。

## 実装すること

### 入力と出力

```haskell
renderText :: Style -> TextVariant -> Doc.Book -> [(FilePath, Text)]

data TextVariant = Vertical | Horizontal
```

- 出力は、マニフェストのソースファイルごとに一つのテキストファイルとする。ファイルの名前は、ソースファイルのパスの拡張子を `.txt` に替えたものとする。
- 文字コードは UTF-8、改行は LF、ファイルの末尾に改行を一つ置く。

### ブロック

- ブロックの間には空行を一つ置く。
- 見出し：style.toml の番号の書式で番号を付け、題を続ける。
- 箇条書きのリスト：`・` に続けて項目を書く。入れ子は全角の空白一つで字下げする。
- 番号付きのリスト：横書きでは `1. `、縦書きでは `一、` のように番号を付ける。
- 定義リスト：用語の行の後に、全角の空白一つで字下げした説明を書く。
- 表：行ごとにセルをタブで区切る。
- コードブロック：中身をそのまま書く。
- 図版：`［図3-2　キャプション］` の形の一行にする。
- 目次：番号と題の一覧にする。
- 索引：出力しない。
- 参考文献：番号と書誌の一覧にする。

### インライン

- ルビ：グループルビは「対象（読み）」とする。モノルビは、読みのあるセグメントが連続する範囲をまとめて「対象（読みを連結したもの）」とする。部分ルビで読みのないセグメントは、そのまま書く（`お父（とう）さん`）。
- 圏点、強調、色、文字スタイル：中身だけを書く。
- 縦中横：中身をそのまま書く。
- Number：縦書きの変種では漢数字（`style=tcy` の数も漢数字にする）、横書きの変種では算用数字にする。
- 章の番号と題への参照：S1 で解決した値を書く。
- ページ番号への参照：ページがないので、参照先の見出しの題を「」で囲んで書く。
- 注の印：横書きでは `*1`、縦書きでは `※1` とし、注の本文はそのファイルの末尾にまとめる。
- 傍注：本文側に `※1` の印を付け、傍注の本文を段落の直後に `※1 …` の形で書く。
- 校正用のコメント：dev のプロファイルでは `【校正：…】` として書き、prod では書かない。

## 実装しないこと

- ページ、柱、ノンブル。
- 索引の出力。
- 縦書きの変種での文字の向きの変換（縦書き用の約物への置き換えなど）。テキストの文字はそのまま書く。

## テスト設計

- docs/markup.md の例を含む原稿から、二つの変種の出力を golden テストで固定する。
- ルビの三つの形（グループ、モノ、部分）の出力を確かめる。
- Number が変種によって漢数字と算用数字になることを確かめる。
- ページ番号への参照が見出しの題になることを確かめる。
- 同じ入力から二回出力し、バイト列が一致することを確かめる。

## トレードオフ

ページ番号への参照を見出しの題に置き換えると、「42 ページ参照」のような文は「「はじめに」参照」のような形になり、文の自然さが損なわれうる。
プレーンテキストにはページがないので、参照先を特定できる情報を残すことを優先する。

注の印と箇条書きの記号を固定するので、表記を変えたい利用者は変えられない。
プレーンテキストは転載の素材であり、細かな表記は転載先で整えることを想定する。

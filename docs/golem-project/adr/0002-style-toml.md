# ADR 0002: style.toml の読み込み

ステータス: 採択→`[emphasis]` の廃止と `[paragraph-styles]` は [docs/adr/0005](../../adr/0005-character-and-paragraph-styles.md)

## 文脈

`style.toml` は、スタイル（見出しの番号の書式、注の配置、強調の表現、数の表記など）、レイアウト IR（判型、版面、マスターページ、フレーム、書字方向）、フォント、色のスウォッチを持つ（specifications.md）。
評価（スウォッチと文字スタイルの存在の検査）、文書構造（番号の書式）、出力（フォント、色）、レイアウトのすべてがこれを読む。
この ADR は、`style.toml` を読み、検査し、型の付いた値（`Style`）にする段階を定める。
レイアウト IR の意味（版面からページの幾何を計算すること）は golem-layout-spec の ADR で扱う。

## 実装すること

### 節

specifications.md の例にある次の節を読む。

- `[page]`、`[page.grid]`：判型、綴じの方向、既定の書字方向、版面（文字の大きさ、字数、行数、行送り、段数、段間 `column-gap`、位置）。
- `[fonts.<役割>]`：和文と欧文のフォントのファイル、OpenType の機能。
- `[character-styles.<名前>]`：文字スタイル。
- `[headings.<階層>]`：フォント、大きさ、番号の書式、改ページ、柱に使うか。
- `[composition]`：禁則の強さ、ぶら下げ組、ルビ、圏点、行分割の許容度（`pretolerance`、`tolerance`）、緊急の伸び（`emergency-stretch`）、hz の設定（`protrusion`、`expansion`）。
- `[figures]`：図番号の書式、回り込みの図版と本文の間隔（`wrap-gap`）。
- `[numbers]`、`[emphasis]`、`[notes]`：数の表記、強調の表現、注の配置。
- `[sidenotes]`：傍注欄の側（`side`）、幅、版面との間隔、フォント、文字の大きさ、本文側の印（`number`、`symbol`、`none`）。
- `[color]`、`[color.swatches]`：出力インテントの ICC プロファイルと、スウォッチ。
- `[masters.<名前>]`：柱とノンブル。
- フレーム（レベル 2 と 3）：型として定義するが、値を書いた場合はエラーとする。

### 検査

- 未知のキーはエラーとする。
- 列挙の値（`binding`、`writing-mode`、`kinsoku`、`placement` など）は、定めた集合の外の値をエラーとする。
- フォント、ICC プロファイルのファイルは、プロジェクトルートの中に存在しなければエラーとする。パスの正規化は [ADR 0001](0001-manifest-and-import-graph.md) と同じ規則に従う。
- スウォッチの CMYK の各成分は 0 から 100 の整数とする。
- 番号の書式の文字列は、使える差し込み（`{n}`、`{n:kanji}`、`{1}`、`{chapter}` など）だけを含むことを検査する。
- マニフェストの章の項目が指すマスターページは、`[masters]` に存在しなければエラーとする。

### 寸法と単位

- 寸法は、数と単位からなる文字列で書く。単位は `mm`、`pt`、`Q`、`H`、`zw` とする。
- `mm`、`pt`、`Q`、`H` は、読み込みの時点で整数の sp に変換する。変換は有理数で厳密に計算し、最後に一度だけ最近接偶数丸めで整数にする（1pt = 65536sp、1mm = 72/25.4pt、1Q = 1H = 0.25mm）。
- `zw`（全角一字分）は文字の大きさに依存するので、読み込みの時点では変換せず、相対的な寸法として保持する。レイアウトの段階で文字の大きさと掛け合わせて sp にする。

### 判型

判型の名前を寸法に写す表を持つ。
B 列は JIS の B 列（B6 は 128mm × 182mm）とし、ISO の B 列ではない。
v1 の表は A4、A5、A6、B5、B6、四六判（127mm × 188mm）とし、ほかの判型は寸法で書く。

### 既定の値

省略できるキーと既定の値を一つの表にまとめ、golem-project の中に一箇所で持つ。
`column-gap` は段数が 1 のときは省略でき、2 以上のときは必須とする。
`pretolerance`、`tolerance`、`emergency-stretch` の既定は TeX の既定（100、200、0）とする。

### インターフェース

```haskell
loadStyle :: Project -> IO (Either [Diagnostic] Style)
```

## 実装しないこと

- 版面からページの幾何を計算すること。golem-layout-spec の ADR で扱う。
- フォントの中身の読み込み（メトリクス、ライセンスの検査）。golem-font の ADR で扱う。
- `style.toml` からほかのファイルを取り込む機能。
- フレーム（レベル 2 と 3）の値の解釈。

## テスト設計

- specifications.md の例の `style.toml` が、エラーなしで読めることを確かめる。
- 未知のキー、範囲外の列挙の値、存在しないファイル、範囲外の CMYK、未知の差し込みを含む書式、存在しないマスターページの参照が、それぞれ診断になることを確かめる。
- 単位の変換：`1pt`、`25.4mm`、`4Q`、`1H` が期待した sp になることと、変換が丸めを一度しか行わないことを確かめる。
- 同じ `style.toml` を何度読んでも、同じ値になることを確かめる。

## トレードオフ

`zw` を読み込みの時点で変換しないので、寸法の型は絶対的な寸法と相対的な寸法の二種類を持つことになる。
文字の大きさを変えたときに全角を基準にした寸法が追随することは、日本語組版の設定として必要であり、型が一つ増える手間を受け入れる。

判型の表を少数に限るので、それ以外の判型は寸法で書く必要がある。
表に載せる判型は、要望に応じて ADR なしで追加してよい事項とせず、追加のたびに ADR を作る。
判型の名前の意味が版によって変わると、同じ `style.toml` から異なる出力が生じるためである。

# golem-pdf の仕様

golem-pdf は、Golem の PDF を書き、図版を PDF に置くモジュールである。
この文書には、[仕様書](../specifications.md) より細かい、実装の値と数え方を書く。

## PDF の図版の取り込み

`Golem.Pdf.Import` は、`@figure` の PDF の図版の 1 ページを読み、Form XObject として写せる形にする（[golem-pdf ADR 0008](adr/0008-pdf-figures.md)）。

### 資源の上限

上限は、図版のファイル一つの取り込み（`importPage` の一回の呼び出し）の中で数える（[docs/adr/0040](../adr/0040-pdf-import-resource-limits.md)）。
上限を超えた取り込みは G0810 とし、`PDF として読めません（理由）` の括弧の中に理由を書く。
新しい diagnostic のコードは作らない。

| 対象 | 上限 | 理由 |
|---|---|---|
| 展開したバイト数の合計 | 256 MiB（2^28 バイト） | `展開した大きさが上限を超えました` |
| 一つのストリームの展開 | 256 MiB | `展開した大きさが上限を超えました` |
| ページの内容（`Contents` の配列をつないだもの） | 256 MiB | `展開した大きさが上限を超えました` |
| ページの木の深さ | 64 | `ページの木` |
| 相互参照の項目の数 | 8,388,607 | `相互参照` |
| 相互参照ストリームの `Size` | 8,388,608 | `相互参照` |
| 改訂（`Prev`）の数 | 256 | `相互参照` |
| 配列と辞書の入れ子 | 256 | `入れ子が深すぎます` |
| 予測子の `Colors` | 1 以上 32 以下 | `予測子` |
| 予測子の `BitsPerComponent` | 1、2、4、8、16 | `予測子` |
| 予測子の `Columns` | 1 以上 | `予測子` |

8,388,607 は、ISO 32000-1 の Annex C が定めるオブジェクトの番号の最大である。
32 は、DeviceN の色空間の成分の数の上限である。
予測子の値は、予測子を使うとき（`Predictor` が 1 でないとき）にだけ確かめる。

### 展開の数え方

- フィルタの各段の出力を足す。Flate の出力、その後の予測子の出力、ASCIIHex と ASCII85 の出力である。`Predictor` が 1 の Flate は、Flate の出力だけを数える。
- 数えるのは、ページの内容のストリーム、Form XObject とパターンと Type 3 のフォントの字形の内容、ICC プロファイル、オブジェクトのストリーム、相互参照のストリームである。画像のストリームは展開せずに写すので、数えない。
- 同じオブジェクトのストリームは一度だけ展開し、結果を使い回す。使い回した展開は数えない。
- どの段も、合計の残りを超える出力を作らない。Flate は残りを超えた時点で展開をやめる。ASCIIHex と ASCII85 は出力の大きさを先に数え、残りを超えた時点で数えるのをやめて止める。
- ページの `Contents` が配列なら、ストリームを改行でつないだ内容が 256 MiB を超えたときに止める。同じストリームを何度も名指しすると、展開は一度でも、つないだ内容はその回数だけ大きくなるためである。

### ページの木

- 訪れたノードの集合を木の全体で一つ持ち、一度訪れたノードをもう一度指す参照で止める。PDF の仕様はページの木のノードに `Parent` を一つだけ許すので、同じノードを二つの `Kids` から指す木は正しい PDF ではない（ISO 32000-1 7.7.3）。
- `page` のページに届いた時点で歩くのをやめる。それより後ろのノードは読まない。

### 相互参照

- 改訂の開始の位置と `XRefStm` の位置を一つの集合に入れる。すでに見た位置を指す `Prev` と `XRefStm` は、読み直さずに空とする。
- 項目の数は、表とストリームのすべての改訂を合わせて数える。ストリームの項目の数は、`Index` の項目の数と、展開したデータにある行の数の小さいほうである。
- 相互参照ストリームは、行を辞書に組み立てず、展開したデータの中の行をオブジェクトの番号から引く。そのため `Index` の小区間は、ISO 32000-1 7.5.8.2 のとおり番号の順に並び、重ならないものに限る。外れれば `相互参照` の理由で止める。

### 予測子と内容のストリーム

- TIFF の予測子（`Predictor` が 2）は、行の長さに比例する時間で戻す。
- 内容のストリームの書き換え（DeviceRGB を sRGB の色空間にする）は、トークンの列を作らず、入力を一度歩きながら出力を書く。書き換えのないストリームは、入力をそのまま使う。
- 内容のストリームの大きさには、展開の上限のほかに上限を設けない。

# ディスコース・ポライトネスを考える見本

『ディスコース・ポライトネスを読むために』は、和文の横組み、二段組みの見本である。
本文は、確認した書誌の題名と刊行年から研究対象を概観し、精読と資料の記録法について独自の問いを提示する。
文献の本文を読んだことを前提にした理論の要約や、会話調査の結果は記していない。
参考文献十一件と著者名の並べ替えのキーの出典は[文献スタイルの調査](../../../docs/research/bibliography-styles.md#見本の論文の参考文献)にある。
Usami 二〇〇二年の未確認の総ページ数や、引用箇所のページは補っていない。

リポジトリのルートで次を実行する。
`golem` には、このチェックアウトからビルドした実行ファイルを使う。
フォントは既存の CI と同じ取得先と SHA-256 を検査して準備し、Git には含めない。

```sh
sh samples/papers/prepare-fonts.sh
cd samples/papers/discourse-politeness
golem check
golem build
```

PDF は `build/pdf/`、HTML は `build/html/`、EPUB は `build/epub/`、二種類のテキストは `build/text/` に出る。
`style.toml` の `discourse` は、著者と年による引用、複数文献の刊行年順、和欧を混ぜた著者順の一覧を指定する。
日本語の名前には書誌データに保持された確認済みのキーを使い、姓の読みを推測しない。
同年の宇佐美の二件、著者名を本文に書く `form=year`、複数文献の引用と再引用を含む。
日本語の題に『』や「」を追加しないが、書誌データの題自体に含まれる括弧は保つ。

この宣言は[採択した root ADR 0470](../../../docs/adr/0470-bibliography-styles-by-name-and-by-declaration.md)の『社会言語科学』向けの条件を確かめるための草案である。
同誌の雛形は一段組みだが、この見本は ADR の指定に従って二段組みにする。
PDF の DOI の直前などには、行の両端揃えで字間が広がる箇所がある。
全媒体の完成確認、投稿規定との細部の照合、A1 のメンテナーによる目視は残っている。
著者と年による引用から一覧へ移る HTML と EPUB のリンクも、現時点では接続されていない。
CI の追加と時間予算の判断も、このプロジェクトには含めていない。

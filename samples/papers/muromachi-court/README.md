# 室町期の朝廷を考える見本

『室町期の朝廷を関係の交点として読む』は、和文の縦組み、二段組みの見本である。
本文は書誌の題名を手がかりに読書の問いを組み立てた独自原稿であり、史料調査や文献の精読の成果を報告する論文ではない。
参考文献十件の出典は[文献スタイルの調査](../../../docs/research/bibliography-styles.md#見本の論文の参考文献)にあり、未確認の今谷一九九〇年の叢書番号は補っていない。
本文の引用に、確認していないページの指定は加えていない。

リポジトリのルートで次を実行する。
`golem` には、このチェックアウトからビルドした実行ファイルを使う。
フォントは既存の CI と同じ取得先と SHA-256 を検査して準備し、Git には含めない。

```sh
sh samples/papers/prepare-fonts.sh
cd samples/papers/muromachi-court
golem check
golem build
```

PDF は `build/pdf/`、HTML は `build/html/`、EPUB は `build/epub/`、二種類のテキストは `build/text/` に出る。
`style.toml` の `court-notes` は章末注を指定し、書籍を『』、論文を「」で囲み、巻号と年を漢数字にする。
今谷一九九〇年と富田一九八九年を再引用し、二度目には「前掲注（最初の注番号）」を出す宣言である。
これは[採択した root ADR 0470](../../../docs/adr/0470-bibliography-styles-by-name-and-by-declaration.md)の慣行の見本であり、特定の雑誌がこの句読点を定めているという主張ではない。

引用から章末注を作る処理と `first-note` の接続が完了していない版では、引用全文が本文中に現れ、再引用も最初と同じ書式になる。
その出力が診断なしで生成されても、この見本の完成を意味しない。
接続後に注の番号、本文から注へのリンク、再引用を全媒体で確かめ直す必要がある。
root [ADR 0470](../../../docs/adr/0470-bibliography-styles-by-name-and-by-declaration.md) A1 のメンテナーによる投稿品質の目視と、日本歴史か史学雑誌の実際の誌面との比較は未完了である。
CI の追加と時間予算の判断も、このプロジェクトには含めていない。
